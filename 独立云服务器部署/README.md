# 独立云服务器部署：新云入口与双份密文备份

> 本目录记录 R730xd 业务保持运行时新增第二云入口和双份密文备份的实施、验收与交接。

本目录是本次“部署到另一台服务器”验收的独立操作簿。适用范围是 **R730xd 继续运行所有业务容器和数据**，旧云 `8.138.10.222` 的共享 FRP 与 HTTPS 入口继续运行；新云 `8.138.42.212` 只运行项目专用 FRP 服务端、Nginx、证书续期和受限 SFTP 接收端。新云和旧云均不是完整业务副本，R730xd 故障时两个入口都会失效。

**当前执行状态以 [验收与变更日志](05-验收与变更日志.md) 为准。** 配置模板存在不代表已在服务器启用，备案未通过时不得启用 `www.cyancarp.cn` 的网站。根域名 `cyancarp.cn` 不在本次范围。

按顺序阅读：[架构与前置门槛](01-架构与前置门槛.md) → [新云与 R730xd 部署](02-实施步骤.md) → [域名备案后启用](03-域名与证书.md) → [备份、切换与回退](04-备份恢复与回退.md) → [验收与变更日志](05-验收与变更日志.md) → [运维交接与值班清单](06-运维交接与值班清单.md)。配置样本在 [config](config/)。

## 运行责任与安全边界

| 位置 | 保留/新增 | 公网入口 |
| --- | --- | --- |
| R730xd | 全部 Compose 业务、数据库、模型、旧 `frpc`；新增独立 `powersystem-edge-frpc`；同一密文双上传 | 不增加业务公网端口 |
| 旧云 `8.138.10.222` | 共享 `frps`、既有 HTTPS/WSS、SFTP 原样保留 | `443` 手动备用 |
| 新云 `8.138.42.212` | 独立 `frps`、Nginx、受限 SFTP、证书任务 | `443` IP 入口；备案成功后 `www.cyancarp.cn` |

域名和两个 IP 是不同浏览器来源，切换后需要重新登录。新云故障时直接访问旧云 IP；不要先停业务容器或旧云客户端。

私密值只保存在主机受限文件：FRP token、TLS 私钥、SSH 私钥、备份口令、业务 `.env` 均不得写进仓库、工单、终端输出或截图。新云只接收 **GPG 密文和 SHA256 文件**，不得放解密口令。最初通过聊天提供过新云 root 密码；部署建立密钥登录并保留应急会话后须轮换该密码。
