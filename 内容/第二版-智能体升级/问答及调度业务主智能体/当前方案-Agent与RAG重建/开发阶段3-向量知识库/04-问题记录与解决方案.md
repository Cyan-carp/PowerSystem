# 04 · 问题记录与解决方案

运行编号 `rebuild-20261011`，日期2026-10-11。本机合成演示范围，R730XD及公网未发布。证据在忽略目录 `artifacts/stage8-agent-rag/rebuild-20261011/`；真实与受控故障分开判定。

## 一、本轮问题与处理

| 现象 | 原因与处理 | 状态 |
| --- | --- | --- |
| 首次检索超时 | E5首次加载超过单工具15秒，改为启动预热 | R3无该超时，已解决 |
| 长段落tokenizer长度提示 | 分片前长段编码正常；关闭编码提示并实际检查所有最终片段≤400 | 已解决 |
| 历史会话引用在换集合后失效风险 | 先查当前别名，再查保留的本项目版本集合 | 用例通过 |
| 失败导入报告易保留旧成功状态 | 异常写独立failed报告，构建失败不切换别名 | 实际失败用例通过 |
| Windows测试报告默认GBK读取失败 | 私有导入验收脚本明确UTF-8读取后完整重跑 | 已解决 |
| 更新全量重新向量化 | 首版以新集合保证无残留，尚未缓存未变片段向量 | 性能优化待办 |
