# 部署测试产物目录

此目录用于保存部署相关工具在本地生成的测试产物。

- `frp-source-tests/`：FRP 动态来源维护测试的本地输出目录，兼作 `test_frp_source.py` 的隔离测试临时根目录（测试 uuid 子目录自动清理）。已放置两条持久验证资产：`自然事件验证手册.md`（真实公网换址四环节验证口径）与 `verify-natural-event.py`（新云侧只读脱敏核对器）。真实换址恢复仍待自然事件，验证口径见手册。
- Git 仅跟踪本说明和目录占位文件；生成的测试产物继续忽略，需要公开的证据应先审查内容，再明确加入跟踪规则。

部署脚本与配置位于 [edge-server](../edge-server/)，部署笔记位于 [系统部署发布备份与变更记录](../../notes/04-系统部署发布备份与变更记录/)。仓库级运行产物仍保存在根目录的 `artifacts/`。
