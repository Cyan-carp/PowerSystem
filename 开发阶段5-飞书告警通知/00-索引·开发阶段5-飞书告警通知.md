# 开发阶段5 · 飞书告警通知索引

> 本阶段是项目所有者在原四阶段路线图之外单列的监控通知扩展。源码见 [[stages/05-feishu-notification/README.md]]；阶段四保留服务器统一编排和 2026-09-29 P0 原始取证。单列阶段不改变 M4“待验收”的结论，也不新设未经约定的 M5 里程碑。

## 一、阶段范围与亮点

| 范围 | 当前状态 | 边界 |
| --- | --- | --- |
| Prometheus 监控规则 | API 不可用、主机磁盘高占用规则已配置 | 设备业务告警不在此通知链路 |
| 告警转发 | Alertmanager 聚合后经内网适配器签名发送 | 适配器不映射公网端口 |
| 触发与恢复 | 2026-09-29 API 宕机演练两条群消息已确认可见 | 磁盘规则未做真实越限送达演练 |
| 凭据管理 | 服务器 root 私有文件，容器启动读取后降权 | 文件和真实值不入公开仓库 |

项目亮点是**监控状态变化能到达值班群，并能看到恢复消息**。证据由 Prometheus 状态、Alertmanager 到适配器的 HTTP 结果和群成员实际看到的两条消息共同组成；只凭配置校验或 HTTP 200 不称“群内送达”。
