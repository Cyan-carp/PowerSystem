# 开发阶段5 · 飞书业务与监控告警索引

> 项目所有者已将阶段五飞书业务告警列为第一版主要业务。设备越限、AI 风险与平台监控均属于本阶段。旧 P0 证据覆盖 API 宕机/恢复；第一版新现场证据覆盖设备业务闭环、失败重试和真实模型合成 AI 风险/恢复，项目所有者确认群内可见。服务器统一 Compose 仍在阶段四目录；阶段五业务验收纳入 M4 第一版总验收，不单设 M5。

## 一、阶段范围与亮点

| 范围 | 当前状态 | 边界 |
| --- | --- | --- |
| 设备越限与 AI 风险 | 触发、确认、恢复、配置关闭及失败重试已现场核对；真实模型合成 AI 高低风险均生成通知，所有者确认群内可见 | 合成数据不代表真实场站预测准确率；更换机器人后须重验 |
| Prometheus 监控规则 | API 不可用、主机磁盘高占用规则已配置 | 与业务事件不同源，历史 API 故障消息已实测 |
| 告警转发 | Alertmanager 聚合后经内网适配器签名发送 | 适配器不映射公网端口 |
| 触发与恢复 | 2026-09-29 API 宕机演练两条群消息已确认可见 | 磁盘规则未做真实越限送达演练 |
| 凭据管理 | 机器人凭据与业务令牌分别存服务器私有文件 | 文件和真实值不入公开仓库 |

第一版已分别取得业务告警闭环与监控故障恢复证据。业务状态变化先与数据库记录同事务落盘，再由后台重试；本轮适配器响应与所有者群内可见性确认一起核对。监控消息的历史证据没有代替新增业务链的新现场证据。
