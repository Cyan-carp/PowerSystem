## 布局方法

- 链接图：两级确定性圆盘打包，不依赖浏览器端力导向（318 节点下会发散）。
  目录簇内按网格铺点 → 簇在分区内用同心环初值 + 只分离松弛 → 分区再按同样方式打包成整图。
  坐标只由结构决定，同一份数据每次打开结果一致；簇圈与簇名由实际坐标反算。
- 思维导图：目录树 tidy layout，横向层级、可折叠；同列强制最小行距，避免同名文件与同名目录重叠；
  选中笔记后叠加关系弧线（颜色对应链接类型）。

## 体积与编码约定

| 文件 | 体积 | 最大行宽 |
| --- | --- | --- |
| `graph-data.json` | 331 KB | 61 KB（`tree` 单行） |
| `index.html` | 379 KB | 61 KB（`tree` 单行） |

早期版本 1.27 MB、单行 637 KB，多数编辑器打开即假死。当前编码约定：

- **链接压缩为 `[源下标, 目标下标, 类型下标]`**，类型顺序由 `stats.linkTypes` 给出；模板启动时一次性还原成 `{s,t,type}` 对象，其余渲染代码不感知压缩格式。原先每条链接重复两段 140 字符绝对路径，占 750 KB。
- **节点不再输出 `id`**（与 `path` 完全相等），由模板启动时补回。
- **`tree` 叶子只保留 `name/path/type/deg/isIndex/count`**，`tags`、`top` 可由 `path` 查回，原先重复约 100 KB。
- 顶层数组（`nodes`、`edges`、`hubs`、`matrix`、`dirs`）**每条记录一行**，便于编辑器和 `git diff`；标量与数组内的标量仍紧凑输出。
- 布局算法完全在浏览器端，`build_graph.py` 只写 `x: 0, y: 0` 占位，不保留任何 Python 侧坐标算法。两次生成的文件 SHA-256 完全一致。
