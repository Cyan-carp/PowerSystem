# 行业调研与产品分析 · 索引

> 本文件夹是「源网智联」新能源场站云边协同智能运维平台在**写代码之前**的地基文档，回答三个问题：**这个行业值不值得做、国家支不支持、我们凭什么做。**

## 一页读懂（给行业外人士）

> **国家为什么推**：国家发改委、国家能源局 2026 年印发的《可再生能源发展"十五五"规划》白纸黑字写着要「应用智能识别、自动化巡检、故障智能诊断等技术，提升新能源智慧运维水平」「支持区域新能源场站群一体化集控运维」——说白了，光伏风电建得越多，国家越要逼着这些场站用 AI 少用人、少停电。
>
> **市场有多大**：2025 年中国风电+光伏运维服务市场规模突破 **700 亿元**，储能运维再添 **300 亿元**；全球可再生能源运维市场 2025 年约 58.4 亿美元，预计 2032 年翻倍到 105.6 亿美元。换句话说，光"伺候"这些电站，就是一个千亿级的生意。
>
> **现在的人为什么痛苦**：以南方电网储能为例，其 AI 运维平台试运行一年，设备故障率降低了 34%——反过来看，没上这套系统之前，电站每年要多坏三分之一的设备。更直观的是金风科技的数据：风电事故 62% 源于部件失效，单次事故损失高达百万以上，而传统模式下调专家到现场平均要等 1 周。设备坏了才发现、发现后又修不起、修还得等——这就是今天新能源场站值班员和业主的真实处境。

## 项目一句话定位

**「源网智联」** = 面向中小新能源场站的云边协同智能运维平台，用**机理仿真数据 + 可解释的小数据 AI**，把运维从「被动响应」变成「主动预防」，实现低成本、可复制的场站少人化运维。

技术主线：`设备模拟器 → MQTT → Go 边缘网关 → 时序库 → Gin 后端 → XGBoost 故障预测 → Vue3 前端`

## 结论速览（答辩快速引用）

1. **市场**：2025 年中国风光运维市场突破 700 亿元，储能运维 300 亿元，智能运维渗透率中国仅 41%，增速 28%+。
2. **政策**：「十五五」规划明文要求「智能识别、自动化巡检、故障智能诊断」，AI+能源系列文件点出「设备故障预测性维护」。
3. **痛点根因**：数据孤岛（协议不统一）、巡检成本高（场站偏远分散）、故障发现滞后（事后维修）、告警淹没（缺收敛分级）。
4. **竞争格局**：头部五家仅占 19.6%，高度碎片化；通用平台「重而不专」、开源平台「全而不易」、垂直平台「强而绑定」。
5. **我们的差异**：小数据可解释 AI（XGBoost+特征重要性，用对照实验说话）+ 低成本可复制（全栈 Docker 化、部署成本较商业平台降 50%）。
