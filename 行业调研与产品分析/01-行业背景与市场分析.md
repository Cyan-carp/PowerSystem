# 01 · 行业背景与市场分析

> 回到 [[00-索引·行业调研与产品分析]]

## 一、行业背景：双碳驱动的装机爆发

在「双碳」战略与新型电力系统建设背景下，以光伏、风电为代表的新能源装机持续高速增长。

**核心装机数据（国家能源局，截至 2025 年底）**：

| 指标 | 数据 | 同比 |
| --- | --- | --- |
| 全国累计发电装机 | 38.9 亿千瓦 | +16.1% |
| 风电+光伏累计装机 | 18.42 亿千瓦（占比 47.3%） | +30.9% |
| 太阳能发电装机 | 12.0 亿千瓦 | +35.4% |
| 风电装机 | 6.4 亿千瓦 | +22.9% |
| 2025 年风光新增装机 | 4.34 亿千瓦 | — |
| 可再生能源装机占比 | 超六成 | — |

关键判断：风光装机已完成对煤电、火电、最大用电负荷的「三连超」，**新能源从配角变成电力装机主体**。装机越多，需要"伺候"的设备规模越大，运维需求随之爆发。

## 二、市场规模：千亿级的后服务生意

运维是新能源资产的"后服务"环节，规模随装机存量持续放大。

| 细分市场 | 规模 | 说明 |
| --- | --- | --- |
| 中国风电+光伏运维服务 | **突破 700 亿元**（2025） | 含设备维护、电力交易、数字化运营 |
| 储能运维 | 突破 300 亿元（2025） | 增速最快的细分赛道，第三方渗透率 >45% |
| 全球可再生能源运维 | 58.4 亿美元（2025）→ 105.6 亿美元（2032） | CAGR 8.82% |
| 中国分布式光伏智能运维 | 38.2 亿美元（2025） | 同比 +28.4%，高于全球 |
| 中国新能源数字化解决方案 | 86.2 → 179.5 亿元（2023→2025E） | CAGR 44.1% |
| 智能运维渗透率 | 中国 41% / 全球 34%（2025） | 提升空间巨大 |

结论：光"伺候"电站就是一个**千亿级**生意，且渗透率不足一半，**增量红利与存量改造叠加**，是典型的高增长蓝海。

## 三、行业核心矛盾：装机爆发 vs 运维能力掉队

行业最尖锐的矛盾不是"没有技术"，而是**装机规模在爆发式增长，运维能力未能同步跟进**：

- 老旧机组技改需求集中释放；
- 市场化电价改革让运维从「成本中心」变为「收益杠杆」；
- 具备 AI 能力与跨区域网络的头部企业，正在快速拉开与中小运维商的差距。

## 四、四大痛点归因分析

> 痛点不是数据堆砌，要落到真实场景、挖出根因，再反推「我们怎么解」。

### 痛点 1：数据孤岛——"设备都通电，但彼此不说话"

- **场景**：同一场站内，逆变器、汇流箱、箱变来自多家厂商，各自私有协议、没有统一物模型，运维人员要在多套系统间来回切换。
- **量化**：新能源场站设备品牌混杂，多源异构是常态；数据孤岛直接导致「上层分析无数据可用」。
- **根因**：① 设备厂商各自为政，缺乏行业统一接入标准；② 场站分多期、多 EPC 建设，设备异构层层叠加；③ 缺一个统一的边缘接入层做协议归一。
- **别人怎么解**：华为 FusionSolar 靠「绑定自家逆变器/储能硬件」从源头规避（局限：锁定生态、无法接第三方品牌）；远景 EnOS 靠「3000+ 设备模型 + 90% 协议适配」硬啃异构（局限：平台重、成本高）；阿里云/华为云 IoT 靠「标准物模型」抽象（局限：只是底座，离新能源业务远、需大量二次开发）。
- **我们怎么解（中小场景）**：以 MQTT 为统一协议 + 轻量 Go 边缘网关做数据订阅、解析校验、标准化治理，把异构设备"翻译"成统一遥测数据——**不需要换硬件、不需要重平台**，中小场站即可低成本落地。

### 痛点 2：巡检人力成本高——"装机越多，人越不够用"

- **场景**：场站地处西北荒漠、山地、海上，分布分散，人工巡检路途远、周期长；海上风电运维成本占全生命周期 35–45%（远超陆上约 20%）。
- **根因**：① 新能源「装机爆发式增长」与「运维人员增速」严重不匹配；② 场站选址天然偏远分散，人工巡检的单位成本随规模不降反升。
- **别人怎么解**：华为「智能 I-V 诊断 + 无人/少人值守」、金风「L3 无人化运营（目标每月只去 1 次风电场）」——但两者都依赖**自家专有硬件 + 重资产体系**，中小场站用不起。
- **我们怎么解（中小场景）**：遥测数据实时回传 + 实时监控大屏，让值班员在一个屏上掌握全场站状态、减少无效下站——**纯软件实现少人化，成本低一个量级**。

### 痛点 3：故障发现滞后——"坏了才知道，知道已晚了"

- **场景**：传统靠人工巡检/事后维修，故障从发生到被发现的采样周期以「天」计，故障期间发电持续损失。
- **量化**：传统故障响应时间平均 48 小时，智能运维可压缩到 4.2 小时以内。
- **根因**：① 缺乏 7×24 连续遥测采集与自动判定；② 「事后维修」模式固有滞后，发电损失按小时累积。
- **别人怎么解**：金风「AI 多模态监测」、华为「I-V 诊断（行业首个 L5 认证）」都能提前识隐患——但都建立在**多年真实运行数据 + 专有硬件**之上，冷启动门槛极高。
- **我们怎么解（中小场景）**：遥测越限 10 秒内告警 + XGBoost 故障前兆预测，从「事后告警」跨越到「事前预测」——**用机理仿真数据即可起步训练，不依赖真实场站历史数据**。

### 痛点 4：告警依赖人工筛查——"告警满天飞，真问题被淹没"

- **场景**：海量遥测产生海量告警，值班员被告警淹没，真正危险的告警反被忽略。
- **根因**：① 缺告警收敛/去重/分级机制，真告警被噪声淹没；② 缺基于模型的事前预测，只能被动应对。
- **别人怎么解**：ThingsBoard「规则链告警」、EMQX「SQL 规则引擎」能做规则判断与告警触发——但**只做规则、不做事前预测**，仍是"越限才报"，且不解决告警收敛分级的业务问题。
- **我们怎么解（中小场景）**：多级告警规则引擎 + 告警收敛（同一设备同一指标未确认前不重复告警）+ 分级通知 + 确认闭环，**再叠加预测预警**，形成「规则告警 + 预测预警」的完整闭环。

## 五、行业成效案例（佐证价值）

| 案例 | 成效 |
| --- | --- |
| 大唐蔚州光伏 | 设备故障预判准确率 >95% |
| 国家能源集团海北 | 隐患识别准确率 >98% |
| 南网储能 AI 平台 | 试运行一年，设备故障率降 34%、消纳电量提升 30% |
| 金风科技 | AI 预测性维护降低非计划停机率超 40% |

这些案例共同证明：**「预测性维护 + 智能运维」的投入产出已被头部企业反复验证**，问题只是如何把它低成本地复制到中小场站。

## 六、本章小结

1. 装机已爆发，风光成为电力装机主体 → 运维需求刚性放大。
2. 运维是千亿级、高增长、低渗透的市场 → 蓝海明确。
3. 四大痛点的共同根因是「**缺数据治理 + 缺自动化判定 + 缺事前预测**」→ 正是本项目的技术切入点。
