# 03 · 技术现状与发展趋势

> 回到 [[00-索引·行业调研与产品分析]]

本章梳理智能运维的关键技术栈现状，回答「政策要落地的能力，技术上现在到哪一步」，并明确本项目的技术站位。

## 一、技术架构主线：云边协同成为主流

新能源场站「偏远、弱网、数据量大」的天然属性，决定了不能把所有计算都压在云端。

| 层 | 职责 | 典型技术 |
| --- | --- | --- |
| 端（设备） | 数据感知 | 光伏逆变器、传感器、ESP32 |
| 边（网关） | 实时采集、协议归一、断网缓存 | Go 边缘网关、边缘计算 |
| 云（平台） | 存储、重计算、AI | 时序库 + 关系库 + 模型服务 |

**趋势判断**：云计算负责存储与重计算，边缘侧负责现场实时处理，二者分工协作以平衡实时性与成本——这已是行业共识，也是本项目「云边协同」架构的理论依据。

## 二、关键组件技术现状

| 组件 | 本项目选型 | 行业地位/说明 |
| --- | --- | --- |
| MQTT 中间件 | EMQX | 工业物联网消息路由事实标准，MQTT 与 OPC UA 并列为通信标准 |
| 时序数据库 | InfluxDB / TDengine | 国产 TDengine、Apache IoTDB 写入吞吐与压缩率优异，广泛用于能源物联网 |
| 边缘网关 | Go 语言 | Go 协程+channel 天然适配高并发收发解耦 |
| 后端框架 | Go + Gin | 企业级 REST 服务主流选择，handler/service/model 分层 |
| 关系数据库 | PostgreSQL + GORM | 设备台账、告警规则、告警记录 |
| 缓存 | Redis | 缓存设备最新遥测值，减轻时序库压力 |
| 前端 | Vue3 + ECharts + Element Plus | 实时大屏与历史曲线 |
| 模型服务 | FastAPI + XGBoost | 独立预测服务，与后端解耦 |

## 三、故障预测技术路线对比

这是本项目 AI 模块的技术选型核心。行业共识已清晰：**工业场景的 AI，可解释性与数据质量远比模型复杂度重要**。

| 路线 | 代表 | 优势 | 劣势 | 适用场景 |
| --- | --- | --- | --- | --- |
| 梯度提升树 | XGBoost | 小样本强、可解释（特征重要性）、训练快 | 对长序列建模弱 | 表格化遥测特征（本项目） |
| 深度学习时序 | LSTM | 长序列建模强 | 小样本易过拟合、难解释 | 大规模带标注数据 |
| 时序 Transformer | PatchTST、TimesNet、TimesFM | 高维长序列预测不断刷新基准 | 数据需求大、黑盒 | 大模型/研究前沿 |

**本项目选择 XGBoost 的实证逻辑**：小样本条件（仿真模拟器产数据）+ 需要向值班员解释"为什么报警"，XGBoost 特征重要性天然可解释，且用 LSTM 做对照实验形成「为什么不用深度学习」的证据链。

## 四、可解释 AI：工业采纳的关键门槛

> 「能讲清为什么报警」的系统才具备落地价值。

- 结合**特征重要性、SHAP 值**等方法输出预测依据，成为提升运维人员信任的标准做法；
- 国家政策（[[02-政策环境与驱动力]]）也点名要攻关「算法黑盒化」问题，可解释 AI 从「加分项」变为「合规项」；
- 本项目输出「故障概率 + 主要依据特征」，让值班员"知其然更知其所以然"。

## 五、数字孪生：从监测到预演的进阶

- 通过高保真仿真环境预演设备状态演进，为预测性维护提供"沙盒"；
- 行业趋势是「数字孪生深度融合」，但属于**进阶能力**（路线图中的 Could 级），本项目以「机理仿真模拟器」作为轻量替代——用真实物理规律建模，正面回应"数据从哪来"。

## 六、国内外研究现状速览

**国内**：
- 平台层：开源 ThingsBoard 提供设备接入/规则引擎/仪表盘，阿里云 IoT、华为云 IoT 等商业平台成熟，「产品—设备—物模型」抽象成为事实标准；
- 数据层：国产时序库 TDengine、Apache IoTDB 表现优异；
- 工程层：国网、南网相继建成智能运检体系，推动少人无人值守。

**国外**：
- 预测性维护（PdM）概念由美军与 NASA 上世纪 90 年代率先提出，方法论成熟；
- MQTT、OPC UA 成为工业物联网通信事实标准；NVIDIA Jetson 推动边缘 AI；
- XGBoost 在小样本表格数据长期保持竞争力，LSTM/Transformer/TimesFM 在高维长序列不断刷新基准。

## 七、趋势总结与本项目站位

| 趋势 | 本项目响应 |
| --- | --- |
| 云边协同主流化 | Go 边缘网关 + 云端平台的分层架构 |
| 可解释 AI 成采纳关键 | XGBoost + 特征重要性 + 对照实验 |
| 数字孪生深度融合 | 机理驱动的仿真模拟器（轻量替代） |
| 「人工智能+」规模落地 | 预测服务化 + 告警闭环，从 Demo 走向可用 |
