# Codex 与 Workbuddy 共享记忆

本目录用于 Codex 与 Workbuddy 在项目协作时交换必要上下文，不属于 `notes/` Obsidian 正式笔记库，也不替代源码 README、设计文档、测试证据或发布记录。

## 目录结构

```text
shared-memory/
├── README.md                         # 入口与使用说明
├── project-memory.md                 # 跨对话长期有效的项目公共记忆
├── workbuddy-collaboration.md        # Workbuddy 协作规范
└── conversations/                    # 每个对话一个独立记忆文件
    └── YYYY-MM-DD-<简短主题>.md
```

## 使用规则

- **结论性状态只认 `notes/00-当前系统状态.md`**：本目录记录过程与判断，生产指针、阶段状态与已知限制以该页为准；协作记忆里的旧状态不作为验收或部署依据。
- 每个新对话必须创建新的记忆文件，不复用或覆盖其他对话的记忆。
- 同一天同主题重名时，在文件名末尾追加 `-02`、`-03`。
- 当前对话的重要目标、决定、约束、完成项、验证结果和待办应随进展更新。
- Workbuddy 返回任务结果时，可以把需要交给 Codex 的结论直接补充到当前对话记忆，并在结果中列出新增内容；不得修改其他对话的记忆。
- 项目公共记忆只保存跨对话长期有效、经过确认的稳定事实；临时进度留在对话记忆。
- 正式结论仍须写回对应工程笔记、README、测试交付页或部署记录；共享记忆不能作为唯一验收证据。
- 禁止记录密码、令牌、私钥、连接密钥、完整隐私数据、未脱敏日志和其他不应进入 Git 的内容。
