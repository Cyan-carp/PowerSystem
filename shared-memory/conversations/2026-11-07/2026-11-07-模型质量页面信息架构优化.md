# 2026-11-07 · 模型质量页面信息架构优化

## 本轮目标（所有者提出）

优化 `/model-quality` 前端页面，四点诉求：

1. 混淆矩阵与命中率类图表过大、信息量低，压住了 AI 解读、模型版本、漂移事件等高信息量模块。
2. 「运维视角」「样本量」等卡片没有重点，文字解释繁重且不易理解。
3. 整页重排：重要但不必占大空间的数据合并展示；运维人员一打开就能对当前质量有大概了解，次要信息下移。
4. 提高页面利用率，避免「卡片铺满但信息分散空洞」。

所有者指令：**先出计划**，未确认前不改代码。

## 现状核查（本轮实读）

- `views/ModelQualityView.vue` 仅 9 行壳，实际全部内容在 `components/PredictionQuality.vue`（1100 行，含模板与 scoped 样式）。
- 页面自上而下 8 块 `.card`：KPI 四格 → 运维视角 → 混淆矩阵 + 高风险组命中率（并排行）→ 按日趋势 → 模型运营（重训 + AI 解读）→ 模型版本 → 漂移事件。
- `ConfusionMatrix.vue` 写死 `grid-template-rows: auto 170px 170px`（≥340px）；`RiskBandsChart.vue` 画布 `BOX.h=360`；`QualityTrend.vue` 默认 `height=208`。首屏基本被图表占满。
- AI 解读在第 5 块、模型版本第 6 块、漂移事件第 7 块，均在常见 900px 首屏折叠线以下。
- `.ov-grid` 为 2 列但渲染 3 个 `.ov-cell`，第三格换行形成不对称空白；第二格说明文字是一段百字长句。
- KPI 四格等权，样本量（分母）与三个结论型指标并列；每格带一句术语型 note。
- 数据口径（不得改动）：批次命中率按故障批次；窗口漏报率 = 1 − recall；运维视角固定近 1 天；模型版本/漂移不随窗口变化。
- 规范约束：无 UI/图表库，图标只用本地集，颜色/圆角/间距取 `tokens.css`，通用类复用 `shell.css`，页面内 `<style scoped>`。
- 环境约束：本地 5173 前端 + 8080 假后端；改 src 后删 `node_modules/.vite` 并重启；构建用托管 Node 22.22.2-6；改 UI 前先截图核对本地实际渲染。

## 计划（待所有者确认）

1. 截图核对当前首屏基线（1440×900 与窄屏）。
2. 首屏重排为「质量速览结论条」：一句客观结论 + 批次命中率主读数 + 漏报批次/误报密度/提前量胶囊 + 现役与运行版本一致性徽标；窗口切换与刷新并入该条。KPI 四格与运维视角三格合并为一条紧凑带，长说明移到「口径说明」。
3. 首屏第二区两列：左 AI 解读（结论 + 建议 + 两个动作），右现役/试用版本与最近触发级漂移摘要；版本不一致告警上移至此。
4. 图表整体下移并 compact 化：混淆矩阵行高、趋势高度、增益曲线画布改为可配置小尺寸；功能全保留，不做删除。
5. 下方保留完整模型版本表与漂移事件表，精简列宽与说明；口径类长文本统一收进可展开区/`title`。
6. 不改 `api.ts`、不改后端、不改指标口径；不新增依赖；本轮不发布。
7. 验证：截图对比、交互回归（刷新/切窗/重训准入/解读/试用-转正-回退确认框/空态错误态）、窄屏、build 与类型检查；收尾清理临时产物并写日志。

## 续作（2026-11-08）：跨屏显示密度自适应

- 用户追问：1080p 屏上「两边间隙小、字大」，2K 笔记本上舒服，为什么、能否统一成图 3 的感觉。
- 核查截图：图 1 是 `www.yancap.top/model-quality` 的 **1900×952 生产旧版**；图 2/图 3 是同一文件（md5 相同）`127.0.0.1:5174/model-quality` 的 **2541×1420 本地新版**。差异 = 页面版本不同 + 屏幕 PPI / 系统缩放不同，不是单纯的屏幕问题。
- 技术原因：全站固定 px + `max-width:1440px` 居中；CSS px 的物理尺寸 = dpr / PPI，1080p 桌面（≈92 PPI）约为 2K 笔记本（≈200 PPI）的两倍；系统缩放 125% 还会把 1080p 的 CSS 视口压到约 1520px，几乎顶满 1440px，居中留白被吃光。
- 已落地（纯渲染）：新增 `lib/density.ts`（按屏幕物理像素宽自动分 compact/standard，DEV 下 `?density=` 可强制对照）；`shell.css` 加流式页边距 + `--content-scale` 仅缩放 `.page-inner`；`AssistantView.vue` 的 `100vh` 高度除以该系数补偿；`main.ts` 挂 `watchDensity()`。窄屏断点不叠加缩放，浮层 Teleport 到 body 不受影响。
- 验证：类型检查与构建通过；同视口 standard/compact 对照截图、自动档、告警表格 sticky、助手页高度补偿、模型质量页切窗点击、窄屏断点均回归正常。
- **仍未发布**：生产站还是旧版，1080p 上要变成图 3 必须先发布新版，本轮没有动生产指针。
