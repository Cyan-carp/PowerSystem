- 必现场取值：controller sha、origin_environment 存在性、21 服务实际镜像与前后 states、新 api 容器 ID/StartedAt、回执四字段、files/private_references 哈希、created/published/accepted 时间、实际命令、history_enabled/队列表。
- 不能克隆：`manifest_sha256`、`release`/`parent`、`published_at`/`updated_at`、`images.api`（不能抄 `38e3ec25…`）、`before`/gate `states`、`source_builds`（不能抄 `d4c1a807…`）、`files` 中 compose/overlay 哈希、`private_references`、`backup_tier`（不能抄 full）、`backup_baseline`、`owner_instruction`、四个 `INBOX_EXPIRY_*` 值。
- 阻塞风险：只更新 overlay 不更新 `private/compose.json`，`status` 可能正常但未来 rollback 会回到旧 api/无 S02；`manifest.services` 写成全部 21 个会让回滚重建全部；`gate.states` 抄父版/截断时间会使 `current_matches` 失败；`manifest_sha256` 两层摘要混用会触发 `active_manifest_changed`；`private_references` 不现算会触发 `private_configuration_changed`；`files` 包含 gate 会自指。
- 已接受但不等于通过：无新备份/无技术门禁/无发布测试，回执应 `gate_executed=false`、`gate_passed=null`、`https_wss_passed=null`、`tests_executed=false`、`new_backup_created=false`；当前生产过期候选 0，启用后短期无新终态不能宣称生产效果已触发；关闭开关只停新写入，已写 `window_expired` 不自动撤销。
- 校验：离线校验器 `python3 -m py_compile` 通过，并用临时合成台账（21 服务、receipt/context、gate/pointer，均在系统临时目录，测后删除）运行 exit 0；未对真实候选目录运行，未跑 DB/长测，未调用生产。本结论可交 Codex 复核并用于现场写台账；不据此签收生产 S02。
