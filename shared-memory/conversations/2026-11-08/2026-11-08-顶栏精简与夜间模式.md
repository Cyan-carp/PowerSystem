## 环境事实与坑（对后续会话有效）

- `qm` 只能在第二跳 PVE `192.168.111.3` 上执行；R730XD `8.138.10.222:7070` 上没有 VM117。
- PowerShell 双引号里带 `\"` 的远端命令，一旦出现 `|` 会被本地解析；**嵌套引号一律改成"本地写脚本 → scp 到 PVE → `ssh PVE 'sh /tmp/x.sh'`"**，脚本内再用 `qm guest exec ... -- /bin/sh -c "..."`。
- `qm guest exec` 的 JSON 里 `"exited": 1` 是布尔标记，退出码看 `exitcode`。
- BuildKit 会把 `FROM sha256:<id>` 当远程仓库拉取（`pull access denied`）；必须先 `docker tag` 出本地 tag 再 `FROM`。
- 手工冻结候选时：`digest = sha256(json.dumps(manifest, sort_keys=True))`；`accepted()` 还会校验 `files` 逐文件字节摘要、`images` 逐个本地存在、`gate['passed']` 与 `gate['manifest_sha256']`。
- 激活参数取 `private/origin-args.json` 再追加 `-f <本批 lock overlay>`，否则会被 `model-balance-20261031-r1` 的 runtime-align 覆盖回旧镜像。
