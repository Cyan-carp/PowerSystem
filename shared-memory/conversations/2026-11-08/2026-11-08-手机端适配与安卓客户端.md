# 2026-11-08 · 手机端适配与安卓客户端

## 目标

所有者要求：给网页做手机端适配，并打包一个安卓安装包，像 Windows 客户端那样在 App 里打开网页。

## 结论与决定

- **适配做在前端，不做第二套页面**：手机端沿用阶段四同一套 Vue 代码，只加壳层断点与页面收紧档；
  App 里不含任何界面代码，网页更新后无需重新发版。
- **手机端导航改为底部四格 + 「更多」抽屉**：9 枚图标平铺在 390px 屏上每枚只剩 43px，
  既难点也认不出；桌面端左侧图标轨保持不变。断点取 900px，与各页面既有 760/900 收紧档衔接。
- **安卓外壳不引 Gradle / 第三方依赖**：用 SDK 自带 aapt2 → javac → d8 → zipalign → apksigner
  直接出包，避免联网拉 Android Gradle Plugin；外壳只有一个 Activity，界面全部由网页提供。
- **服务器地址可配置**：默认生产入口，首次启动先确认，之后长按桌面图标（静态快捷方式）再改；
  连不上时错误页也能改。这样内网/测试环境不必另出一个包。
- **未发布生产**：本轮只改工作区前端并产出 APK，生产 active 指针未动；是否上线待所有者决定。
