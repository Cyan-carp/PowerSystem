# 2026-10-29 · 前端整体覆盖 + 任务记录补齐

## 起因

用户要求：把同级的独立前端 `新能源场站云边协同智能运维平台` 整体覆盖进 `PowerSystem/stages/04-frontend`，
补上「任务记录」，并出一份「新前端比旧前端多了什么、还缺什么」的对照。

同日前一轮已在旧前端做过「报表双页签 + 解读切换器」，这次覆盖会把它替换掉——用户知情并要的就是这个方向。

## 做了什么

### 1. 覆盖（破坏性）

- 备份：`backups/frontend-pre-cover-20261029/`（旧 src 98 文件 + index/vite/tsconfig/package，共 102）
- `src/` 换成新前端 25 个文件；`index.html` / `README.md` / `DESIGN.md` 一并替换
- `vite.config.ts` 保留本项目代理约定（5173 → `VITE_API_TARGET` 默认 8080）；去掉旧配置里按
  `lib/auth|api|realtime` 分块的 rolldown `codeSplitting`（这些模块已不存在）
- `package.json` 依赖收敛为 vue / vue-router / marked / dompurify，移除 element-plus、@element-plus/icons-vue、echarts
- 为旧 tsconfig（`strict` + `noUnusedLocals` + `verbatimModuleSyntax`）修 23 处类型错误：
  缺 `Alarm` 类型导入、`probability/threshold/observed_availability/data_coverage` 可空未收敛、两处未使用导入；
  `timeOf()` 放宽为接受 null

### 2. 任务记录（原 170 行面板 + 完整渲染链）

- EP 替换：`ElMessage` → `toast()`，`ElMessageBox.confirm` → `askConfirm()`（Promise<boolean>），

## 关键事实（写进 PARITY 文档）

1. 新前端 `api.ts` 有 `ackAlarm` / `archiveAlarm`，但**没有页面调用** —— 告警写操作在 UI 上不可达。
2. 新前端无登录、无 token 注入（`token()` 直接返回 `mock-token`）—— 发布到需要鉴权的环境前必须先补。
3. 新前端无 SSE（`/agent/runs/:id/events`）、无动作审批弹窗、无证据卡片与核验。
4. ~~**报表没有后端 CSV 通道**：旧前端 `?format=csv` 属臆造端点~~ → **该判断错误，当晚修正**：
   `stages/02-backend/internal/api/report_export.go` 的 `availabilityCSV` / `timelinessCSV` 就是 `format=csv` 分支，
   返回 `text/csv` 且带场站汇总行，比前端拼当前页更全。已改回后端 CSV（`api.exportReport`），后端失败才退回本地拼。
   误判原因：只读了 `report.go` 的 JSON 分支，没在同包里 grep `format`。
5. 新前端告警解读按第五轮要求由前端模板生成，不调 `/agent/interpretations`，与旧 AI 解读不是同一能力。
