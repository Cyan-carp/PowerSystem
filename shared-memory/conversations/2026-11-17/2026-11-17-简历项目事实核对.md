# 简历项目事实核对

用户请先详细了解 PowerSystem 和大创智慧泳池项目，后续再优化简历。本轮核对本地源码、状态与交付材料，不改简历和项目实现。

## PowerSystem

- Git 历史自 2026-09-27 起。以当前系统状态与分卷为运行口径。四业务场站 140 台合成逆变器，加基线 3 台共 143 台，5 秒采样。200 台 / 30 分钟 / 72,000 条是隔离容量对账，发布、接收、处理、落库四项一致。
- Go 网关经 MQTT QoS 1 / EMQX 接入，SQLite 持久化提交后有序 ACK，TDengine 管理时序数据，Gin / PostgreSQL / Redis / WebSocket 服务控制台。部署运维日志 56 的异常混合输入对照中，正常样本入库由 33/100 到 100/100，修复版同会话离线补传累计 120/120。日志 90 记录另一次故障恢复后 10 分钟处理 72,961 条成功，历史缺口和积压另有记录。
- 可用率查询两组独立窗口。日志 21 的 7 天 / 3 台从 38.204s 到中位 1.007s，使用 TDengine 列裁剪和时间戳游标分页。日志 61 的 7 天 / 143 台从 45.137s 到 2.506–2.640s，使用小时汇总、generation 控制的脏桶重算和边界补算，逐项与原计算一致。
- LangGraph 编排模型和工具，E5 / Qdrant 管理知识检索，SSE 输出带来源答案，PostgreSQL 会话与运行恢复，检查点 / 租约防旧任务覆盖。已开放签批后告警确认与设备备注、定期日报与巡检。传统运维写入与重启未开放，日常自动告警以事实模板为主。
- XGBoost 输出未来 60 分钟风险，工程链包括质量回填、漂移监测、候选重训、试用和热加载回退。基于合成数据，真实场站预测表现未验证。

## 大创智慧泳池

- 校级创新训练一般项目 CXXL2026087，正式周期 2026-06 至 2027-05。正式材料已列项目负责人，写简历前需把本人身份和模块分工对应起来。目录名中的 2025 不作正式立项时间。
- Roboflow drowning-detect v7 两类，Drowning / Swimming。原始三份 results.csv 与汇总表一致。Mamba-YOLO-T 150 轮次实验峰值验证集 mAP@0.5 83.30%、mAP@0.5:0.95 49.76%，对应 Precision 79.98%、Recall 79.33%。100 轮组 81.22% / 47.98%，续训组 80.57% / 44.78%。未发现同一条件的其他检测架构对照。
- SmartPool 打包源码已有 Spring Boot / MyBatis-Plus / MySQL / Redis 后端，FastAPI / OpenCV 推理服务，Vue 3 / TypeScript 控制台。用合成视频及传感数据演示风险评分、告警和处置回溯。源码有 FrameSource 四源、可替换 Detector、MJPEG 最新帧缓冲与按需推理、离线 JSON 生成和前端回放。MJPEG 架构借鉴及适配见提交包说明。
- 独立训练有真实指标与权重，平台演示使用占位检测器，部署环境无 GPU，未确认真实池边实时推理端到端效果。目录有研究报告、代码和实验资料，学校结题验收、论文、软著及奖项无已完成凭证。
