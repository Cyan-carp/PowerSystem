# 2026-10-23 登录页重做：等距城市 + 输电走廊光流

> Workbuddy 会话记忆。仅记录本轮结论与可复核事实；`shared-memory/project-memory.md` 未改动，等待 Codex 复核后再决定是否提炼。

## 需求

用户要求两件事：

1. 登录页做成有科技感的**动态过渡页**，主题与电力相关：城市俯瞰地图 + 几座巨大电力支架 + 支架之间的导线上有蓝白色光段单向流动，每档一段，走到终点后停顿再从头开始。表述留了自由度（"主要以你的想法来"）。
2. 账号密码表单从原来的**右侧栏移到正中**。

## 实现

### 新增 `src/components/PowerGridScene.vue`

纯 SVG 场景，几何全部按视口像素现算（`ResizeObserver` → `size` → `computed`），布局用固定种子伪随机（`mulberry32`），刷新不跳变。

- **等距城市**：`sx = ox + (i-j)·cw`、`sy = oy + (i+j)·ch - height`。街区 4×4 格切 2×2 地块，逐块随机细分成 1~2 栋，保证街廓连续；顶面加 0.8px 细边线读出体积。
- **遮挡与雾化**：按 `(i+j)` 深度分带（每 4 格一带），带之间按深度升序绘制；顶部用线性渐变 mask 把远景吃掉，避免出现菱形边界。
- **网格必须盖住视口**：菱形中心放在 `(w/2, 0.72h)`，边长 `cells = 2·ceil((0.5w/cw + 0.72h/ch)·1.12)+8`。**踩过的坑**：一开始用 `oy = 0.72h - (cells/2)·ch`（漏了 ×2），城市只画出一个小菱形，边界清晰可见。
- **铁塔**：单线桁架（腿 / 横材 / 交叉斜材 / 三层横担 / 绝缘子串），本地坐标 100 单位高。`k = min(h/100, 0.32w/29)` 同时受高宽约束；`baseY = 0.05h + TOP_CLAMP·k`，把最上面一条导线锚在 0.05 屏高，最下面一条的弧底必然落在品牌标题之上。
- **导线**：二次贝塞尔，`control.y = 中点 + 2sag`，`sag = 0.04·档距`；弧长用 40 段折线逼近，用来给光流定速。
- **光流**：`stroke-dasharray` + `stroke-dashoffset` 动画。offset 由 `dash+len` 递减到 `2*dash` 即完成"起点→终点"；`keyframes` 里 dashoffset 用 CSS 变量 `--pg-from/--pg-to` 传入（已验证 Vue scoped 样式里 `var()` 能在 keyframes 中按元素求值）。
- **柔光拖尾**：外层 glow 用更长的 dash（`dash + 2·HALO`）、offset 加 `HALO`。**关键约束**：两个 dasharray 的**图案总长必须相同**（gap 用 `from - halo`，不是 `haloFrom - halo`），否则 modulo 偏移量变化，柔光会跑到亮芯前面而不是两侧包围。
- **窄屏（< 700px）**：铁塔整体推到画外，只留三条导线从头顶横过；通过把塔高放大到 1.25 屏高，让三层横担按比例压到 0.09~0.19 屏高，否则窄幅里两塔横担会互相穿插。

### 改写 `src/views/LoginView.vue` + `styles.css` 第八节

- 品牌（六边形 + 闪电）与表单卡片改为**水平居中竖排**，`margin-top: 14vh` 把内容压到画面中下部，给顶部走廊留出天空带。
- 卡片：16px 圆角、`backdrop-filter: blur(16px)`、顶边一道冷光；输入框 10px 圆角；提交按钮蓝紫渐变 + 悬浮上浮。
- **类名冲突坑**：`.brand-mark` 已被后台侧栏占用（带 `padding: 18px 10px 16px`），登录页同名会把 38px 的 logo 内容盒压成 18×3。已改名为 `.login-mark` / `.login-status` / `.login-field`，全部收敛在 `.login-*` 前缀。
- **Element Plus 2.14 的聚焦态类名在根节点**：`.el-input.is-focus .el-input__wrapper`，不是 wrapper 上的 `.is-focus`。已同时写 `:focus-within` 兜底。

## 第二轮迭代（10-24 00:0x）：铁塔立体化 / 塔数增加 / 去掉光条柔光

用户反馈三点：多几个支架、做成 3D 结构不要全是平面、光条外面不要套一层。改法见 `.workbuddy/memory/2026-10-24.md`。

几个值得记住的几何约束：

1. **一排塔的塔高是被档距反算出来的，不是拍脑袋定的**。横担臂长按塔高 29/100 计，相邻塔中心距必须大于两倍臂长才留得下导线，
   所以四座塔同框时塔高上限 ≈ 间距 × 0.46 / 0.58。想在 1440 宽塞 4 座塔，塔高就只能 ~380px；想更巨就得减塔数。
2. **导线挂点高度受塔顶约束**：塔顶在挂点之上 22.4% 塔高，挂点若压到 0.05 屏高，最上层横担的导线会被画框切掉。
   挂点因此抬到 0.105 屏高（仍高于品牌标题）。
3. **等距铁塔必须有明暗分面**，只画两三条腿 + 斜材，即使几何是立体的，读起来仍是纸片。
   左前脸 / 右前脸 / 正棱 / 背面分四档亮度是最小成本的做法；塔头若不按横担高度补环与斜材，中间会空成一条黑缝。
4. 光条的"外层柔光"是 `stroke-width: 9` + 半透明的第二条 path，删掉后只剩一条圆头亮线，视觉上反而更像电流。

## 第三轮（10-24 00:4x）：地图改真透视、支架沿线路错落

用户第二次否决："支架要错落分布、像真实地图里的线路，而不是排成一排；背景地图要再往里倾斜。"

- 把等距仿射地面换成单点透视：`s = 1/(1+nK)`，`sx = cx + m*cw*s`，`sy = horizon + span*s`。地平线在画面外（-1.2h），
  全屏仍有城市，只是越远越小、街道向远处收敛。**关键性质**：这个映射把地面直线映成屏幕直线，街道可以直接两点连线。
- 塔位不再由间距反算（透视尺度差只有 1.9 倍，算出来五座塔仍然一样大），改成手给屏幕比例 + 塔高 + 空气透视 alpha。
- 结论：品牌块 0.232–0.36h 与卡片顶 0.387h 之间只剩 24px，三根导线（间距 ~50px）过不去，线路中段只能从卡片背后穿过。
  这是这套居中卡布局下唯一的走法，除非把品牌或卡片整体上移。

## 定稿（10-24 09:2x）：A 逆光剪影

前六轮依次是：等距城市+平面铁塔 → 立体四腿桁架 → 真透视地图 → 背景铺满+塔位错落 → 一次接线图 → **逆光剪影**。
用户最终选定 A，理由不是"更好看"，而是前三轮的根本矛盾终于被绕开了。

**这条经验值得留档：在黑底上画深色物体，永远画不出体积。**
城市、铁塔、导线、卡片全落在 `#0a0e14 ~ #2a3548` 这一小段明度里，无论把桁架画得多准、把塔做得多立体，
都只会得到"更清楚的线稿"。A 的做法是把明度关系倒过来——天空最亮（`#2e5279` 地平线）、所有前景纯黑（`#03060b`），
剪影自己就成立，且不需要任何描边、阴影、发光。

另外三条复用结论：
1. 近景逆光塔必须画**构件**（塔腿 4.4px / 横材 2.6px / 横担 3.2px，中间透空），实心轮廓只适合远景剪影——填实会糊成一块黑楔子。
2. 天际线要用连续函数（两条正弦叠加）再补几座高楼；"每段随机高度 + 立面跳变"会变成一排锯齿。
3. 窄屏（<900）放不下低机位巨塔：两塔横担会互相插进对方，必须降级成站在地平线上的中景塔。

代码：`stages/04-frontend/src/components/PowerGridScene.vue`（384 行，纯 SVG + CSS 动画，无第三方依赖），
节奏由 `CYCLE`/`TRAVEL` 两个常量控制（6.4s 一轮、行进 55%、末 2.5s 留白），
`--pg-cycle` 已在根节点绑定，改时长只需改一处（关键帧百分比仍需手动同步）。
