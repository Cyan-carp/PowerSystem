## 关键事实（决定能做什么的硬边界）

1. 前端**无任何** settings/preference 路由、视图、组件；`src/lib/icons.ts:15` 已有 settings 图标但无引用；路由表内联在 `src/main.ts:18-40`（12 条命名路由）。
2. 唯一已持久化的用户偏好是 `powersystem.theme`（`src/lib/theme.ts`），由顶栏按钮切换。**没有统一偏好存储封装**；`sessionStorage` 由各视图直接读写（`AssistantView.vue`、`SchedulesView.vue`）。
3. 后端**没有任何**用户偏好表、迁移、jsonb 列、kv 表、Redis 偏好键、`/config` 或 `/preferences` 端点，也没有用户资料更新端点。`users` 表仅 7 个标量列。唯一「每用户可写状态」是 `agent_interpretation_reads`（解读已读）。生产 R0 只读、运维写窗口关闭。
4. 后端常量固定了时区（Asia/Shanghai）、单位（kW/kWh/℃/V/A）、告警阈值、健康五档、预测 1h 窗口、报表 31 天上限、遥测历史 24h 上限、模型质量 30 天默认、`page_size ≤ 100`。前端若让用户改这些，会造成口径不一致或请求被拒。
5. 服务端的全部开关（AI_ENABLED、INBOX_EXPIRY_ENABLED、V4_* 档位等）都是运维/部署性质，前端读不到，不能当设置项。
6. 已明确否决、不得作为设置项：跨屏密度档位（11-08 所有者否决「健康/关注/异常」主观档位，且专题写明「生产始终自动，不留可改开关」）、整站深色（DESIGN.md:29 记载被否决两次）、模型 Key/模型切换（ModelPanel.vue:9-11 注明刻意不做，Key 是 docker secret、网页保存无法热生效）。注意：11-08 上线的**夜间模式**是既有的顶栏按钮，不等于被否决的「整站深色」。
7. 前端硬编码可抽取点：分页 `8/8/10/8/12/10`（告警/设备/健康/预测/报表/模型质量）；总览默认 24h、设备详情 1h、模型质量 30 天；Toast 统一 3600ms；顶栏 60s、余额 10min；`alarm-notices.ts` 硬编码级别 urgent/major/minor、最多 5 条、新鲜度 30s~120s 且**无用户开关**；桌面端 `desktop.ts` 的 `Preferences { notificationsEnabled, launchAtLogin }` 已定义但无 UI 调用；`PARITY:73` 记录「无告警提示音，需用户手势授权」。
8. 既有架构约束：筛选条件写进 URL（PARITY:58「URL 即状态」）；`auth.ts:75-76` 退出登录只删 token/user、保留 username；`AssistantView.vue:84` 的会话 key 已按 `user.id` 隔离。

## 分层建议（本轮结论）

- **第一梯队（纯前端 localStorage，零后端、零口径风险）**：① 通知与提醒（总开关、按级别过滤、同屏条数、提示音、接上桌面端 notificationsEnabled）② 默认落地页与默认设备范围 ③ 列表每页条数（统一，且 ≤100）④ 默认时间范围（各页记忆上次选择，不越后端上限）⑤ 自动刷新开关与间隔。
- **需先定规则**：主题三态（跟随系统/固定白天/固定夜间，`theme.ts` 现为刻意不跟随系统）、快捷键一览（纯展示）、记住导出偏好（不得合并两个导出按钮）。
- **明确排除**：跨屏密度档位、整站深色、时区/单位/阈值/预测窗口、账号级云同步偏好（要迁移 + 用户写接口，与 R0 只读冲突）、模型 Key 与模型切换。

## 必须先做的一件事

先抽 `src/lib/prefs.ts`：统一 schema、缺省值、版本号、按 `user.id` 隔离、读写降级（存储不可用时仅本次生效）、越界回落。否则 8~10 个设置项会散成 8~10 个 key 与 8~10 套 try/catch。

## 主要风险（先讲哪里会坏）

1. **账号串偏好**：退出登录不清偏好 + 不按用户隔离 → A 账号关掉告警提醒，B 账号登录也静音。
2. **URL 与默认值冲突**：筛选写进地址栏，若设置默认值覆盖 URL 显式参数，分享出去的链接会失效。应定「URL 显式参数优先，设置只作缺省」。
3. **越界值**：设置值必须夹在后端上限内，否则请求 4xx 或页面空白。
4. **自动刷新与分页交互**：PARITY:302 明确「健康页要加 10 秒自动刷新得先想清楚和筛选 + 分页的交互」，刷新会重置页码/让正在看的行跳走。
5. **默认值与硬编码不一致**：总览功率曲线写死 `scope:'baseline'` 且取 3 台，若设置里默认范围改成「业务设备」，会出现「设置说业务、曲线是基线」的口径矛盾；要么不碰该曲线，要么明确标注。
6. 告警音需浏览器用户手势授权，设置页「开启」点击需实际播放一次验证，不能只存个标记。
7. 入口须同时覆盖 `App.vue` 的 user-pop（`:402-425`）、图标轨/顶栏（settings 图标现成）、手机端 `msheet-grid`（`:483-503`），否则手机端进不去。
