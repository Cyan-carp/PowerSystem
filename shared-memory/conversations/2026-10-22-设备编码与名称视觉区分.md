# 设备编码与名称视觉区分（2026-10-22）

## 需求

用户反馈「设备管理和统计报表里面的设备名词很没有区分度，看着高度相似，想办法在视觉上做出一定的区分度」。

## 问题定位

实测数据（生产 Postgres 实查 + `stages/01-data-chain/simulator/fleet.json`）：同一场站 143 台设备里

- 编码 `PV-01-INV-01`…`48`：前 8 个字符完全相同，只有末 2 位序号不同
- 名称 `示范园区 A 屋顶光伏片区 01号逆变器`：前缀同样全同

扫读时每行都是同一串字符，缺少锚点。

## 方案：弱化常量，强调变量

1. **编码分段**：`PV-01-INV`（弱化灰 12px）+ `01`（等宽 13.5px、加粗、亮色），扫读只读末尾数字。
2. **场站色点**：每行前置 6px 圆点，按 `station_code` 稳定映射 5 色（蓝/青/紫/橙棕/灰蓝，低饱和且避让红黄绿状态色）。颜色只承载场站、不承载状态。
3. **名称列同构**：`示范园区 A 屋顶光伏片区`（弱化）+ `01`（强调）+ `号逆变器`（弱化）。
4. **三个长列表加 `stripe`**：设备列表、健康排行设备表、报表设备可用率表。

关键细节：色点取台账的 `station_code` 字段，不从编码文本推断——否则 `INV-M4-AI-…` 这类历史设备会算出与所在场站不符的颜色。

## 改动文件

| 文件 | 作用 |
|---|---|
| `src/lib/device-code.ts` + `.test.ts` | 编码分段、名称分段、场站色映射（新增 8 项单测） |
| `src/components/DeviceCode.vue` / `StationCode.vue` / `DeviceName.vue` | 三个渲染组件 |
| `src/styles.css` | `:root` 新增 `--st-0`、`--st-t1..t5` 与 `.dev-*` 分段样式 |

场站色用哈希（hash×33 % 5）而非硬编码映射表，实测 PV-01/02/03/04 + ST-01 恰好各得一色；新场站自动分色，无需维护清单。

## 发布中值得记住的坑

1. **记忆里的生产指针早已过时**（以为是 1019，实际是当天 1222 版本）——发布前必须现查 `production-stack.py status`。
2. **md5 全量比对会把换行符差异报成内容漂移**：本机 `core.autocrlf=true` 检出 CRLF，服务器是 LF，84 个文件报 24 处差异，全是假的。判内容要用 `tr -d '\r'` 后 diff。
3. **公网 HTML 里看不到分块引用关系**：改为 `docker exec` 进 frontend 容器 grep `/usr/share/nginx/html/assets` 更可靠。
4. **Vite 会把小组件合并进其他分块**：按 `DeviceCode-*.js` 找会 0 命中，实际被并进 `StationCode-*.js`，DeviceName 则内联进 DevicesView 分块。
