# 2026-10-22 前端健康排行与统计报表分页优化（Workbuddy 执行记录）

## 任务

用户反馈「健康排行」和「统计报表」两个界面一次性展示全部数据、页面过长，要求改为分页展示。

## 关键决定

- **采用前端分页，不改后端接口。** `/api/v1/health/devices` 与 `/api/v1/reports/availability` 均一次性返回完整结果集，无分页参数；设备规模 140 台，客户端切片成本可忽略。
- **新增公共分页工具 `src/lib/paged.ts`**（配套 `paged.test.ts`）：`usePaged(source, defaultSize)` 返回 `page / pageSize / total / pageCount / rows / reset`，内部 watch `pageCount` 在数据缩短时回退页码，避免刷新后出现空白页。
- **仅对长列表分页**：健康排行设备表、报表设备可用率表。场站排行（4 行）、场站可用率（4 行）、告警处理时效（4 行）保持全量。
- **未采用 Tabs 拆分统计报表三个结果区**。理由是 Tabs 会隐藏信息、增加对比成本，超出「分页」这一明确诉求；已作为可选后续在结果中提出。
- 健康排行页顺带增加场站下拉 + 设备编号/名称关键字筛选（140 台设备下定位成本高），筛选变化时页码重置。
