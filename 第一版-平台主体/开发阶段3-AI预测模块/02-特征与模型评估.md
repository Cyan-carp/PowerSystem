# 02 · 特征与模型评估

> 对应路线图第 9–10 周和手册任务 16；模型评估以运行目录中的 JSON 原始结果为准。

## 一、因果特征

每个特征窗口覆盖过去 30 分钟，按每分钟一个桶选取该分钟最后一条遥测；离线样本窗口每 5 分钟滑动一次。30 个桶中至少 27 个有值，窗口结束分钟必须有值，且相邻两个有值的分钟桶间隔不超过 2 分钟（中间最多缺 1 个桶）。输入仅含电压、电流、温度、功率在窗口结束前的值；提取末值、均值、标准差、变化率及温度连续上升次数。温度减去功率相关项的残差帮助区分自然升温与异常升温。`status`、`fault_code` 和未来事件时间不进入模型。

## 二、切分与阈值

- 按自然日期先后切分 60% 训练、20% 验证、20% 测试；同一天的设备窗口不会跨集合。
- 只在验证集比较三组树深度、学习率和轮数，拟合单调逻辑概率校准并选择告警阈值，再冻结模型、校准和阈值去测最终测试集。
- 特征贡献解释树模型原始分数；对外概率使用验证集校准后的数值。
- 报告完整混淆矩阵、召回率、精确率、F1、准确率与误报率。

## 三、当前合成结果

21 天、3 台设备生成 90,720 条遥测与 63 次故障事件。测试集 4,125 个窗口、180 个正样本；当前基线阈值 0.350。

| 指标 | 数值 |
| --- | --- |
| TN / FP / FN / TP | 3941 / 4 / 14 / 166 |
| 召回率 | 约 0.922 |
| 精确率 | 约 0.976 |
| 误报率 | 约 0.0010 |

该结果仅适用于同一合成机理的晚期日期，不代表真实场站表现。完整参数与每次试验见 `artifacts/stage3-AI预测/model/evaluation.json`。

三组试验的选型、误报代价口径与测试窗全局特征贡献排序见 [[07-阶段三总结]]；公开场站字段与标签边界见 [[08-公开数据审计]]。

> 已预训练的 [Chronos-Bolt Tiny](https://huggingface.co/amazon/chronos-bolt-tiny)预测未来时序数值，不能直接代替“未来一小时故障概率”分类器。它只作为后续可选对照。
