# 05 · 智能体接口设计

> 回答阶段三与智能体的关系；本阶段只设计读取、解释和演示接口，不启动自动处置。

## 一、职责

- 预测模型计算未来一小时概率和特征依据。
- 诊断智能体把这些结构化结果与历史曲线、告警关联起来，向值班员说明可能原因及建议的人工检查步骤。
- 概率由模型给出，智能体不得自行改写或伪称验证过真实故障。

## 二、只读工具

| 工具 | 输入 | 输出 |
| --- | --- | --- |
| `get_prediction` | 设备 ID | 概率、阈值、窗口时间、依据、过期状态 |
| `get_telemetry` | 设备、指标、起止时间 | 原有历史曲线 |
| `list_alarms` | 设备、状态 | 当前及历史告警 |

约束：

- 所有工具经 Go 后端 JWT 与设备可见性约束调用，回答中展示数据时间与模型来源。
- 数据不足、结果过期或模型不可用时说明无法判断。
- 未来如接入大语言模型，需对建议与引用证据进行人工核查；自动建工单和远程控制不属于阶段三。
