# 开发阶段3 · AI预测模块索引

> 对应《企业级项目完整落地实战手册》任务 16 与路线图第 9–12 周；源码与命令见 [[stages/03-ai-prediction/README.md]]。

## 一、目标与状态

本阶段目标是预测设备在未来一小时内的首次故障风险，并给出可解释依据。阶段二 M2 已通过；原模拟器只输出“前兆激活”标记且故障码始终为 0，因此本阶段另建有明确故障起点的离线合成数据。2026-09-28 的 M3 入库、告警、WebSocket、恢复及重启去重联调已通过；真实公开数据尚未提供，外部验证等待下载后核对。

| 交付物 | 当前落点 |
| --- | --- |
| 多天合成数据与事件账本 | `artifacts/stage3/synthetic/`，不入库 |
| 训练、评估、服务 | `stages/03-ai-prediction/` |
| 后端查询与告警 | `stages/02-backend/` 增量实现 |
| 模型报告 | `artifacts/stage3/model/`，本目录保留结论 |
