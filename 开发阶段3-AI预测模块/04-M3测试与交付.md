# 04 · M3测试与交付

> 对应路线图第 12 周；区分已执行的离线检查和需要运行全链路才能确认的 M3 验收。

## 一、已执行

| 项 | 当前结果 |
| --- | --- |
| 合成数据 | 21 天、90,720 条遥测、63 次故障事件 |
| 时间测试集 | 4,125 个窗口；TN 3941、FP 4、FN 14、TP 166 |
| 模型指标 | 召回率 0.922、误报率 0.0010，限定于合成数据 |
| Python 单元测试 | 因果窗口、缺失窗口、事件标签通过 |
| Go 测试 | `go test ./...` 通过，包括时间戳解析 |
| FastAPI 烟测 | 本机 HTTP 健康检查、故障前推理与不完整窗口拒绝通过 |

## 二、尚待全链路验收

当前执行环境没有可用的 Docker、EMQX、TDengine、PostgreSQL 与 Redis 进程，故不能标记完整 M3 通过。待环境可用时按源码 README 启动预测服务与阶段二链路，通过 `prediction.replay` 在故障前补入 30 分钟前兆，记录预测入库、JWT 查询、告警生成及 WebSocket 推送时间；随后发送故障点、验证恢复与重复窗口去重。验收证据放 `artifacts/stage3/<运行编号>/`，不得上传公开仓库。

公开数据未交付，独立外部验证未执行。合成结果不得当作外部验证成绩。
