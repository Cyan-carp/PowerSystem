### 根域名配置与维护

- `cyancarp.cn` A=`8.138.42.212`、TTL 600；公共解析查询无 AAAA。主机记录为 `@`，`www` 记录继续保留。
- 新云 `/etc/nginx/sites-enabled/powersystem-apex.conf` 指向 `sites-available` 同名文件。80 的 ACME challenge 路径保留给续期，其他 HTTP 请求及所有 HTTPS 路径均 301 到带 `www` 的固定地址。
- 独立证书位于 `/etc/letsencrypt/live/cyancarp.cn/`，本次到期为 **2027-01-15 07:35:02（北京时间）**；现有 timer 已覆盖 IP、www、裸域名三张证书。裸域名单独续期演练及与 timer 相同的 deploy hook 均通过。
- 根域名不单独承载业务页面；跳转后使用现有 `www` 的登录会话和备案页脚。启用前后 IP 及 www 站点配置摘要一致。回退根域名时，仅移出 apex 站点链接，`nginx -t` 通过后 reload，保留已有 www/IP 配置及证书。

## 备案前：只准备，不开站

- 从阿里云 DNS 控制台和可信公共解析器记录 `www.cyancarp.cn` A=`8.138.42.212`、AAAA、TTL。若 AAAA 指向其他服务器，先修正；本轮不处理根域名。
- 在新云保存两个 `.disabled` 模板，但不要把它们链接到 Nginx 的 `sites-enabled`。`nginx -T` 应只有 IP 站点；对 `Host: www.cyancarp.cn` 的 HTTP/HTTPS 请求不得返回业务页面/API。
- 80 端口保留 IP 证书 HTTP-01；不能因为域名已有解析就提前申请域名证书并开通站点。中国内地未备案网站可能被接入商阻断，首次备案成功前不应开放访问；见[阿里云备案 FAQ](https://help.aliyun.com/zh/dns/pubz-filing-domain-name-related-faq)。

## 备案完成后：一次受控启用

1. 由所有者出示备案成功结果，核对备案主体、`www.cyancarp.cn` 所属域名、实际接入商、新云实例地域和**真实备案号**；记录核对时间。未满足则继续禁用。
2. 核对公开 A/AAAA 正确、80/443 从公网可达、IP 站点和旧入口仍健康。将 `domain-http-bootstrap.conf.disabled` 复制为新云 `sites-enabled/powersystem-domain-bootstrap.conf`，执行 `nginx -t && systemctl reload nginx`；该临时站只服务 ACME challenge，其他请求返回 421。
3. 用 `/opt/powersystem-edge/certbot-venv/bin/certbot certonly --webroot -w /var/www/powersystem-acme -d www.cyancarp.cn` 申请正式域名证书，HTTP-01 必须从公网访问 80。先可用 `--staging` 演练；正式命令不可带 `--staging`。核对证书 SAN、链和到期日。参考 [Let's Encrypt HTTP-01](https://letsencrypt.org/docs/challenge-types/)。
4. 在新云的 `/etc/nginx/powersystem-icp-footer.conf` **只写实际备案号**，内容格式为 `sub_filter '</body>' '<footer class="icp-footer"><a href="https://beian.miit.gov.cn/" target="_blank" rel="noopener noreferrer">实际取得的备案号</a></footer></body>';`。文件由 root 管理。备案号不得用示例或占位值；`nginx -V` 须确认 `http_sub_module`。代理层只对 HTML 的 `</body>` 做一次替换，R730xd 业务容器不改。
5. 移除临时 domain bootstrap，复制 `domain-after-filing.conf.disabled` 为启用站点，执行 `nginx -t && systemctl reload nginx`。核对 80→443、TLS 完整链、HTML 底部备案号和工信部查询链接；页面登录、总览、设备、告警、预测、智能体问答及 WSS 均复测。源站返回压缩 HTML 时，Nginx 已请求未压缩响应以确保替换；若版本构建不含 sub 模块或响应不含 `</body>`，**停止域名启用并修复展示**，不得将占位号上线。
6. 续期覆盖 IP 与域名两张证书；执行 `/opt/powersystem-edge/certbot-venv/bin/certbot renew --dry-run`，检查 `systemctl list-timers`、deploy hook reload 和证书剩余有效期。IP 证书六天，监控阈值要早于过期。若备案号变化，先变更备案资料，之后更新 footer 并重验。

域名入口与 IP 入口会话不共用；用户切换时重新登录。故障时用户手动访问旧云 `https://8.138.10.222/`；本轮不做自动 DNS 故障切换。
