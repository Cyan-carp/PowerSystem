# 运行产物说明

> 运行状态只认 [[00-当前系统状态]]。本目录登记产物用途、来源、保留与清理，不复制源码、秘密或原始载荷；实际文件仍在Vault外。

## 阅读与保留

日志、构建、合成夹具、来源回执和失败记录按阶段/批次定位；缓存数量会变，不把目录枚举数当运行基线。到期先核归属、引用与所有者决定，不清生产卷、正式冻结候选或仍需恢复的资产。创建产物不等于测试通过，历史记录不覆盖当前状态。

**新增批次必须在本目录对应分卷登记**（批次目录 → 一句话用途 → 结论指针），未登记的不算交付完成。`artifacts/` 顶层收纳规则、命名标准与清理记录见同一目录下的 `artifacts/README.md`；`artifacts/` 被 Git 忽略，不进仓库。
