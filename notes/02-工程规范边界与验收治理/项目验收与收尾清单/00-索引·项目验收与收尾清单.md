# 项目验收与收尾清单

> 本目录保存任务判定与正式来源；实时生产状态唯一见 [[00-当前系统状态]]。

## 一、判定与维护规则

- `[x]` 表示该任务已实现，并在对应阶段声明的环境和边界内完成测试或验收。
- `[ ]` 表示当前仍未完成；未完成项不得因旧批次、单次 HTTP 成功、合成样例或其他阶段结果而记为通过。
- 本项目当前仍是合成演示和受控运维环境。合成预测、公开资料问答及固定安全样例不能外推为真实场站效果或专业操作结论。
- 阶段命令只在对应 `stages/<阶段>/README.md` 维护；本页只保存状态、边界和正式交付入口。
- 本页不保留“当时未启动、后来已完成”的未勾选历史项。旧事实需要追溯时，进入对应阶段正式交付页和问题记录页。
- 每组现行未完成项、每条拓展项和每条暂缓完善项均标注提出该任务的源笔记；源码实现入口仍以本节所列阶段目录为准。
