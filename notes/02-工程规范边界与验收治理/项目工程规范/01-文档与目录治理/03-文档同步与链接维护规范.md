# 文档同步与链接维护规范

目的：变更后同步入口、状态与引用，避免笔记打开了却找不到现行事实。

## 变更记录与文档同步（2026-10-28）

> 日常修复不再逐页回写；只有改变运行口径、对外契约或资产归属的事实才扩散。所有者本轮要求的一次性全量同步，不构成对每次 Bug 的固定义务。变更按“日常本地／兼容普通发布／高风险变更”三档管理，判定标准与验证深度见 [[02-工程规范边界与验收治理/项目工程规范/03-协作联调与验收/00-索引·协作联调与验收|阶段联调与智能体长期约定]] 第五章。

### 6.1 文档同步最小集

| 变化 | 必写 |
| --- | --- |
| 日常修复、单次排障 | 一份变更记录（部署日志对应分组） |
| 生产指针、运行版本、阶段状态、已知限制 | [[00-当前系统状态]] 的入口摘要 + `06-当前系统状态/` 对应分卷（两者同批改） |
| 接口、命令、参数、用法 | 对应手册或源码 README |
| 证据、模型、外部数据、目录归属 | [[02-工程规范边界与验收治理/运行产物说明/00-索引·运行产物说明]]、测试资产台账 |
| 阶段里程碑 | 四件套（方案、测试与交付、问题记录、交接）＋八项交接＋索引 |

- 日常修复不回写根 `README.md`、验收清单、全部手册与阶段索引；这些入口只在对外口径、阶段状态或用法改变时更新。
- 四件套与八项交接是**阶段里程碑口径**，不扩展到每次 Bug、补丁或单次排障。
- 移动、改名、合并仍执行第四章全链同步；一次性处置升级为长期条款须先按第一章取得确认。
