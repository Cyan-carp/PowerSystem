## 原因与授权

所有者截图显示“分析漂移”返回 `AI 解读暂不可用：llm key unavailable`。代码在实际调用模型前从 `QUALITY_LLM_KEY_FILE` 读取凭据；生产 API 未显式配置该变量，默认 `/run/secrets/quality_llm_key` 在原容器中不存在。页面旧解读仍是历史记录，余额来自另一条服务通道，不代表 API 已得到凭据。所有者本轮明确选择“授权本轮修复并发布”。
