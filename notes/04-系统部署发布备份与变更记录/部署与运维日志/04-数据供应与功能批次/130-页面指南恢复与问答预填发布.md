## 一、本批改了什么

| 行为 | 129 批次 | 本批 |
| --- | --- | --- |
| 顶栏帮助按钮 | 固定标题「数据说明」，内容是「接本地假后端、演示数据、北京时间」四行 | 按 `route.name` 取页面指南：标题为页面全名，正文分「用途 / 编号步骤 / 注意」三段 |
| 覆盖范围 | 全局一份 | 12 个视图各一份（总览、告警、设备、设备详情、健康、预测、模型质量、报表、任务、助手、关于、账号），登录页无顶栏不涉及 |
| 底部动作 | 无 | 「问助手」带 `?question=` 跳 `/assistant`，只预填输入框，**不自动发送**（发送要花一次模型额度） |
| 助手页 | 不读 `route.query.question` | 新增 `watch` 命中即填入草稿并聚焦输入框；同页重复点也生效 |

实现要点：

- 新增 `src/lib/page-guide.ts`：`PageGuide { title, purpose, steps, notes, question? }`，`guides` 按路由名索引，`guideVersion='BND-M3'`。写作口径只覆盖代码里真实存在的操作，notes 每条都能对到一处实现或契约。
- `App.vue` 顶栏弹层改为渲染 `guides[route.name]`；按钮 `title` 变为「页面指南：<页面名>」，路由切换时原有 `watch(route.path)` 已负责关闭弹层。
- `AssistantView.vue` 新增 `useRoute` + `watch(() => route.query.question, …, { immediate: true })`，只填 `draft` 并 `nextTick` 聚焦。
- 弹层宽度 320 → 368px；正文 `max-height: calc(100vh - 150px)` 内部滚动，避免矮窗口把最后一行切成半行；注意段用 `--warn-soft` 底 + 「注意」小标，与步骤区分开。
- **`.guide-pop` 关掉了 `pop-in` 淡入**：该弹层实测会长期停在动画首帧（整块半透明，底下表格文字透上来），同一位置的铃铛弹层不受影响；淡入仅 140ms，去掉不损失信息。
- `PARITY-20261029.md` 第 10 条同步改为「页面指南已恢复（弹层形态）」，推挤式检视栏与告警音仍未做。
