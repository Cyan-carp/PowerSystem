# IR-S02 过期收尾手工激活（97）

> 生产当前事实只认 [[00-当前系统状态]]。本批承接 [[96-入库积压放弃与先进先出发布]] 的先进先出与 7 天窗，**只**启用 IR-S02 过期终态出口；S03/S04 未上线。所有者本轮原话：「不用备份和门禁，能过就行，不会回退」。本记录把已做和未做分开，不把所有者接受写成技术门禁通过。

## 一、为什么做、做了什么

96 批次的 7 天窗让旧样本不再挡住正常队伍，但旧样本仍可能永远显示“待处理”。本批为它加一个出口：超过 7 天且仍 `processed_at IS NULL` 的行，由独立 worker 每 30 秒最多取 2,000 行，在 5 秒预算内把**原行**登记成 `quarantined/window_expired`；不删行、不改 payload，也不碰 `owner_abandoned`。生产候选在启用前为 **0 行**，所以本批只能验证程序开启并自然运行，尚不能宣称“生产已有过期件实际转终态”。

只换 API 镜像，并给 API 加 `INBOX_EXPIRY_ENABLED=true`、`INBOX_EXPIRY_INTERVAL_SECONDS=30`、`INBOX_EXPIRY_BATCH=2000`、`INBOX_EXPIRY_BUDGET_SECONDS=5`。不建 021 索引、不改前端、网关、TDengine、`energy_daily` 历史或其他服务。关闭开关只阻止后续标记，已写终态不会自动撤销；本批未执行应用回退。
