# 57 · 开发阶段运行错误与功能定位清单

> **版本归属**：跨版本开发运维，2026-10-29建立。供所有者在真实服务器遇到问题时定位功能和提交证据；可能性不表示错误已经发生。当前已发生与未解决事项只认 [[00-当前系统状态]]，本轮原始结论见 [[56-遥测供数能源与历史积压接续处理]]。

## 一、使用方式

取消两小时及后续AI驻守长时间稳定性测试，真实服务器自然运行，发生实际问题再修。需要短观察时由本人运行脚本并交回日志；正式规则见 [[02-工程规范边界与验收治理/项目工程规范/03-阶段联调与智能体长期约定]] 第五章。

记录下面最小信息即可，不必为了报错重跑全套测试：

- 出现时间与时区、网页路径/功能、操作步骤、预期与实际现象。
- 是否全部设备/单台设备、一直失败/偶发；可附截图，隐去账号与私人内容。
- 若有观察文件，提供 `summary.json` 和 `samples.jsonl`；它们是投影证据，不含口令、token或完整业务载荷。
- 不提供私钥、环境文件、登录口令、未脱敏容器完整日志或浏览器存储。

## 二、供数、实时与历史

| 看到的现象或事件 | 对应功能与优先定位 | 影响与边界 |
| --- | --- | --- |
| 显示已连接/有订阅，TD最新时间不动 | MQTT Broker投递→网关收件/SQLite→TD；比对投递、提交序号与TD实际样本 | 连接状态不能证明供数。Broker确认/重放错误本轮已见，见56 |
| `out-of-order_commit`、`puback_packetId_not_found` | MQTT确认顺序或会话确认状态 | 可能堵住窗口；不能清会话/队列掩盖，保留现场并定向处理 |
| `emqx_persistent_session_ds_replay_inconsistency` | Broker持久会话重放 | 本轮已见；可能涉及历史重放状态，不自动升级Broker或删除旧会话 |
| 网关待写行增长、`tdengine_batch_deferred` | 设备映射、TD连接/建表/插入或写入负荷 | 已持久收件不等于TD成功；未确认组保留重试 |
| 设备未知/离线、`/ready`返回503 | 样本时间、新鲜度、恢复初始化或PG/Redis/TD依赖 | 先看实际最新时间与探针年龄，不改时间或降低新鲜度门槛 |
| 网页更新停住，刷新后才变 | API广播、ticket/WSS、反向代理或慢客户端 | 区分TD已经推进和仅网页不动，按受影响WSS短核查 |
| 历史成功不动、队首`td_missing` | TD缺样、每设备顺序处理/重试 | 不能把队列减少直接当业务成功，隔离数增加也会减队列 |
| 某设备长期不推进、其他设备推进 | 该设备队首原因、公平调度、重试时间或索引计划 | 比对逐设备ID/尝试次数；保留缺样/隔离原行，不统一改成功 |
| 队列查询慢、CPU升高 | PG统计、pending设备索引、TD负荷 | 本轮已见旧统计导致退化；按实际计划核查，不默认扩超时/并发 |

## 三、电量与报表

| 看到的现象或事件 | 对应功能与优先定位 | 影响与边界 |
| --- | --- | --- |
| `energy_rebuild_failed`连续发生 | dirty日期调度、PG设备日期切片查询与聚合提交 | 核对dirty最早时间、日期/设备及daily更新时间；3秒预算不靠扩大解决 |
| 待重建数量一直不为0 | 持续新样本使同日反复变脏，或实际处理停滞 | 看最早dirty年龄与逐日落表推进，单看数量不能判断卡死 |
| 电量标“暂定/不完整” | 来源含旧未知/待处理/隔离记录、缺样或覆盖不足 | 可能是正确质量提示；先看覆盖与缺口，不把旧值签完整 |
| 日电量与曲线不一致 | 日期时区、跨日插值、重复时间、迟到样本/重建进度 | 保留UTC原时间与北京时间日期口径，超过15秒缺口不外推积分 |
| 今天有值、旧日仍未知 | 历史来源质量与单独回补范围 | 旧聚合保留；历史回补还是保留缺口由本人另定，不自动抹平 |

## 四、助手、告警、发布与备份

| 现象 | 对应功能 | 处置线索/正常边界 |
| --- | --- | --- |
| 助手超时/无答复 | 各角色模型通道、网络与任务执行 | 提供任务时间/脱敏ID，按对应角色查；不重跑全部模型矩阵 |
| 告警没有外发通知 | 业务投递表、既有飞书适配或TR规则路由 | TR空receiver不承诺通知；不把未开放路由当已开放能力故障 |
| 定期任务没执行/没交付 | S08有效授权、暂停/取消、时槽与本人站内交付 | 取消/无grant不执行可能正确；恢复须重批，不代建授权 |
| 动作提示过期/拒绝，S07重启不能用 | S06审批绑定、权限或关闭的运维写能力 | 先核当前状态；权限关闭不因本轮修复而开放 |
| 上传/发布报pending或基线漂移 | 发布事务、运行身份、定时备份停复回执 | 不删标记重试。只补必要事务缺口，不先扩建发布平台 |
| 备份很慢或异地上传失败 | 队列一致快照、PG导出、压缩、双端传输 | 分段计时定位；失败不能记成功，不清原始数据来加速 |
| 页面502/登录失败，内部服务正常 | 公网代理、FRP、TLS、鉴权或会话 | 按具体入口短测，不因单入口错误重跑全平台稳定性 |
