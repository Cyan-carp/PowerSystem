# 71 · 表格分页快捷跳转与左右栏对齐发布

> 本页记录五处表格分页的统一改造、健康排行页左右两栏等高，以及所有者「直接发布、绕过门禁、不备份不测试」的本批发布。当前状态见 [[00-当前系统状态]]。

## 一、两处界面问题

截图给的是健康排行页（`/health`）：左栏「设备排名」卡片比右栏三张卡短一截，底边停在分页条上，右栏「计算口径」还多出一段——两列看起来没有收在同一条水平线上。另外每页只看 8 条、共 18 页，翻页只有「上一页 / 下一页」两个箭头，要去最后一页得点十七次。

两个改动的边界都是纯前端展示，不碰接口、不碰数据：

- **左右等高**：`.hl-grid` 的 `align-items` 由 `start` 改 `stretch`，左卡片变成纵向 flex 容器，分页条 `margin-top: auto` 沉底。这样左卡片高度由右栏决定，底边自动压在同一行，表格上方内容仍按原顺序排。
- **分页快捷跳转**：新增 `components/Pager.vue`，所有表格共用。结构是「上一页 · 页码块 · 下一页 · 右侧统计与跳转框」；页码块在 7 页以内全列，超过则固定首末页、当前页左右各一页，其余折叠成省略号，任意一页最多两次点击可达；右侧另有一个页码输入框，回车或失焦即跳，越界自动夹到 1 与总页数之间。

替换的五处：告警中心、设备台账、健康排行、故障预测、报表「设备可用率」。前四处原来各自手写箭头 + 当前页数字，第五处同样。改造后口径统一，右侧统计文字（`显示 1–8 / 143 台`、`每页 8 台`、`竖线为阈值 35%`、`覆盖率低于 90% 记为数据不足`）由 `note` / `total` / `pageSize` 三个 prop 传入，不再各页自己拼。

`ReportsView` 另有两处 `.pager` 只是脚注条（「计算于…」「事件 N 条」），不含翻页，保持原样。

## 七、两条可复用的操作教训

- **`--from-args` 是受管文件**：`prepare` 用 `owned()` 校验路径，`/tmp` 下的文件一律 `owned_file_required`，必须放进 `/opt/powersystem/runtime/<批次>/`。
- **不要在 ssh 一行命令里 `pkill -f '<含本命令的字符串>'`**：`pkill -f 'http.server 18099'` 会匹配到承载它的那条 ssh 命令行，把会话连同后续 `rm` 一起杀掉，表现为「清理命令没有输出也没有生效」。改用 `ss -ltnp` 取 pid 后 `kill <pid>`，或把模式写成不落在命令行里的形式。
