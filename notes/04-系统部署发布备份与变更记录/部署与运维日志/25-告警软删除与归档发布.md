# 25 · 告警软删除与归档发布

2026-10-20 11:14:15（北京时间），生产指针切换到 `alarm-archive-20261020-r1`，直接父版本为 `bnd-answer-release-20261020-r2`。本次只更新 API 与前端，其他业务服务保持原镜像；发布事务完成后 `pending=false`。

后端在 `alarm_records` 新增非空布尔字段 `archived`，默认为 `false`；`008_alarm_archive.sql` 幂等迁移随 API 启动自动执行，并建立未归档记录的部分索引。新接口 `POST /api/v1/alarms/:id/archive` 只更新归档标记，不删除告警事实、确认时间、恢复时间或规则快照。`GET /api/v1/alarms` 默认过滤 `archived=true` 记录，因此告警中心与复用该列表的首页不再展示已归档告警。

前端告警表格与告警详情都新增「归档」入口，操作前明确提示「从默认列表隐藏、原始记录保留」；归档成功后关闭详情并刷新当前页。

按用户要求未运行全量回归或严格功能验收；只执行归档后端目标测试包和前端 TypeScript 类型检查。正式发布仍遵守不可跳过的加密备份与健康门禁：两个备份目标上传成功，强制门禁通过。发布后只做非破坏性冒烟：默认列表返回成功且无 `archived=true` 条目，对不存在告警 ID 的归档请求返回 404，未归档或新建任何真实业务告警。

私有发布证据保存在本机 `artifacts/alarm-archive-20261020-r1/` 与服务器 `/opt/powersystem/runtime/alarm-archive-20261020-r1/`。
