# 104 · 顶栏精简与夜间模式前端发布

## 授权与范围

所有者 2026-11-08 指令「发布，不要门禁不要备份不用测试，我直接看效果」。按 [[02-工程规范边界与验收治理/项目工程规范/04-生产发布与恢复/01-上传服务器与分级发布规范]] 的「开发阶段执行优先级」直接接受：不新建备份、不跑完整 HTTPS/WSS 门禁、不跑发布测试套件。

本批**只替换 frontend 镜像**：API、数据库、其余 20 个服务、模型、接口、指标口径一条未动。代码在本地已过 `vue-tsc --noEmit` 与 `vite build`（含 9 页浅/深两版本地渲染核对），本批不重跑。

## 一、改动内容

### 1. 顶栏快捷入口精简

原顶栏并排五枚深链胶囊，其中「待处理告警 / 紧急未处理 / 离线设备 / 健康未知」四项长期为 0、很难产生值，占满一整排却不提供信息。本批只保留「最新告警 + 指标名」，其余四枚与其计数逻辑一并移除。

连带效果：`loadHeadline()` 原先为四枚胶囊各查一次列表，现只保留 `api.summary()` 与 `fetchAlarmViews(8)`，每轮轮询少两次 `/api/v1/alarms` 请求。铃铛角标（活动告警）口径不变。

### 2. 夜间模式

| 文件 | 改动 |
| --- | --- |
| `src/styles/tokens.css` | 抽出 20 余个结构色令牌（card-border / rail-bg / hover-bg / thead-bg / track-bg / chip-bg / tip-bg / chart-* 等），浅色值等于原硬编码值；新增 `:root[data-theme='dark']` 整表覆盖 |

## 二、来源、上传与激活

发布前现查 VM117 `powersystem-prod`：active=`alert-card-20261108-r1`、manifest=`0a2baf52…24ac`、pending 文件不存在、21 服务、frontend 容器 `784ce388843b` 镜像 `sha256:91aa5bd3…d80f` healthy、`/opt` 可用 59 GiB。

本地 `vite build` 产物 36 文件，`dist.tgz` 212,747 字节、SHA-256 `1fc2119f0fc7b4c12f122e8e43d4dc49c1b8658676d80f9b25ce1854cbc22927`；经本机 → `8.138.10.222:7070` → `192.168.111.3` → QGA VM117 送入本批独立目录，VM 内摘要一致。`dist/demo/index.html` 与原版同摘要 `e85beb0d…50fe3`。

`FROM` 现役镜像需先打本地 tag：BuildKit 会把 `FROM sha256:…` 当成要拉取的远程仓库并报 `pull access denied`，本批第一次构建即因此失败（`build.log` 只保留成功那次，不把失败写成一次成功）。改为 `docker tag <现役ID> powersystem-frontend:base-ui-theme-dark-20261108-r1` 后构建成功，得固定镜像 `sha256:b6bdb939ed4baae108fb959ca954782be51131fb5169dfc739fc3bf580fe38ae`；镜像内 `index.html` 引用 `assets/index-CCw7fejT.js`（原 `index-B_gFNwDc.js`），34 个 assets。

候选由父候选 `alert-card-20261108-r1` 复制，`private/compose.json` 只把 frontend image 替换一处；另建 `private/frontend-lock.compose.json` 作为激活时追加在原 15 个 `-f` 之后的镜像覆盖层，避免被 `model-balance-20261031-r1` 的 runtime-align 覆盖回旧值。manifest 按 `sha256(json.dumps(manifest, sort_keys=True))` 现算 `851aaabb…dcda4`，`files` 七项重新取字节摘要，`before` 为激活前现查的 21 服务状态，`manual_activation` 逐项写明未执行内容。

UTC 2026-11-08 15:35:22 持 `deployment.lock` 执行 `docker compose … up -d --no-deps --force-recreate frontend`，退出码 0；`ai-trainer` 孤儿容器警告属既有外部服务，未清理、未重建。
