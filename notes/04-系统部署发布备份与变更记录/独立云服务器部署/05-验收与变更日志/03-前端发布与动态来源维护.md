## 2026-10-16 · 新云入口 502 修复与宿主机容量检查

用户授权修复入口异常。现场新 IP 首页和 `/api/v1/ping` 返回 502，本地和旧入口均为 200；新云 frps 在运行，但业务代理端口 3667 未监听，R730XD 专用 frpc 日志反复出现连接 7000 超时。通过从已认证 R730XD 发出的唯一标记 HTTPS 请求与新云访问日志交叉核验，确认当前业务出口与 `allowed-client-ipv4` 不一致。原始来源地址只保存在服务器私有证据中。

保存允许列表和 IPv4/IPv6 规则副本后，仅替换 `POWERSYSTEM_EDGE` 中 7000 ACCEPT 规则的单个 `/32` 来源，并同步持久文件 `/etc/powersystem-edge/allowed-client-ipv4`。归一化规则对照确认其他 IPv4 规则、全部 IPv6 规则及 7070 管理来源未变。FRP 随后自动重连，3667/7070 恢复监听；未重启 FRP 或业务服务，未修改业务镜像及编排。此修复不代表云安全组控制台待办已经完成。

恢复核对：本地、新旧 IP 的首页与 ping 全部 200；新 IP 经系统 CA 及主机名验证的 HTTPS 首页、设备页、助手页及 ping 为 200，匿名设备 API 为 401。20 个项目容器全部 running，其中 12 个有健康检查且为 healthy，其余 8 个未定义健康检查；重启计数均为 0，无 OOMKilled。本轮只核对故障恢复，未重复运行全套验收、凭据登录、WSS 或模型问答测试。

私有证据及回退副本：新云 `/etc/powersystem-edge/entry-repair-20261016-r1/` 的 `request-source.json`、`allowed-client-ipv4.before`、`iptables-before.rules`、`ip6tables-before.rules`、`iptables-after.rules` 和 `firewall-change.json`；R730XD `/opt/powersystem/runtime/entry-repair-20261016-r1/recovery-check.json` 保存入口响应和容器镜像、启动时间、重启计数快照。回退时应按记录只还原本次来源文件和目标规则，不覆盖共享主机的其他实时规则。后续业务出口再变化时仍需重新核验单一来源；此次没有增加全网放行或自动白名单刷新。

本次容量快照：操作系统可用总内存 62.78 GiB，`MemAvailable` 7.77 GiB，纯空闲 5.74 GiB，Swap 为 0；内存 PSI 的 10/60/300 秒均为 0。项目容器合计约 3.4 GiB，仅为容器统计口径，不能直接等同于整机进程内存占用。当前项目有运行余量；新增本地大模型或虚拟机须另按峰值估算，不能把本次快照视为持续容量保证。

## 2026-10-16 · SAS产品类型更正与1.1.0停用升级

### 原因、影响与修正

所有者确认新云为轻量应用服务器SAS。此前仅凭SSH系统环境及可访问IMDS就按ECS设计前缀列表和实例角色，是前置产品识别错误；1.0.0工程和隔离检查不能证明SAS控制面可用。原包、记录和失败保留并标为不适用，不得按原步骤激活。

经官方文档核对，SAS使用SWAS-OPEN 2020-06-01；ModifyFirewallRule支持来源SourceCidrIp和按指定FirewallRule ARN授权。所有者已选择专用RAM程序用户、AccessKey仅保存在新云root私有文件的方式，替换先前“不保存长期AccessKey”的ECS设计前提；这是本次明确选择，不扩大为其他业务默认凭据规则。

1.1.0改用ListFirewallRules/ModifyFirewallRule，固定SAS实例及RuleId，保持TCP 7000和备注。写权限仅一条规则，List读取授权为本账号本地域firewallrule/*；程序固定查询本实例并保护其他规则。凭据只读新云root:root 600文件，不使用IMDS实例角色、不创建ECS资源。

### 实测与当前状态

- 本机SAS修订套件32项通过，R730XD Linux37项通过（含5项Unix socket/UID检查），全部云写与主机规则写仍为模拟。未重跑业务全套测试，未使用或创建真实云AccessKey。
- 双端已通过SSH升级停用包到1.1.0；新云未填写的ECS配置先私有备份，再替换为enabled=false、provider=swas的新模板。systemd单元检查通过，自动服务和timer继续inactive。
