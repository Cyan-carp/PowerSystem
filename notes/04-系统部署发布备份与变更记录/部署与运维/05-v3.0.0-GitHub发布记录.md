# v3.0.0 · 三智能体协作大版本仓库发布记录

## 一、版本定义与公开入口

2026-10-14所有者授权将已完成的多智能体建设提交仓库并作为大版本发布，版本从v2.0.0推进至v3.0.0。公开发行入口为[GitHub Release v3.0.0](https://github.com/Cyan-carp/PowerSystem/releases/tag/v3.0.0)；固定源码以附注标签v3.0.0实际指向的提交为准。

本版本包含Supervisor问答/需求指令与委派、Operation规划/诊断及受控程序、安全模型独立审查与强制门禁、项目只读巡检、任务卡分区和配套发布/备份/隔离恢复工具。原目录布局重构与联合第四阶段03目录归属也纳入本次仓库交付。

## 二、业务签收与运行版本

联合第四阶段原签收保持：SEC-M4本机签收与r6追加准入、MA-C32～C35服务器验收以及1801.117秒/59次固定镜像观察。服务器运行档r6、策略/许可v5、备份恢复维护修订3；174项运行核心摘要仍为905f62d2209ec6d9f0f6d56abb9c321f6a81ef90e0a4bdbb547bcdfed565a1e8。

详细数字和失败只由[[01-项目调研规划与开发建设记录/第二版-智能体升级/多智能体协作建设/06-联合发布验收/03-联合第四阶段测试与交付]]及两层正式页维护。v3.0.0是仓库发行标识，不改变原运行候选或业务签收编号，也不表示本次重新部署服务器。联合规划注明为验收后归属整理，原日期、失败、批次、签收JSON及私有证据保留。

## 三、发布前复核

2026-10-14本次仓库发行在原已验收运行核心不变前提下独立回归：安全审查264项、基础运维108项、Supervisor/RAG/BND120项及2个子测试、前端30项及类型/构建、Go全包通过。PostgreSQL/Redis测试仅使用既有本机专用回归环境，真实模型、生产写和服务器部署未在本轮重跑。

全量待公开文件比对当前已知私有值及指定凭据格式；禁入文件、运行核心、签收JSON和链接/锚点另行复核。公开扫描不等于所有Git历史或所有未知秘密格式审计。日志、扫描摘要、提交/远端/Release回读结果保留于忽略的artifacts/stage9-ops-agent/github-v3-release-20261014-r1。

## 四、分支、标签与发行核对

按[[02-工程规范边界与验收治理/项目工程规范/02-发布仓库与界面验收规范#六、上传远程仓库规范]]的feature → dev → main流程提交已验收变更；main仅前进，不覆盖远端其他提交。v3.0.0使用附注标签，GitHub正式Release以该固定提交发行；完成后独立回读main、标签提交、Release版本/草稿状态和本机状态。

提交SHA与发行时间由Git/GitHub维护，不把待发布候选写成已发布事实。发布前的未提交/未推送描述属于原验收或本次文档迁移批次的历史边界；本次仓库发行授权及结果由本页与实际Release承接。

## 五、公开范围与保留边界
