# 平台使用手册 · 网页功能与五分钟体验

> 本页只讲**怎么用**。发布指针、设备口径、已知限制统一见 [[00-当前系统状态]]，不在此页复制；历史界面描述见文末「已归档」两条链接。

本页面向第一次接触新能源设备运维的读者。平台把设备上报的温度、功率等数据汇总到网页，帮助值班人员看设备在不在、功率多少、有没有异常、哪台可能出问题。当前公网环境使用 **143 台合成演示设备**（四个业务场站 140 台 + 基线 3 台），**页面数值不能用于真实场站调度**。

## 一、登录与全局布局

1. 用管理员提供的 [HTTPS 入口](https://www.cyancarp.cn/) 打开（旧云 `https://8.138.10.222/` 为故障备用）。旧 HTTP 演示入口是历史取证地址，现已阻断外部直连。
2. 用管理员单独提供的演示账号登录，账号密码不写在公开笔记里。登录有效期 8 小时，过期会回到登录页。
3. 登录后是固定的三块布局，任何页面都一样：

| 位置 | 内容 | 用途 |
| --- | --- | --- |
| 左侧图标轨 | 总览、告警、设备、健康、预测、报表、任务、助手，共 8 个入口 | 鼠标停在图标上浮出名称；底部还有一个「使用说明」图标，点了也进助手页 |
| 顶部横栏 | 页面标题、搜索框、5 个快捷入口、实时连接点、北京时间、告警解读、铃铛、数据说明、账号 | 不离开当前页就能拿到最常看的数据，详见第二节 |
| 主区域 | 当前页面的内容 | 每个页面自上而下是「筛选条 → 数据卡 → 表格」 |

4. 页面底部有一条 26px 高的备案条（`粤ICP备…`），可以点进工信部备案系统。它是合规要求，不能隐藏；这条带子固定贴在窗口底部，不参与页面滚动，所以滚鼠标滚轮时页面不会跟着整体挪动。

> **两个单位不能混**：「当前功率」单位 kW，表示此刻的功率；「今日发电量」单位 kWh，表示今天累计发了多少电。看到 0 kW 不等于没发电，可能只是这一刻没出力。

## 二、顶栏：不进页面就能拿到的信息

**搜索框**：输设备编码、名称或场站，按 `Enter` 跳到设备台账并带上条件。`Ctrl+K`（Mac 是 `⌘K`）随时把光标放进去。

**5 个快捷入口**，每个后面的数字就是当前条数，点一下直接跳到对应筛选结果：

| 入口 | 数字口径 |
| --- | --- |
| 待处理告警 | 状态为「未处理」的条数 |
| 紧急未处理 | 未处理里级别为「紧急」的条数；大于 0 时数字变红 |
| 离线设备 | 台账总数减去在线数（含故障） |
| 健康未知 | 算不出健康分（遥测未知）的设备数 |
| 最新告警 | 最近一条告警的指标名，如「温度」 |

窗口窄时这 5 个入口会从右往左依次隐藏，宽度小于 1080px 全部收起——数据还能在总览页和告警页看到，功能不丢。

**实时连接点**：绿色表示遥测已接入，灰色表示已断开。断开时页面会自动重连，先等几秒，仍不恢复就刷新。

**北京时间**：顶栏时钟固定按 `Asia/Shanghai` 显示，与设备所在时区一致，不跟随本机时区。

**告警解读**（星标图标）：打开一个抽屉，逐条读**未处理告警**的模型解读。按钮上的小红点表示「有未读、且仍值得看的解读」，与铃铛角标不是一回事——告警可能早有人看过，解读可能还没人读。当前没有未处理告警时，抽屉会直接说明「不需要解读」。

**铃铛**：显示活动告警总数（未处理 + 已确认），弹层列最近 6 条，点一条进告警详情；「全部」进告警中心。

**数据说明**（问号图标）：弹出一段口径说明。注意这段文案目前仍在描述本机联调环境（127.0.0.1:8080、密码非空即可），与实际生产登录方式不符，属待修文案；请以本手册第一节的登录说明为准。

**账号**：显示姓名与角色，弹层里有账号、会话有效期和「退出登录」。退出会清掉当前标签页的登录状态。

## 三、八个页面分别解决什么问题

| 导航 | 要解决的问题 | 常用操作 |
| --- | --- | --- |
| 总览 | 现在多少功率、发了多少电、各场站怎么样？ | 看 4 张指标卡、功率曲线、场站对比表、右侧三张卡 |
| 告警 | 哪些异常还没人管？ | 按状态/级别筛选、读详情与处置时间线、确认、归档 |
| 设备 | 某台设备在哪、现在什么数据？ | 按场站/状态筛选、搜索、排序、进详情看曲线 |
| 健康 | 哪台设备状态最差？ | 看档位分布与排名表、读评分依据 |
| 预测 | 哪台设备未来一小时风险高？ | 按概率排序、打开依据看特征贡献 |
| 报表 | 上个月可用率多少、告警响应快不快？ | 选时间与范围、切换两个页签、导出 CSV |
| 任务 | 定期巡检和日报跑到哪了？ | 建任务、看运行历史、只读预演 |
| 助手 | 想用一句话查数据、要一份结论 | 提问、看运行过程、批准受控动作、翻历史会话 |

> 所有列表都分页，**每页 8 条**（报表里的设备表 12 条），底部写着「显示 1–8 / 143 台」并可前后翻页。别把第一页当成全部设备——143 台要翻十几页才看得完。

### 总览

右上角两个按钮：**刷新**重新拉一遍全部数据；**处理告警**跳到未处理告警列表，按钮上的数字就是待处理条数。

- **4 张指标卡**：实时功率（kW）、设备在线（在线 / 总数）、今日发电量（kWh）、活动告警（条）。其中「设备在线」可点进设备台账、「活动告警」可点进未处理告警列表，另外两张只是读数。
- **功率输出**：可选近 6 / 24 / 48 小时，右上角菜单可导出 CSV。图上只有**基线站 3 台**的合计功率，不是全站出力——全站出力看上面的指标卡。图下方标注峰值与采样点数。
- **场站对比**：每个场站的设备在册/规划数、在线率、当前出力、活动告警、遥测未知。点任意一行进入该场站的设备列表。若某场站有未注册设备，表格下方会提示「统计按已注册口径」。
- **右侧三张卡**：数据质量（近 7 天平均可用率、数据覆盖率两个圆环）、设备状态（设备在线率、健康度）、告警构成（紧急/重要/次要/已恢复的条数与占比条）。每张卡右上角的 `⋯` 菜单可导出该卡数据，或跳到报表、台账、告警页。

各区独立加载，某一块取不到只在那一块报错，其他区域照常看。

### 告警中心

> **演示告警是按固定时段造的**：143 台模拟设备每天北京时间 09 / 11 / 13 / 15 / 17 点各产生一条告警，10 分钟后系统把它标记为「演示已结束」。这**不是设备故障后自动恢复**，错过的时间段不补。看到告警一天出现几次又自己结束属演示设计，不是异常，也不用去排查。

筛选分两层：**状态**（全部 / 活动 / 未处理 / 已确认 / 已恢复）+ **级别**（全部级别 / 紧急 / 重要 / 次要），还可按关键词搜。「活动」是**未处理 + 已确认**的合计，也就是还没恢复的都算在内，与顶栏铃铛的角标同口径。列表最多取最近 100 条，上方四格统计走的是全量聚合，不受 100 条限制。

点一行打开详情，可看到设备、指标、实测值与阈值、触发时间、规则版本、报警上下文和**处置时间线**（何时触发、何时确认、何时恢复、由谁操作）。设备为仿真数据时会带「仿真」标记。

两个写操作要分清：

| 操作 | 作用 | 注意 |
| --- | --- | --- |
| 确认告警 | 记录「人已经知道了」 | 只对**未处理且未恢复**的告警可用。多人同时点时，后到的一方会收到状态已变化提示，页面自动拉回最新状态，刷新后以服务器为准 |
| 归档 | 只是打一个标记 | 不删除告警事实、时间线与规则快照，但**归档后不再出现在列表里，目前没有撤销入口**。单条归档和勾选后批量归档都会先弹确认框，写清楚这一点 |

确认**不代表设备已恢复**。只有指标回到规则范围内，系统才把本次告警标成「已恢复」。关闭详情面板也不算确认。

### 设备台账

上方是场站切换（全部场站 / 各场站）和状态切换（全部 / 在线 / 离线 / 故障 / 未知），右侧可按编码、名称、厂商搜索，并按健康分升降或设备编码排序。

每行显示设备、编码、场站、健康分、状态、最高活动告警。「在线/离线/故障/未知」四态直接来自后端健康规则，其中：
- **在线**：最近 15 秒内有数据；
- **离线**：超时没收到数据，健康分计 0；
- **故障**：最新遥测自身报告了故障状态，不是「没数据」；
- **未知**：数据不足以判断，既不能说正常，也不能当故障处理。

点一行进入**设备详情**：设备档案（编号、类型、厂商、场站、分组、设备性质）、最新遥测（温度/功率/电压/电流 + 采样时间与接收时间）、历史遥测曲线、健康评分与评分依据、该设备告警与预测。

曲线可切**温度、功率、电压、电流**，先选指标再选 **15 分钟 / 1 小时 / 4 小时 / 24 小时**，或自定义起止时间（单次不超过 24 小时，超过 6 小时系统自动分段取数）。曲线上的时间是**测量发生时间**；判断数据新不新鲜要看最新遥测里的**接收时间**。空白曲线表示所选时间内没有可显示的数据，不代表读数为零。

### 健康排行

顶部统计给出平均健康分与在线/离线/故障台数，下面按分数分五档：

| 分数 | 含义 |
| --- | --- |
| 100 | 在线且无活动告警 |
| 90 | 在线，有一般（次要）告警 |
| 70 | 在线，有重要告警 |
| 40 | 在线，有紧急告警 |
| 0 | 离线或故障 |

排名表列出名次、设备、场站、健康分、状态、最高活动告警、规则版本和**评分依据**（这台为什么是这个分）。可按编码、名称、场站搜索。

这个分是**当前时点的规则分**，由在线状态和活动告警级别算出来，不是设备寿命预测，也不看历史趋势。

### 故障预测

按「未来一小时故障概率」从高到低排，概率高的在前；**结果过期**和**暂无预测**的设备排在后面。可按风险等级切换，也可按编码、名称、场站筛选。

- **结果过期**：预测超过 15 分钟没更新就不能再当作当前风险依据。列表上方会提示「存在过期预测」，抽屉里也会写明。
- **暂无预测**：通常是设备还没有完整、新鲜的约 30 分钟遥测窗口，不是网页坏了。
- **刷新**只重新读取已有结果，**不会立即重新训练模型或制造新预测**。

点任意一行打开依据抽屉，可看到概率、预测窗口、模型版本与来源、风险阈值、主要特征贡献与概率分布。特征贡献说明的是模型为什么给出这个数，**不是现场故障原因**。当前模型用合成数据训练，不能据此安排真实检修。

### 统计报表

两个页签，**各自一个导出按钮**，导的是该页签当前条件下的数据，与当前激活哪个页签无关：

- **可用率**：整体可用率、数据覆盖率、故障占比、未知占比四个数，下面是场站表和设备表。设备表可按可用率升降排序、搜索、翻页。未知表示「压根没数据」，不计入可用率分母，所以它和故障不是一回事——设备没上报不等于设备坏了。
- **告警及时性**：告警确认耗时、平台告警恢复耗时、遥测恢复耗时、预测风险下降耗时四项，以及确认中位、恢复中位、待确认、待恢复。这里只统计**走完完整生命周期**的告警，未确认、未恢复的单列出来，避免用还没结束的事件拉高平均值。

筛选条件：开始时间、结束时间、场站、设备。时间范围**不能超过 31 天**，结束必须晚于开始，否则页面直接提示并不发请求。条件即接口参数，改完点「查询」才生效。

### 定期任务

列表**只列本人创建的任务**，类型只有两种：**定期巡检**、**定期日报**。每行可看运行历史、修改配置、暂停；暂停中的可以「申请恢复」。运行历史同样只列本人提交的那几条。

- **只读预演**：在执行前先按近 24 小时或近 1 小时的数据试算一遍，看会产出什么，结果可下载为 JSON。预演只读，不改任何数据。
- 任务详情里能看到配置、状态、运行历史与每轮结果摘要。

新建或修改任务时填写任务类型、周期、范围等配置；提交后按周期自动运行。

### 智能助手

页头两个按钮：**任务记录**（看本人已受理的运行，可独立查看全部/未关联对话/未完成，点开看报告，**打开记录不会重新执行诊断**）和**新会话**。

对话区空着时显示一段说明和三个示例问题（哪个场站今天出力下降最明显、未处理告警里最久的是哪一条、哪些设备健康分低于 80）。点示例只是**填进输入框**，要自己按发送。

发送后服务端先受理一次「运行」，正文、进度、待批准动作和产物都从同一条事件流里出来：

- 回答上方显示运行状态（排队、进行中、待批准、已完成、已停止等）；中途离开页面不会中断任务，回这段会话会自动重新挂上。
- 「参考来源」可展开，点章节会打开来源抽屉，显示文档名与版本。
- 「审批与动作」在没有待批准项时收起；有待批准动作时默认展开并提示。**批准只消费一次，须本人当场确认**。
- 进行中可「停止接收回答」——这只停止接收，后台任务仍在继续。回答结束后出现「再问一次」，它把原问题**填回输入框**、不自动重发，改完再按发送。
- 取消运行**不等于撤销已经发生的修改**；结论以服务器权威状态为准，结果不明时先对账，不要重复执行。

**输入框支持多行**：1 行起，最多长到 6 行后内部滚动。`Enter` 发送，`Shift+Enter` 换行。用中文输入法打字时，按回车选词不会误发（组合态一律交给输入法）。

右栏上半是**历史会话**（可批量管理、刷新、单条删除、新会话），下半是**能力边界**三条常驻提示。右栏与对话卡严格等高，会话多了只在会话列表**内部**滚动，不会把整页撑出滚动条。

## 四、五分钟只读走查

这条路径不创建、不删除、不确认、不归档任何数据，适合第一次验收。

1. 登录后停在**总览**，记下 4 张指标卡的数字，确认顶栏连接点是绿色、时钟在走。
2. 看**功率输出**：横轴时间、蓝色折线、图下标注的峰值；切一次「近 24 小时」，确认曲线重画。再看右侧三张卡有没有数字。
3. 看**场站对比**表，点一个场站，确认跳到了设备台账且已按该场站筛选。
4. 在**设备台账**打开一台设备，切「功率」和「温度」，分别选 15 分钟与 1 小时，确认指标、单位、时间轴都跟着变。
5. 进**告警中心**，切几个状态页签。有记录就打开一条，核对实测值、阈值、时间和处置时间线；没记录就确认空状态显示正常。**不要点「确认告警」和「归档」。**
6. 进**健康**看排名表与档位分布，进**预测**点「刷新」再点开一台设备的依据（显示「结果过期」或「暂无预测」属正常，按提示理解即可）。
7. 进**报表**，选最近 7 天，两个页签各看一遍，点一次导出确认能下载 CSV。
8. 进**助手**，点一个示例问题再发送，看回答、展开参考来源；回历史会话列表，点「新会话」。
9. 最后点右上角账号 →「退出登录」，确认回到登录页。

测试记录只写观察到的时间、设备编码、页面状态和截图；**不要在截图或共享笔记里附带密码、令牌**。

## 五、常见问题

**登录与连接**

| 现象 | 先做什么 |
| --- | --- |
| 打不开网址 | 确认用的是 `https://www.cyancarp.cn/`（故障时备用 `https://8.138.10.222/`）；稍后重试，仍不行把时间和浏览器提示告诉管理员 |
| 登录后又回到登录页 | 会话已过期（8 小时）；用演示账号重新登录，别反复试未知密码 |
| 显示「连接断开」 | 等自动重连；仍不恢复就刷新网页，并向管理员报告时间与页面 |

**数据与页面**

| 现象 | 先做什么 |

## 六、能力边界与不要做的事

- **全部是合成演示数据**：143 台模拟设备、合成遥测、合成数据训练的模型。不能据此安排真实设备调度、检修或对外汇报。
- **确认不等于恢复**：确认只记录「人已知道」，恢复由指标回到规则范围决定，两者分别在时间线上留痕。
- **归档不可撤销**：只打标记、不删事实，但归档后列表里不再出现。
- **健康分与故障概率都是规则/模型输出**，不是设备真实寿命或现场故障原因；两者都不能替代人工核查。
- **AI 只给建议，不执行设备操作**。设备操作建议须由专业人员核对实际机型、厂家手册与现场条件后决定。受控动作要本人在界面上当场批准，批准只消费一次。
- **不要输入敏感信息**：账号、密码、密钥、个人信息都不要贴进助手输入框。
- **截图与共享笔记**不要附带密码、令牌；转发前先确认画面里没有登录态。
