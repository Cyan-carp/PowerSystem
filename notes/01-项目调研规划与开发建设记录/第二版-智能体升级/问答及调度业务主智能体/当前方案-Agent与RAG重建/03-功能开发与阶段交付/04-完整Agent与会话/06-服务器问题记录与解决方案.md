| 模型目录700导致非root不可读 | 只修改公开模型目录为755、文件644；私有配置仍700/600，密钥400 | E5384维预热与98片导入成功 |
| 容器浅目录触发ROOT默认值越界 | 显式环境路径优先，避免即使设置环境变量仍提前计算parents[3] | Linux导入通过 |
| Linux测试位置、PYTHONPATH或审计目录错误 | 保留三批失败；测试置于/app/tests、PYTHONPATH=/app、审计目录可写，独立验证后再切换 | 最终16/16，未拼接批次 |
| 第一次API切换502 | Windows预编译产物丢失可执行位；实际回退原源码和镜像，旧公网问答复测成功；COPY显式755后重建R2并先行隔离健康测试 | 最终API健康及真实12题通过；失败切换和回退日志保留 |
| 资料答案混淆本地与生产Compose | 公开手册明确powersystem-stage4及生产叠加配置，保留原错误回答；增量导入新集合 | 新12题批次资料回答能区分两者；不等于逐句正确 |
| 来源详情在页面底部展开 | ElDialog未注册；补齐main.ts组件注册，重建前端R2，重新计时观察 | 实际弹窗打开、关闭、版本展示通过；不再有该内容引起的横向溢出 |
| 自动审批拒绝备份外传 | 改为先在R730XD生成本地AES256密文并恢复；明确载荷及目的地后用户允许上传新云，不外传口令 | 指定云端SHA256与本地一致 |

| 自由复问未调用工具却说重新查询 | 模型未遵从软提示，原始会话与quality-repeat-without-tool截图保留 | 质量失败，未恢复程序强制取证 |
