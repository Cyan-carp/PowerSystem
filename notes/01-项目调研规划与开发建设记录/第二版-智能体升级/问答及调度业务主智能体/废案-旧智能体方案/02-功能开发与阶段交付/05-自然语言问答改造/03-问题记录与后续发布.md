# 03 · 问题记录与后续发布

> 归档声明（2026-10-11）：本页属于已弃用的旧智能体方案，仅保留历史设计、测试和发布事实。正文中的“当前”以原记录日期理解；新问答方案见 [[01-项目调研规划与开发建设记录/第二版-智能体升级/问答及调度业务主智能体/当前方案-Agent与RAG重建/00-索引·Agent与RAG重建]]。旧自动告警解读作为独立历史模块继续维护。

## 本机发现及修复（2026-10-09）

| 问题 | 修复与证据 |
| --- | --- |
| Docker 启动初期不可达 | 所有者重启后恢复；未改名或删除套接字，未修改旧容器数据 |
| 原 TDengine 创建测试库时报 Vnodes exhausted | 单独建立本轮回环 16041 容器；历史库与卷保留 |
| 原模型/工具夹具直接返回旧答案格式 | 原路线移入测试夹具，新运行入口另有语义专项；取消期间缺口和审计继续回归 |
| 旧时间测试省略时区，与现有护栏矛盾 | 保留时区护栏；测试同时断言带时区时间通过、不带时区拒绝 |
| 第一批预测混合题没有预测样本 | 保留 11/12 失败批次；本轮专用库补 synthetic 预测后复测 |
| 完整第二批七天排名意图被模型写成 live=false | 程序强制非资料意图取业务证据；新增矛盾计划专项回归；修复批次七天统计通过 |
| 第二批告警资料题出现服务故障，原批次未记录细分原因 | 增加安全失败原因审计、限制输出长度、一次严格格式修复，并压缩来源摘录；9/9 修复批次包含该题通过；不将猜测原因记为已证实 |
| 来源存在却与陈述无关 | 独立来源支持审核、逐字摘录校验及支持覆盖率；未支持陈述计入未核验，现场断言拒绝 |
| 混合题超时可能丢失已取得数据和设备指代 | 保留已核验业务事实，并在释放会话锁前保存指代元数据 |
| 编码紧贴中文时兜底识别遗漏，导致后续“它”没有指代 | 编码边界改为 ASCII 标识边界，模型故障温度问法仍查询 INV-1002；增加回归 |
| 库外技术回答偶发结构失败和主模型超时 | 校验反馈只携带字段位置/类型；结构限制最多两条事实、解释和建议；保留各完整批次失败记录 |
| “还有告警吗”不能用近 30 天触发次数代替当前未恢复数量 | 独立 current/events 计划字段；当前活动计数不限定触发日期，增加专项和真实答案断言 |
| 一批库外技术题被模型误判为范围外 | 最终审计确认“钙钛矿组件衰减”属于范围误判，而非该次超时；补范围契约校验，明确新能源技术主题不会按生活问题拒绝，混合生活请求仍拒答，新增回归 |

原始批次及最终汇总均保存在 Git 忽略目录；不覆盖失败报告。

## 后续服务器发布门槛

本轮仅本地交付。R730xd、`8.138.42.212` 和旧公网入口没有发布或本轮实测。后续发布必须使用本轮最终受审源码和知识指纹，在更新前保存现网源码/镜像回退点及加密备份，再增量构建 API、Agent、前端和执行 006 迁移。

服务器需重跑自然问法、全量告警排名、知识缺口、多轮会话、角色鉴权、原业务/WebSocket 和旧入口回归；完成实际源码/镜像回退、最终备份隔离恢复及固定镜像观察。未取得这些证据前，本机结果不计为现网签收。

专业来源审核、真实设备机型适用性、真实场站数据与预测效果仍保持既有待办；模型故障期间开放式知识问答无法保证持续可用。
