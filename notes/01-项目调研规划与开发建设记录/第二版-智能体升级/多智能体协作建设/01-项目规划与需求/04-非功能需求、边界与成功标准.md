# 04 · 非功能需求、边界与成功标准

> 2026-10-14当前：SEC-M4本机限定签收及r6追加准入通过；MA-C32～C35和最终文档门槛已完成，MA-M4及联合阶段四在声明范围正式技术签收。服务器r6/v5、恢复维护修订3；本机唯一批准动作保留，写窗口关闭，生产仅登记R0。

> 集中记录工程质量、能力范围和默认参数；对应MA-NFR01～MA-NFR10。

## 一、非功能需求

| 编号 | 要求 | 判定方式 |
| --- | --- | --- |
| MA-NFR01 | Go认证身份贯通，服务鉴权，任务所有权 | 伪造拒绝，跨用户404 |
| MA-NFR02 | 密钥不进模型、队列、数据库或公开材料 | 凭据样例与输出扫描 |
| MA-NFR03 | 运维资源池独立、配额集中配置 | 边界值、并发与超限测试 |
| MA-NFR04 | 数据库唯一状态真相，幂等与可靠投递 | 重复请求、投递与重启故障 |
| MA-NFR05 | 失败真实、部分结果可见、无自动写重试 | 故障注入与不确定状态 |
| MA-NFR06 | 旧聊天契约及BND功能兼容 | 旧历史和现行边界回归 |
| MA-NFR07 | 审计与模型解释分离，失败证据保留 | task/step/call可追溯 |
| MA-NFR08 | 业务链路不等待运维模型 | 运维故障时原业务回归 |
| MA-NFR09 | 内网部署、备份恢复、配套回退 | 外部端口、实际回退及隔离恢复 |
| MA-NFR10 | 脱敏与资料指令隔离，不外推效果 | 注入测试和质量评测分账 |

## 二、运维侧默认参数

| 参数 | 默认值 |
| --- | --- |
| OPS_TASK_TIMEOUT_SECONDS | 300秒；排队起计至阶段截止时间 |
| OPS_MODEL_TIMEOUT_SECONDS | 60秒 |
| OPS_TOOL_TIMEOUT_SECONDS | 15秒 |
| OPS_MAX_ROUNDS / OPS_MAX_TOOL_CALLS | 8轮 / 16次 |
| OPS_GLOBAL_CONCURRENCY / OPS_USER_ACTIVE_LIMIT | 2个运行任务 / 每用户1个活动任务 |
| OPS_LEASE_SECONDS / OPS_HEARTBEAT_SECONDS | 50秒 / 10秒；均为新运维配置 |
| OPS_QUEUE_CAPACITY | 20个待运行任务，全局满返回429 |
| OPS_APPROVAL_TTL_SECONDS | 1800秒 |
| OPS_POLL_INTERVAL_SECONDS | 前端2秒，隐藏暂停、终态停止 |
| OPS_CHAT_WAIT_SECONDS | 最多15秒，且不得超过剩余聊天预算 |
| OPS_ENABLED / OPS_WRITE_ENABLED | 新源码首次交付默认false / false |

审批等待不占运行槽，但占每用户活动任务名额；审批决定30分钟过期。审批通过后重新生成300秒执行阶段截止时间，不延长原规划阶段。签名身份失效必须重新经Go认证授权，不依赖长期保存JWT。

现有聊天120秒、代理125秒及原聊天配额保持；聊天到运维的总成本与工具次数可观察，不能把单轮16次解释成多个Worker无限调用。

## 三、边界与例外

- 现行BND-E02仍是平台固定GET；会话管理、运维状态持久化不是业务库写工具。
- R0可运行参数化读取，不等于允许任意SSH命令、任意SQL或Docker管理。
- 后续BND-P06只计划允许登记的隔离演练容器重启，不开放真实新能源设备、共享服务或核心容器。
- 平台当前无逐设备ACL，本期不宣称租户/设备级隔离；基础设施只读范围按在册项目资产限制。
- operator/admin可读脱敏诊断，只有任务所有者可读其任务；admin没有自动跨用户查看所有任务的例外。
- 公网入口、模型服务和数据库现状来自既有资料，本次不把它们写成今日已现场核验。

## 四、成功标准与不承诺事项

需求到任务到证据可追踪；没有执行不标已执行；模型故障保留事实；未经审批零写入；原业务继续工作。只读成功不等于诊断正确，程序事实展示不等于逐句审核。

真实机型专业审核、真实场站效果、长期无人化可靠性、数据库数据级回滚和整机生产切换均不在本期证明范围。新增基础设施日志外发前确认数据范围与目的地，脱敏后仅发送必要摘要，不自动继承旧问答外发授权。

## 六、安全审查非功能需求（待实现）

| 编号 | 要求与判定 |
| --- | --- |
| SEC-NFR01 | 可信身份/所有权、独立服务认证和结果摘要绑定；伪造/跨用户拒绝 |
| SEC-NFR02 | 数据先投影脱敏、目的地/许可/载荷一致；秘密与越界外发零发送 |
| SEC-NFR03 | 独立预算、耗时/成本可观察；不能绕父任务预算或影响原业务 |
| SEC-NFR04 | ma_ops程序存证、失效可解释、恢复不重放授权；审计失败停止受审动作 |
| SEC-NFR05 | 旧ma/v1状态/聊天/任务兼容；普通平台GET和主动核验零额外模型 |
| SEC-NFR06 | 程序事实/模型质量分账；注入、误拒/漏放、缺项与不确定性独立评测 |

安全服务默认未启用、模型必须显式配置，不自动新增供应商或fallback。预算和审查有效期唯一契约见程序控制层，不改现有OPS/BND默认值。强制模式启用后安全不可用不能降级旁路执行。

专业审核、真实设备效果、生产核心执行、等保/渗透测试与整机灾难切换仍不在SEC本机证明范围。新的实际数据与目的地授权在开发/验收前明确，文档建档不构成外发授权。
