# S03 · 试用与回退

> 目标：候选模型先跑 24 小时再定去留，不行一键退回，全程不重启容器。

## 一、状态机

```
candidate ──trial──▶ trial ──confirm──▶ active
                        │
                        └──rollback──▶ candidate（软链回退 + reload）
```

新增字段（`model_registry`，均可空）：

| 字段 | 用途 |
| --- | --- |
| `trial_started_at` | 试用开始，用于算 24 小时 |
| `previous_version` | 回退目标，回退只认这个字段 |
| `trial_note` | 试用结论（人工或 AI 填写） |

## 二、三个接口

| 接口 | 动作 |
| --- | --- |
| `POST /models/{v}/trial` | 校验版本可加载 → 改软链 → reload → 置 `trial`，记 `previous_version` 与 `trial_started_at` |
| `POST /models/{v}/confirm` | 校验已满 24 小时 → 置 `active`，原 active 置 `retired` |
| `POST /models/{v}/rollback` | 软链改回 `previous_version` → reload → 目标版本置回 `candidate` |

三个接口都是写操作，需管理员权限，且都要有二次确认框。

## 三、试用期满的判定

- 时长：`now - trial_started_at >= 24h`；
- 指标：新模型在试用期内 `precision` 不得低于旧模型试用前 24 小时 `precision` 超过 5 个百分点；
- 优劣只做提示，**不自动回退**——写操作必须人点。

## 四、验收标准

| 项 | 判据 |
| --- | --- |
| 试用切换不中断 | 切换前后连续调 `/predict` 无 5xx，容器 `StartedAt` 不变 |
| 未满 24 小时不能 confirm | 按钮置灰并显示剩余时间 |
| 回退可复现 | 回退后 `/health` 与台账都回到旧版本，试用版本回到 `candidate` |
| reload 失败自动改回 | 故意指向坏目录，软链与台账均不变 |
