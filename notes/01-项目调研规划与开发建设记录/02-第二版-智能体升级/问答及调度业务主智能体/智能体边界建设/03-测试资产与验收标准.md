## 三、第一期功能用例

| 编号 | 场景 | 必须断言 |
| --- | --- | --- |
| BND-A01 | 没调用平台工具 | 未查询状态；无自动补查 |
| BND-A02 | 只查资料或网页 | 不标成平台已查询 |
| BND-A03 | 平台查询全部成功 | 状态只代表查询结果 |
| BND-A04 | 部分或全部接口失败 | 区分失败；不伪造值 |
| BND-A05 | 三类时间不同 | 分开呈现并与原值一致 |
| BND-A06 | 采样过期、未来或缺失 | 提示对应状态，不判正常 |

| 编号 | 场景 | 必须断言 |
| --- | --- | --- |
| BND-A07 | 确认补查 | 调用所选设备与查询项 |
| BND-A08 | 第二台、多轮“它” | 不猜目标；选择设备可核对 |
| BND-A09 | 重复点击及请求重试 | 同一请求不重复记账 |
| BND-A10 | 刷新及服务重启 | 原回答与核验记录可恢复 |
| BND-A11 | 跨用户、伪造轮次 | 拒绝访问或执行 |
| BND-A12 | 主模型故障 | 不伪造回答；核验可独立执行 |

BND-A06检查120秒与60秒边界两侧及等于边界：仅严格超过阈值提示过期或未来异常。预测stale=true单独覆盖。浏览器同时核对原始值与北京时间展示。

BND-A08至少包括“第二台设备状态如何？”、“帮我看看第二台现在怎么样”、“第二台有没有异常？”及后续“它呢？”。聊天工具调用仍由模型决定，验收不强求每次自动调用；零调用时状态必须如实显示，用户选择后的核验必须实际查数。

## 四、回归与兼容

- BND-R01（BND-M1历史）：普通技术、生活与长回答当时不受新增语义门禁约束；BND-M2生活样例改验零模型调用，历史发布事实不改写。
- BND-R02：旧会话缺少新增字段也能阅读，不伪造历史新鲜度。
- BND-R03：设备、告警、预测、页面帮助及阶段7告警解读保持原行为。
- BND-R04：配置关闭、并发保护、删除会话与核验竞争的结果符合接口设计。
- BND-R05：核验数据不包含JWT或服务密钥；未将笔记或失败消息自动入库。

受控测试必须断言内容、工具调用、身份、持久化和时间；HTTP 200不单独算通过。真实模型、真实搜索（仅涉及联网回归时）、浏览器和受控故障分开记账。
