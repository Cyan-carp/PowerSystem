## 一、数据语义（批次1）

**告警关闭原因 `close_reason`**

- 迁移：`stages/02-backend/deploy/postgres/007_alarm_closure.sql`，新增 `alarm_records.close_reason / rule_operator / rule_version` 与 `alarm_rules.version`，历史已恢复记录补标 `unknown`，不推断补填。
- 模型：`stages/02-backend/internal/model/model.go`（`AlarmRecord`、`AlarmRule` 新增字段）。
- 恢复路径分别写关闭原因：
  - 遥测恢复 → `telemetry_recovered`（`internal/service/alarm.go`）。
  - 预测风险下降 → `prediction_risk_resolved`（`internal/api/prediction.go`）。
  - 规则禁用 → `rule_disabled`、规则删除 → `rule_deleted`（`internal/api/alarms.go` 的 `closeRuleAlarms`）。
  - 设备删除 → `device_deleted`（`internal/api/handlers.go` 的 `deleteDevice`）。
- 规则版本：`internal/api/alarms.go` 的 `nextVersion`，创建 `v1`，更新递增；触发时快照运算符与版本。
