# 03 · RAG-M2测试与交付

运行编号 `rebuild-20261011`，日期2026-10-11。本机合成演示范围，R730XD及公网未发布。证据在忽略目录 `artifacts/stage8-agent-rag/rebuild-20261011/`；真实与受控故障分开判定。

## 一、实际结果

博查接受模型生成的普通搜索问题，不限制生活词汇，不拼接固定技术关键词。真实R3最新新闻及组合工具用例实际调用web_search，并产生网页来源；接口仅发送搜索问题。

HTTP503受控故障无虚假来源；工具失败后的模型继续回答由Engine用例验证。查询参数URL、非法协议和凭据脱敏有代码验证。首版仅使用搜索摘要，不提供任意网址抓取工具。

## 二、证据

`real-r3/responses.json`中真实搜索和组合工具；`local-checks.json`、`agent-tests.log`、`frontend-tests.log`。链接展示来自真实工具结果，不计算来源覆盖率。
