# 03 · 风险、待办与后续规则规划

> 2026-10-14当前：SEC-M4本机限定签收及r6追加准入通过；MA-C32～C35和最终文档门槛已完成，MA-M4及联合阶段四在声明范围正式技术签收。服务器r6/v5、恢复维护修订3；本机唯一批准动作保留，写窗口关闭，生产仅登记R0。

> 记录设计风险与阶段归属，候选不混入当前开放能力。

## 一、风险与控制

| 编号 | 风险 | 控制与归属 |
| --- | --- | --- |
| MA-R01 | 拆分后模型仍可能推断错误 | 证据/解释分区与质量样例；M1/M2 |
| MA-R02 | 认证保护限制重启续跑 | 显式auth_context_lost，用户新任务；M1 |
| MA-R03 | 数据库与消息队列双写遗漏 | 同事务outbox、重复投递防重；M1 |
| MA-R04 | Docker权限远超只读表述 | 独立受限适配层、实际ID与输出白名单；M2 |
| MA-R05 | 日志/inspect/SQL暴露内部数据 | 先脱敏、最小字段、外发范围确认；M2 |
| MA-R06 | 审批后目标或策略变化 | 参数/容器ID/版本绑定和执行前检查；M3 |
| MA-R07 | 写已发生但结果未持久化 | 不确定结果、零自动写重试；M3 |
| MA-R08 | 共享主机对象误纳入 | 项目归属台账、拒绝未核实资产；M2 |
| MA-R09 | 回退配置与旧前端不兼容 | 配套源码/镜像实际回退；M4 |
| MA-R10 | 恢复出的批准记录触发动作 | 隔离恢复只读、无凭据、禁止自动执行；M4 |

## 二、进入实施前的待办（历史）

- MA-M1：上述准备已完成；工作区、专库、独立签名、GET迁移及MA-C10原生页面证据已落实。
- MA-M2：上述归属、专用只读采集与权限已在正式页声明范围签收；后续新增对象仍需核对。
- MA-M3：本机隔离演练和BND-P06已技术通过，写窗口关闭；不扩大为服务器写能力。
- MA-M4：上述延期为2026-10-13历史；2026-10-14已联合签收，当前规划与结果归03。

该段保留建档时的依赖说明；当前SEC-M4/MA-M4联合签收及未覆盖边界见[[01-项目调研规划与开发建设记录/02-第二版-智能体升级/多智能体协作建设/06-联合发布验收/03-联合第四阶段测试与交付]]。MA-M1实际故障及修复统一保存在阶段一独立问题页，旧失败不覆盖。

## 三、后续候选

Network/Backup/Deployment Agent、多Worker可撤销委托身份、PVE工具/快照、其他主机、资产级ACL、定向WebSocket、viewer/auditor、生产服务执行均须另行立项。

阈值比较、告警状态解释和手册适用性仍由BND-C01～C03维护，不因建立多智能体就自动实现。真实场站/专业审核沿既有待办保持。

## 四、规则增量与文档状态

新边界按提出样例 → 台账 → 用户确定 → 设计 → 实施 → 独立测试 → 正式验收 → 发布。BND-P06当前为MA-M3本机隔离技术验收通过且默认关闭，不改变BND-E02平台只读。

阶段状态变化同步正式测试页、索引、根README、验收清单、手册、源码README、测试资产和运行产物说明。没有证据不得将“已建档”改成“已上线”。

## 五、安全审查建设风险与待办

| 编号 | 风险 | 控制与归属 |
