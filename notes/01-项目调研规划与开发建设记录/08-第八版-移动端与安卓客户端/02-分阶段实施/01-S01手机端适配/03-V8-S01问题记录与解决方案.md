# 03 · V8-S01 问题记录与解决方案

> 适配过程中真正踩到的四个问题，按「现象 → 原因 → 影响 → 解决 → 验证」记。状态均为已解决。

## 问题 1 · 顶栏弹层整块溢出屏幕左侧

**现象**：390×844 下点顶栏铃铛，弹层 `getBoundingClientRect()` 返回 `x = -81`，即左侧 81px 在屏幕外，标题被切掉。

**原因**：`.popover` 是 `position: absolute; right: 0`，锚在触发按钮上。桌面端铃铛离右边缘上千像素，340px 向左展开没问题；
手机端铃铛离右边缘只有几十像素，340px 必然越界。仅把宽度收窄到 `100vw - 16px` 也不够，因为越界是定位造成的。

**影响**：顶栏三个弹层（活动告警 / 数据说明 / 账号）在手机上全部不可用。

**解决**：手机断点内改 `position: fixed; top: calc(var(--top-h) + 6px); right: 8px; left: auto`，
宽度取 `min(340px, calc(100vw - 16px))`。`.popover` 全库只有 `App.vue` 一处使用，改固定定位不影响其他页面。

**验证**：改后同一操作返回 `x = 42, right = 382`，完整落在 390px 视口内。

## 问题 2 · 底栏插在 `v-if` 与 `v-else` 之间导致编译报错

**现象**：把 `<nav class="mnav">` 与 `<Teleport>` 写在 `.app` 之后、`<RouterView v-else />` 之前，`vue-tsc` 直接失败。

**原因**：模板里 `v-else` 必须紧跟 `v-if` 元素；`Teleport` 虽然不产出 DOM，但仍是模板节点，会打断这条链。

**影响**：编译不通过。

**解决**：把底栏与 `Teleport` 移进 `.app` 内部（`.app` 无 `transform`，`fixed` 子元素不会被 `overflow: hidden` 裁剪）。

**验证**：`npm run typecheck` 与 `npm run build` 均通过；手机上底栏正常吸底。

## 问题 3 · 手机端「没有横向溢出」却仍有元素被切

**现象**：首轮截图里总览页正常，但登录页在软键盘弹起后表单下移、按钮被推到底部之外。

**原因**：页面用 `100vh` 计算可视高度，软键盘与地址栏变化时 `vh` 不跟随；同时缺少底部让位。

**影响**：手机上最后一排内容可能永远滚不到。

**解决**：`html/body/#app` 与 `.app` 同时写 `100vh` 与 `100dvh`（后者覆盖前者）；
底部固定元素统一让位 `--mnav-h + --safe-b`；助手页会话卡按同一组变量计算高度。

**验证**：9 页 `scrollWidth == clientWidth`；模拟器软键盘弹起时登录按钮仍可点击（见 S02 测试页第 3 张截图）。

## 问题 4 · 图表在手指横向拖动时读数探针消失

**现象**：手机上按住曲线横向拖动，探针闪一下就没了。

**原因**：浏览器把横向 `pointermove` 判定为页面滚动，触发 `pointercancel`，脚本的拖动状态被中断。

**影响**：手机上看不出某个时刻的具体功率值。

**解决**：`.chart svg` 加 `touch-action: pan-y`——纵向仍交给浏览器滚动页面，横向交给脚本。

**验证**：属于行为类改动，模拟器上手势可用；未做自动化断言。
