# 01 · V8-S01 方案与实施记录

## 二、壳层规则（≤900px）

**导航形态**

- `.rail` 隐藏；`.mnav` 成为 `position: fixed` 的底部条，`height: calc(--mnav-h + --safe-b)`，
  `bottom: var(--icp-offset)`（有备案页脚时抬 26px）。
- 底栏每格图标 + 文字；选中态品牌蓝 + `stroke-width: 2.2`（CSS 可覆盖 `stroke-width` 指示属性）。
- 「更多」触发 `.msheet`（底部抽屉）＋ `.msheet-scrim`（遮罩），`z-index` 95/96，高于顶栏弹层（60）。

**顶栏取舍**

| 元素 | 手机端处理 | 理由 |
| --- | --- | --- |
| 页名 | `max-width: 34vw` + 省略号 | 长页名不再把右侧图标挤走 |
| 搜索框 | 隐藏 | 设备台账页自带搜索框，重复入口不如把宽度还给数据 |
| 快捷胶囊 | 既有断点在 1120px 已隐藏 | 不变 |
| 时钟 / 遥测灯 | 既有断点在 1180/760px 已隐藏 | 不变 |
| 弹层 | 改 `position: fixed` + 贴视口右上角 | 390px 下原本左溢出 81px |

**页面与卡片**

- `.page` 下内边距 = `--mnav-h + --safe-b + 18px`，保证滚到底不压住最后一行。
- 卡片内边距收一档（`13/14` 与 `0/14/16`），表格首尾列内边距同步收窄。
- 触控热区：`.pager-btn`/`.icon-btn` 提到 34px，`.btn` 36px，`.btn-sm` 30px。
- 表格滚动区加 `-webkit-overflow-scrolling: touch` 与 `overscroll-behavior-x: contain`。

## 三、App.vue 的导航实现

```text
nav 数组（九个入口，桌面端图标轨用）
  ├─ M_PRIMARY = ['/', '/alarms', '/devices', '/assistant']
  ├─ mobilePrimary = nav 中属于 M_PRIMARY 的四项   → 底栏
  └─ mobileMore    = 其余五项 + 演示台              → 「更多」抽屉
```

两个实现细节值得记：

1. **底栏与抽屉放在 `.app` 内部**。模板里 `<div v-if="showShell" class="app">` 之后紧跟 `<RouterView v-else>`，
   把导航插到两者之间会打断 `v-if/v-else` 链、直接编译报错；`.app` 没有 `transform`，`fixed` 子元素不受 `overflow: hidden` 裁剪。
2. **抽屉用 `Teleport to="body"`**。避开壳层的层叠上下文，保证遮罩能盖住顶栏与页面内容。

## 四、高度与安全区口径

| 变量 | 值 | 用途 |
| --- | --- | --- |
| `--mnav-h` | 56px | 底栏可视高度 |
| `--safe-b` | `env(safe-area-inset-bottom)` | 手势区让位 |
| `--safe-t` | `env(safe-area-inset-top)` | 刘海屏顶部 |
| `--icp-offset` | `0px` / `26px`（`html[data-icp]`） | 备案页脚占位 |

助手页高度：`calc(100dvh - 250px - var(--mnav-h) - var(--safe-b))`，并设 `min-height: 360px`。

## 五、明确没做的事

- 没有为手机端新增路由、视图或组件目录；
- 没有改桌面（>900px）的任何字号、间距与断点；
- 没有改页面内部栅格（1240/1180/1100/760/680/600 六级断点原样保留）；
- 没有引入 UI 库或任何依赖。
