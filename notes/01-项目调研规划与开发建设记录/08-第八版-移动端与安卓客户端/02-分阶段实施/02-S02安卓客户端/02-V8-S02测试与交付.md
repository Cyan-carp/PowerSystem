# 02 · V8-S02 测试与交付

> 记录本轮**实际执行**的实装验证。设备是模拟器，不是真实手机，结论不外推到真机与老系统。

## 一、测试环境

| 项 | 值 |
| --- | --- |
| 设备 | Android Studio AVD `Medium_Phone_API_36.1` |
| 系统 | Android 16（API 36） |
| 屏幕 | 1080 × 2400，density 420（约 411×914 dp） |
| 连接 | `adb`，无头模式（`-no-window`，`screencap` 取图） |
| 加载地址 | `http://10.0.2.2:5173/`（模拟器回环到宿主机的 Vite dev + 假后端） |

> 用 dev 地址是为了同时验证「地址可改」与「手机端布局」，而不是为了验证生产。
> 生产仍是旧前端，真机连生产要等 S03。

## 二、静态检查

| 检查 | 命令 | 结果 |
| --- | --- | --- |
| 包信息 | `aapt2 dump badging` | 包名 `com.powersystem.mobile`；`versionCode=1`、`versionName=1.0.0`；`minSdk=24`、`targetSdk=34`；权限三项（INTERNET / ACCESS_NETWORK_STATE / WRITE_EXTERNAL_STORAGE ≤28）；应用名「源网智联」；自适应图标生效 |
| 包内容 | 解压清单 | `classes.dex` 13,980 字节、`resources.arsc`、5 个密度图标、`shortcuts.xml`、签名文件齐备 |
| 签名 | `apksigner verify --print-certs` | 通过；证书 `CN=PowerSystem Mobile`，SHA-256 `2d5abb78…f50165` |
| 包体 | 文件大小 | 29,716 字节（约 0.03 MB） |

## 三、实装流程与结果

| 步骤 | 操作 | 结果 |
| --- | --- | --- |
| 1 | `adb install -r` | `Success` |
| 2 | 启动 Activity | 首启进入「服务器地址」页，默认值 `https://www.cyancarp.cn/`，两个按钮与提示文案正常 |
| 3 | 地址改为 `http://10.0.2.2:5173/` 并保存 | 加载出登录页；页面为手机端布局；软键盘弹起时表单不被挤没 |
| 4 | 输入账号密码点登录 | 进入壳层，显示场站总览：底部四格导航 + 指标卡 2×2 + 功率曲线 |
| 5 | 点底栏「告警」 | 切到告警中心，底栏选中态跟随 |
| 6 | 点「更多」 | 底部抽屉展开 6 个入口，遮罩覆盖页面，可关闭 |
| 7 | 按返回键 | 先关闭抽屉；再按一次从告警退回总览；再次按下提示「再按一次退出」 |
| 8 | 读 logcat | 无 `AndroidRuntime` 异常；仅有 http 源下 autofill 关闭的常规 chromium 警告 |

## 五、未覆盖的验证

| 项 | 原因 | 归属 |
| --- | --- | --- |
| 真实手机机型 | 本轮无真机接入 | S03 体验确认 |
| Android 7–10 | 模拟器只有 API 36 镜像 | 后续按需 |
| 系统下载器实际落盘 | 模拟器环境无法确认公共下载目录产物 | 后续按需 |
| 外网弱网/断网切换 | 未构造 | 后续按需 |
| 生产地址登录 | 生产未发布新前端 | S03 |

> 「模拟器通过」不等于「真机可用」：厂商 WebView 版本、系统省电策略、刘海与手势区差异都可能影响观感。
> 因此本页只作技术证据，本人手机确认仍是 S03 的门槛。
