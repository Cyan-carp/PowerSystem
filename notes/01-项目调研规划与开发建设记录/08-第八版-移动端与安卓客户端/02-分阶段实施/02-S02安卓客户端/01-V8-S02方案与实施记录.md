# 01 · V8-S02 方案与实施记录

> 工程怎么搭、构建链怎么串、外壳行为怎么定。可执行命令只在 `stages/12-android-client/README.md` 维护，本页写结构与判断。

## 一、工程结构

```text
stages/12-android-client/
├── app/
│   ├── AndroidManifest.xml           单 Activity，minSdk 24 / targetSdk 34
│   ├── src/com/powersystem/mobile/
│   │   └── MainActivity.java         外壳全部逻辑，约 480 行
│   └── res/
│       ├── values/                   应用名、主题色、无 ActionBar 主题
│       ├── drawable/ic_launcher_foreground.xml
│       ├── mipmap-anydpi-v26/ic_launcher.xml   自适应图标（Android 8+）
│       ├── mipmap-*/ic_launcher.png            兼容图标（脚本生成）
│       └── xml/shortcuts.xml         长按图标的「服务器设置」
├── scripts/
│   ├── make-icons.ps1                System.Drawing 画各密度图标
│   └── build-apk.ps1                 aapt2 → javac → d8 → zipalign → apksigner
└── build/                            产物与密钥（git 忽略）
```

**没有** `build.gradle`、没有 `settings.gradle`、没有 `gradlew`、没有任何 Maven 依赖。

## 二、构建链

| 步骤 | 工具 | 关键参数 | 产物 |
| --- | --- | --- | --- |
| 图标 | `make-icons.ps1` | 48/72/96/144/192px | `res/mipmap-*` |
| 资源编译 | `aapt2 compile` | `--dir res` | `res.zip` |
| 资源链接 | `aapt2 link` | `-I android.jar`、`--min-sdk-version 24`、`--target-sdk-version 34`、版本号由参数注入 | `base.apk`（无 dex） |
| 源码编译 | `javac` | `-source 8 -target 8 -classpath android.jar` | `.class` |
| dex | `d8` | `--lib android.jar --min-api 24` | `classes.dex` |
| 打包 | .NET `ZipArchive` | 把 `classes.dex` 写入 APK 根 | 含 dex 的 APK |
| 对齐 | `zipalign` | `-f -p 4` | 已对齐 |
| 签名 | `apksigner` | v1/v2/v3，`--v4-signing-enabled false` | 可安装包 |

两条工程约束（来自本轮踩坑，见问题记录）：

1. **中间产物必须落在纯 ASCII 路径**（`%TEMP%\powersystem-apk-build`）。`aapt2`/`zipalign` 是原生程序，
   仓库路径含中文时它们打不开目录；`javac`/`d8`/`apksigner` 是 Java 工具，不受影响，最终 APK 仍写回仓库。
2. **`.ps1` 必须带 UTF-8 BOM**。Windows PowerShell 5.1 默认按 GBK 解析脚本，无 BOM 时中文提示变乱码并触发语法错误。

## 三、外壳行为

| 场景 | 实现 |
| --- | --- |
| 首次启动 | `SharedPreferences` 无地址 → 显示服务器设置页（默认生产入口），保存后才加载 |
| 之后再改地址 | 桌面图标长按 → 静态快捷方式（`com.powersystem.mobile.SETTINGS`）→ 设置页 |
| 同源判断 | `shouldOverrideUrlLoading` 比较 host；首次加载时 `getUrl()` 为空，回退到配置入口的 host |
| 主文档失败 | `onReceivedError` 且 `isForMainFrame()` → 错误页（重试 / 修改地址）；接口与图片失败不拦 |
| 下载 | `DownloadListener` → `DownloadManager`，带 Cookie 与 UA，落公共「下载」目录 |
| 返回键 | 有网页历史则 `goBack()`；无历史则 2 秒内连按两次退出；覆盖层直接交给系统 |
| 销毁 | `onDestroy` 先解绑 client 再 `destroy()`，避免回调打到已销毁的 WebView |

界面全部用代码搭，不引 `R` 资源常量——这样 `aapt2 link` 不需要生成 `R.java`，链路少一步。

## 四、资源配置

| 资源 | 值 | 说明 |
| --- | --- | --- |
| 应用名 | 源网智联 | `res/values/strings.xml` |
| 主题 | `Theme.Material.Light.NoActionBar` | `windowBackground`/状态栏/导航栏都用 `#EEF1F7`，避免启动闪白 |
| 图标 | 自适应（蓝底 + 白色晶体） | 与网页 favicon 同源图形 |
| 快捷方式 | 「服务器设置」 | 静态，API 25+ 生效 |

## 五、版本与签名

| 项 | 值 |
| --- | --- |
| 包名 | `com.powersystem.mobile` |
| 版本 | `versionCode 1` / `versionName 1.0.0`（构建脚本可传参覆盖） |
| 签名 | 自签名 RSA 2048，别名 `powersystem`，有效期 10000 天 |
| 密钥位置 | `build/keys/powersystem-mobile.jks`（git 忽略） |

> 这是**内部安装包**：密钥口令写死在构建脚本里，任何人拿到仓库都能出同名同签名的包。
> 对外分发前必须换成自己的密钥并离线保管——换钥匙等于换身份，老包无法覆盖升级。

## 六、明确没做的事

| 项 | 说明 |
| --- | --- |
| 上架应用商店 | 不做，targetSdk 34 也不满足商店新要求 |
| 推送通知 | 不做，告警提醒仍靠网页内的 WS 提醒与飞书 |
| 离线缓存 | 不做，「不打包网页」原则的必然结果 |
| 多服务器切换列表 | 只留一个可编辑地址，够用且实现简单 |
| 深色模式跟随系统 | 网页自带主题切换按钮，外壳不重复实现 |
