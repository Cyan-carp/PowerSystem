# 04 · 阶段路线与验收矩阵

> 三阶段的切分依据与判据。「代码完成 / 本地实测 / 内部安装包 / 生产上线」四类证据分开记，互不代偿。

## 一、为什么切三段

| 阶段 | 交付 | 为何独立 |
| --- | --- | --- |
| S01 手机端适配 | 前端断点与壳层 | 只动前端，可独立验证与回退；不涉及任何原生构建 |
| S02 安卓客户端 | 外壳工程与安装包 | 引入新工具链（SDK/签名），失败面与前端完全无关 |
| S03 生产发布与体验确认 | 上传前端、本人手机实装 | 触及生产，必须单独取得授权并登记定位卡 |

> S01、S02 可以在同一次对话内完成（本轮即是），但证据必须分别留存；
> S03 因为涉及生产，不得与 S01/S02 合并签收。

## 二、验收矩阵

### S01 手机端适配

| 判据 | 口径 |
| --- | --- |
| 类型检查 | `npm run typecheck` 零错误 |
| 构建 | `npm run build` 成功产出 `dist/` |
| 无横向溢出 | 390×844 视口下 9 个主要页面 `scrollWidth == clientWidth` |
| 导航可用 | 底栏四格 + 「更多」面板可点、选中态正确、切页自动收起 |
| 浮层不越界 | 顶栏弹层在 390px 下完整落在视口内 |
| 控制台 | 页面无 JS 报错/异常 |
| 桌面不受影响 | 所有新规则在 `≤900px` 内，>900px 观感与既有验收一致 |

### S02 安卓客户端

| 判据 | 口径 |
| --- | --- |
| 可构建 | 脚本一次跑完，无需 Gradle、无需联网 |
| 包信息 | 包名/版本/minSdk/targetSdk/权限/中文应用名/图标 与设计一致 |
| 可安装 | `adb install` 成功 |
| 可运行 | 首启设置页 → 指向地址 → 登录成功，页面为手机端布局 |
| 系统能力 | 返回键先退历史、底栏与抽屉可用、无崩溃 |
| 日志 | logcat 无 `AndroidRuntime` 异常 |

### S03 生产发布与体验确认

| 判据 | 口径 |
| --- | --- |
| 发布 | 按上传规范与前端快路径执行，active 指针与镜像留痕 |
| 登记 | 当月上传定位卡登记本批路径 |
| 回写 | 唯一状态页同批更新「本批变更 / 本批镜像」 |
| 体验 | 本人手机实装确认（不代签） |

## 三、进入下一阶段的判定

- S01 → S02：前端构建通过且手机视口无溢出即可，不要求真机（真机在 S02 一起看）。
- S02 → S03：APK 在至少一台 Android 14+ 设备/模拟器上完成「登录 + 切页 + 返回」。
- S03 收尾：所有者本人在手机上看到新布局并确认，才可把本版标为「已上线」。

> 本轮实际停在 S02 完成、S03 未开始。因此本版在 [[00-当前系统状态]] 只登记为「工作区完成、未发布」。

## 四、失败与回退口径

| 场景 | 处置 |
| --- | --- |
| 手机端样式带崩桌面 | 只回退 `shell.css`/`App.vue`/`tokens.css` 三处，页面栅格不动 |
| APK 装不上（签名冲突） | 卸载旧包重装，并记录「本地登录态被清」的事实 |
| 签名密钥丢失 | 只能用新密钥重新出包，旧包无法覆盖升级；不得声称已升级 |
| 发布后手机端异常 | 按前端回退资产回到直接父版镜像，不跨版本激活 |
