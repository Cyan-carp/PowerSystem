# 项目调研规划与开发建设记录 · 索引

> 本目录收纳八个版本的建设记录、两个专项修复线和后台/展示两类补充业务。**“第几版”是建设阶段，不是 Git 标签或生产批次**；四套编号的换算见 [[00-版本与发布口径映射]]。生产指针只认 [[00-当前系统状态]]。

## 一、怎么读

1. 只想看现在是什么样 → [[00-当前系统状态]]，不要从版本目录翻起。
2. 想追某条能力怎么来的 → 先看对应版本索引，再进阶段页。
3. 想接续未完成的工作 → 看该版本的「跨对话交接 / 当前接续入口」，不要从最早的立项页读起。
