# 补充业务 · 索引

> 补充业务：即在实际应用中可能不需要，但为了本项目在我的特定环境下的完整演示而**新增的独立功能**。本目录集中维护这类功能的需求、设计、配置流程与实施边界。展示、参数、工具链一类的微调不进本目录，按运维口径记入部署与运维日志（分界见下方第二节末）。

## 一、定位与阅读约定

本目录独立于第一版、第二版的大纲和阶段主线。这里的“补充”描述本项目的引入原因，不表示每项能力都缺乏实际生产价值，也不豁免已经生效的安全与发布规范。阶段五基础通知、阶段一数据链路、阶段六基础备份/公网安全仍留在原阶段。

2026-10-16 按所有者要求整理：已有独立专题迁移正文，原部署位置仅留兼容导航；原来散落在源码 README/部署步骤中的内容补写为专题。源码、脚本、配置、测试及私有运行证据不随笔记迁移，不自动更新向量知识库。

## 三、文档与代码维护边界

- 业务需求、设计原理、适用条件、配置顺序、运行回退与真实状态集中于本目录；具体命令仍以源码或部署脚本 README 为唯一入口。
- 部署主流程只引用必要内容；FRP 自动来源更新必须单列为可选附加流程，说明本项目 R730XD 动态公网出口、SAS 单一来源限制及独立 443 恢复通道的特殊前提，不能要求所有服务器照搬。

- 生产发布强制约束仍归 [[02-工程规范边界与验收治理/项目工程规范/00-索引·项目工程规范]] 和 [[02-工程规范边界与验收治理/项目工程规范/08-发布工具与故障恢复说明]]；补充业务目录不复制第二套条款，不把自动验收门禁改为可选。
