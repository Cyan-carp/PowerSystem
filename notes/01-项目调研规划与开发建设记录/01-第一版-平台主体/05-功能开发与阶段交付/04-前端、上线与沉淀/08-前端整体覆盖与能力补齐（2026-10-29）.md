# 前端整体覆盖与能力补齐（2026-10-29）

> 本页记录 `stages/04-frontend` **换掉整套实现**之后的八轮补齐：为什么要换、换成了什么、每轮补了什么、接口覆盖到什么程度、还差什么。
> 现行工程事实见 [[09-当前前端工程说明（2026-10-29）]]，本人可直接执行的界面规则见 [[02-工程规范边界与验收治理/项目工程规范/02-发布仓库与界面验收规范]] 第三节。
> 本页 **不代表已上线**：工作区是本地候选，生产仍是 `frontend aafd11ea…` 的旧浅色版，发布指针见 [[00-当前系统状态]]。

## 一、起因：整站被覆盖

2026-10-29 按要求把同级独立前端 `新能源场站云边协同智能运维平台` 整体覆盖进本仓库 `stages/04-frontend/src`，属于**破坏性替换**（旧 `src` 98 个文件整体让位）：

- 覆盖前留档：`backups/frontend-pre-cover-20261029/`（旧 `src` 98 文件 + 入口与配置，共 102 项）。
- `src/` 换成新前端 25 个文件，`index.html` / `README.md` / `DESIGN.md` 一并替换；`vite.config.ts` 保留本仓库的代理约定（5173 → `VITE_API_TARGET`，默认 8080）。
- `package.json` 依赖收敛为 `vue` / `vue-router` / `marked` / `dompurify`，**移除 Element Plus、ECharts 与图标包**。
- 为满足旧 tsconfig（`strict` + `noUnusedLocals` + `verbatimModuleSyntax`）修 23 处类型错误。

覆盖带来的**能力缺口**（旧版有、新版没有）逐条登记在 `stages/04-frontend/PARITY-20261029.md` 第四节，按影响排序后一轮一轮补。

## 二、八轮补齐

| 轮次 | 补什么 | 关口 | 纪要 |
| --- | --- | --- | --- |
| 1 | 整体覆盖与新前端落地 | 破坏性替换 | 本页第一节 |
| 2 | 登录与会话（`POST /auth/login`、token 注入、401 唯一出口、路由守卫、账号菜单） | 无鉴权就不敢上公网 | PARITY 第七节 |
| 3 | 告警写闭环（抽屉确认/归档、列表勾选批量归档、409/503 中文提示、跨标签实时刷新） | 写能力在 UI 上不可达 | PARITY 第八节 |
| 4 | 报表导出接回**后端 CSV**（`?format=csv`），后端失败才退回本地拼 | 推翻上一版「端点臆造」的误判 | PARITY 第四节第 7 条 |
| 5 | 助手运行态（SSE 事件流、动作审批弹窗、产物下载校验、来源阅读、任务记录） | 只有一次性返回，看不到过程 | PARITY 第九节 |
| 6 | 报表设备级可用率表 + 健康评分依据/采样时间/状态四分 | 排障看不出分数怎么来 | PARITY 第十节 |
| 7 | 定期任务方案预演（`/agent/rule-preview`）+ 最近审查列表 + 审查就地审批 | 不能先预演再建任务 | PARITY 第十一节 |
| 8 | AI 告警解读改读后端结果（结论/事实/建议/局限/证据），模板降级为兜底 | 页面上的「AI 解读」其实是模板文案 | PARITY 第十二节 |

每轮的共同做法：**先读真后端实现，再动界面**；接口形状、状态码、时序都以 `stages/02-backend` 与生产实测为准，假后端 `dev/mock-server.mjs` 同步改成同一份契约（否则本地验证的是假象）。

## 三、接口覆盖

- 前端调用 **51 条**（50 条 HTTP + 1 条 WebSocket），全部能在 `internal/api/server.go` 找到同名路由，**不存在对着空气调接口**。
- 后端有、界面还没入口的 **17 条**，都是功能缺口（注册、会话核验、发电量报表、设备台账写、告警规则管理、09 部分运维接口等）。
- 逐条对照与参数基准见 `stages/04-frontend/API-INVENTORY-20261029.md`。

## 四、验收方式

纯前端改动按「必要构建 + 页面实际效果」验收，不重复跑业务测试套件（历史偏好见规范第三节 3.7）：

- `vue-tsc --noEmit` 0 错；`vite build` 通过；`node --check dev/mock-server.mjs` 通过；假后端与 `npm run dev` 起来后按页面走查。
- 浏览器核验一律看**实际渲染**：本机 MCP 内置浏览器曾整轮不可用（截图返回 `Current display surface not available`），改用无头 Chrome + CDP 探针（`Page.navigate` / `Runtime.evaluate` / `Page.captureScreenshot`）截图落盘核对，探针用完即删。

## 五、留在本页之外的三件事

1. **生产尚未发布**：本轮只到本地候选，`production-stack.py prepare → backup → publish` 与发布指针回写都还没做。
2. **构建落后于代码**：`dev/mock-server.mjs` 刻意不入库（`.gitignore` 覆盖 `stages/04-frontend/dev/`），别人拉仓库只拿到源码与文档。
3. **历史界面记录不迁改**：第 13–15 周的周记、深空值班台、浅色控制台上线记录留在原处作历史；本页只描述覆盖后的实现。
