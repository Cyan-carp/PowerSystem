## 三、样式与设计令牌

- **只有两个样式入口**，都在 `main.ts` 里按 `tokens.css` → `shell.css` 顺序引入；页面内样式一律 `<style scoped>`，覆写子组件用 `:deep()`。
- `tokens.css` 分组定义：底色/卡片/边线（`--bg`、`--card`、`--card-soft`、`--line`、`--line-strong`）、文字四级（`--ink` → `--ink-4`，另有 `--ink-placeholder`）、品牌（`--brand`、`--brand-deep`、`--brand-soft`、`--brand-line`）、语义（`--ok` / `--warn` / `--bad` + 各自 `-deep` / `-soft`）、圆角（`--r-lg` 8px、`--r-md` 6px）、尺寸（`--rail-w` 64px、`--top-h` 60px、`--dock-w` 420px）。
- **色值不写进文档**：改主题只动 `tokens.css`，页面里出现硬色值视为缺陷（图表与个别语义色除外，改时逐处核对）。
- `shell.css` 提供跨页复用类：`.card` / `.card-head` / `.btn` / `.btn-primary` / `.chip`（`is-ok`/`is-warn`/`is-bad`/`is-brand`/`is-plain`）/ `.kv`（`dt/dd` 网格）/ `.page-head` / `.error-box` / `.notice` / `.empty` / `.loading`。

## 四、骨架

```
.rail   64px 图标轨：顶部品牌按钮 → 8 个导航（图标 + 两字标签 + 悬停提示）→ 底部「使用说明」
.shell
 ├─ .topbar  60px：页名 → 搜索框（Ctrl/⌘+K）→ 弹性留白 → 实时灯 / 时钟 / 告警解读（未读点）/ 活动告警（角标+弹层）/ 账号菜单
 └─ main.page  页面内容（每个视图自带 .page-head）
```

- 导航固定 8 项：总览 / 告警 / 设备 / 健康 / 预测 / 报表 / 任务 / 助手。选中态由 `route.path` 前缀匹配，设备详情页仍点亮「设备」。
- 弹层只有三种（活动告警、账号、解读抽屉），点外部关闭；页面级详情一律用 `Drawer` 抽屉，不用弹窗。

## 六、数据与状态约定

- **两条通道**：`/agent/runs`、`/agent/schedules`、产物元数据是**裸 JSON**，走 `rawGet/rawPost`；其余是 `{code,message,data}` 信封，走 `get/post`。`code !== 0` 即失败。
- **401 只有一个出口**：`lib/auth.ts` 清会话 → `notifyUnauthorized()` → toast + 带 `redirect` 回登录页。业务代码不各自判断 401。
- **不做乐观更新**：写操作成功后再回读服务端结果；失败给中文原因（`409` 已被别人处置、`404` 已归档、`503` 维护中、`0` 连不上），并提示刷新核查。
- **实时**：`lib/store.ts` 建一条 WS（`/ws-ticket` 换 ticket → `/ws/realtime`），遥测更新 `shell.pulse`，告警写事件递增 `shell.alarmRevision`，解读进度递增 `shell.insightRevision`，各页按需 watch 后静默重取。
- **时间与数值**：一律 `lib/format.ts`——`across()` 相对时间（支持「N 后」）、`clock` 时钟、`METRIC_CN/UNIT/DIGITS` 指标口径、`LEVEL_CN`、`stationTone` 场站色标。时间按北京时间展示，原始时间戳不改写；数值用 `tabular-nums`，空值显示 `—` 而不是 0。
- **深链即契约**：`/alarms?id=` 直接开抽屉、`?status=&level=` 双向同步；`/health?state=` 四分；`/reports?tab=` 页签。查询参数进得去也回得来。

## 八、本地开发与校验

```bash
# 假后端（127.0.0.1:8080，seed mulberry32(20261026)，143 台设备 / 26 条告警）
node dev/mock-server.mjs

npx vue-tsc --noEmit && npx vite build && node --check dev/mock-server.mjs
```

## 九、已知边界

- **未发布**：本轮只到本地候选，没走 `production-stack.py`，生产指针与本页描述的新版无关。
- 解读只接 `device_alarm` 一类；`prediction_risk` / `platform_monitor` 还没有消费它们的落点；`hypotheses` 未渲染（生产 answered 样本里为空）。
- 移动端只做「收窄不坏」，没有精细适配；会话代码块与超长内容的可读性仍是待办。
- 无 UI 组件库意味着表单校验、日期选择、虚拟滚动等都要自己写，新增交互前先看现有组件能否复用。
