# V5-S01基础安装版 · 索引

> 本阶段把现有固定域名页面装进受控的 Windows 桌面窗口：能安装、能启动、能登录、能退出，并先立住主进程隔离与桥接安全边界。不做托盘、通知、另存为等运维桌面能力。

## 一、阶段定位

**一句话**：交付一个「只是容器」的最简桌面壳，行为与现有浏览器访问一致，权限不扩大。

| 本阶段包含 | 本阶段不包含 |
| --- | --- |
| 立项与契约冻结（`powersystem-desktop/v1`） | 托盘常驻与关闭隐藏（S02） |
| 工程骨架与源码 README | 系统通知、告警去重与路由（S02） |
| NSIS 安装包与卸载 | 报表另存为（S02） |
| 单实例、窗口位置尺寸恢复 | 桌面设置项与开机启动（S02） |
| 加载固定来源、登录与既有核心业务 | 断网/休眠恢复策略（S02） |
| 启动失败本地兜底页 | Win11升级/回退、B机短验与团队发放（S03） |
| 主进程隔离与桥接白名单 | 自动更新、正式签名分发（首版不做） |

## 三、准入条件

1. Codex 六篇总体设计与本索引的上游导航已落盘，`03-桌面桥接契约与安全边界` 中窗口、桥接、来源三项契约可读。
2. 工作区基线已核对：分支、HEAD、既有未提交变更清单与交接一致；不覆盖、不回退他人修改。
3. 新建本阶段独立协作记忆，并确认本轮无并发发布窗口。
4. 本地具备 Windows 11 x64 测试机与固定团队账号，仅做本地与隔离验证。

## 四、退出条件与停止点

**退出条件**：测试页 T01–T13 均有实际证据（不是文档推演），问题页无阻塞项，四件套齐全，八项交接完成。

**停止点**：以下任一未满足即停在 S01，不进入 S02。

- 安全基线（sandbox / contextIsolation / nodeIntegration）在实机可核验；
- 关闭窗口即退出，进程与托盘均无残留；
- 重启后不保留 token，需重新登录；
- 安装包可装可卸，卸载残留范围已记录；
- 不存在任何内置模型凭据或密钥生成路径。

> S01已验收：工程、同候选Win11本机安装/使用/卸载、技术测试及交接完成。实际边界见测试页；本轮停止，不自动进入S02。
