# V5-S01 · 基础安装版 · 测试与交付

> S01基础安装版验收通过：T01–T13的技术、本人操作及实物证据已核。范围限本机Win11 x64的0.1.0候选；本阶段交接后停止，不自动执行S02。

## 一、测试计划

测试编号沿用 `V5-S01-Txx`；每条必须可复现，证据落 `artifacts/v5-desktop/s01-<日期>-rN/`。

| 编号 | 场景 | 前置 | 判定要点 |
| --- | --- | --- | --- |
| T01 | 本机Windows10/11 x64实际安装 | 未装过本候选 | 安装完成、快捷方式可用、首次启动进入登录页，记录实际系统；S03按2026-10-27最新范围仅Win11增量与B机短验 |
| T02 | 当前用户安装与权限核验 | 普通Windows用户 | 当前用户可装可卸，不默认请求管理员权限；核对x64打包配置及实际安装路径 |
| T03 | 卸载与残留检查 | 已安装并登录过 | 卸载后程序目录、快捷方式、开机项清理；用户数据残留范围如实记录 |
| T04 | 单实例 | 已运行一个实例 | 临时启动进程退出，无第二个常驻应用实例或订阅，已有窗口被聚焦 |
| T05 | 窗口位置与尺寸恢复 | 移动/缩放窗口后退出 | 重启回到原位置尺寸；断开副屏后不落到不可见区域 |
| T06 | 关闭窗口即退出 | 已登录 | 窗口关闭后进程退出，托盘无图标（S01 语义） |
| T07 | 重启不保留token | 内存partition，登录后完全退出再启动 | 启动未登录；核用户数据目录无令牌材料、无persist分区或持久浏览器会话，只保留非敏感偏好 |
| T08 | 登录与既有核心业务 | 团队账号可用 | 登录成功，告警/设备/助手等既有页面可正常浏览，行为与原浏览器一致 |
| T09 | 启动失败兜底页 | 断网或域名不可达 | 显示本地说明页，可重试可退出；不出现空白页或伪造登录态 |
| T10 | 安全基线核验 | 开发构建 | `sandbox`/`contextIsolation` 开、`nodeIntegration` 关；渲染层无 `require`/`process` 直通 |
| T11 | 桥接来源限制 | 已启动 | 非白名单来源调用桥接被拒并留日志；白名单内调用正常 |
| T12 | 外部链接 | 页面含目标为 `https` 的外链 | 由系统默认浏览器打开，不在应用内新开窗口 |
| T13 | 不生成模型密钥 | 完成一次登录与页面浏览 | 安装目录与用户数据无模型凭据；应用不发起模型请求 |

**补充记录项（不作为通过条件）**：未签名安装包的 SmartScreen 提示、首次启动耗时、安装包体积。

## 四、阶段五问结论

1. **做了什么**：工程、锁文件、NSIS、最终7项单元/15项隔离、同候选Win11实际安装使用卸载、Workbuddy复核与四件套八项交接，T01–T13通过。
2. **遇到什么问题**：Node/沙箱、事件签名、窗口缩放与测试时序、安装器模式、故障注入与检查器问题；失败批次保留。
3. **如何解决**：合规运行时/事件签名/窗口校正/当前用户专用配置，以及真实用户HKCU、DisplayIcon定位、ASCII+CRLF入口修正；保留失败并由本人复验通过。
4. **遗留什么**：S01无阻塞。未签名/默认图标、保留非认证用户数据、S01不支持文件保存均已说明；Win10/双机、升级/团队交付及S02能力尚未执行，按原阶段处理。
5. **能否进入下一阶段**：**S01验收通过，具备另开S02的准入条件。** 本对话止于S01，不自动执行S02，不外推S03或生产上线。

> 判定边界：本轮文档通过检查不等于 S01 通过；本机通过不等于团队机器通过；单次安装成功不等于安装卸载链路验收完成。
