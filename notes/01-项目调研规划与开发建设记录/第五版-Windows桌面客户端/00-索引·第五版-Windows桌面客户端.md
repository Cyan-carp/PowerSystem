# 第五版 Windows 桌面客户端 · 索引

> 第五版需求、设计、三个实施阶段与跨对话接续的总入口。创建版本目录不表示客户端已实现或生产已升级。

## 一、目标与阅读顺序

将现有平台扩展为固定团队使用的 Windows 客户端，保留网页入口。Electron 加载已有 HTTPS 业务页面，服务端继续承担数据、智能助手与定期任务；桌面端增加安装、窗口、托盘、通知和文件保存能力。

1. 每次先读 [[00-当前系统状态]] 与仓库协作规范、公共记忆。
2. 阅读 [[01-项目调研规划与开发建设记录/第五版-Windows桌面客户端/03-跨对话交接/00-V5当前接续入口]] 和 [[01-项目调研规划与开发建设记录/第五版-Windows桌面客户端/01-立项与总体设计/00-索引·V5立项与总体设计]]。
3. 核对本阶段契约、上阶段交接和实际工作区，再开始限定范围工作。
