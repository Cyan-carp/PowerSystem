# V5-S01 · 基础安装版 · 问题记录与解决方案

> 单独记录 S01 实际发生的错误与阻塞。每条按固定六要素填写；未解决项必须写明归属与是否阻塞阶段验收。预计风险另设一节，且明确标注尚未发生。

## 一、记录规范

- 编号格式 `S01-Pxx`（已解决/已明确）与 `S01-Uxx`（未解决/待归属），编号不复用。
- 必填六要素：**现象 → 原因 → 影响 → 解决办法 → 验证结果 → 状态/归属**。
- 失败证据原样保留，不覆盖成通过批次；重试成功也要保留首次失败记录。
- 只写本阶段实际问题，不搬运阶段历史缺陷。

- 阻塞项未清则 S01 不得签收；非阻塞项须写明去向（S02 / S03 / 后续维护）与不阻塞理由。
