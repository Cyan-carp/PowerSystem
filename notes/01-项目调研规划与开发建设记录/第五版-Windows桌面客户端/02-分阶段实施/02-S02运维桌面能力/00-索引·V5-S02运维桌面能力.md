# V5-S02运维桌面能力 · 索引

> 本阶段在 S01 可用桌面壳之上，增加托盘常驻、系统通知、报表另存为、桌面设置与断网/休眠恢复处理；不改变服务端权限与业务语义。

## 一、阶段定位

**一句话**：让桌面端在「不盯页面」时仍可用，但所有提醒与保存都以本机可观测为前提，不承诺后台兜底。

| 本阶段包含 | 本阶段不包含 |
| --- | --- |
| 关闭窗口隐藏到托盘、托盘菜单与显式退出 | Win11增量及B机短验（S03） |
| 系统通知：隐藏或未聚焦时提醒 | 后端推送接口改造 |
| 按告警 ID 去重、点击路由到告警详情 | 邮件/短信等外部渠道 |
| 报表「另存为」：沿用原鉴权与归属 | 报表内容或口径变更 |
| 桌面设置：通知默认开、开机启动默认关 | 保存账号口令或令牌 |
| 断网与休眠恢复：只重连不重放 | 自动重提任务、自动批准 |
| 退出/换号清理 | 自动更新与签名分发 |

## 三、准入条件

1. S01 已签收：安装卸载、单实例、窗口恢复、登录、兜底页与安全基线的证据可回读。
2. 核对总体设计中已冻结的桥接v1：能力查询、告警通知、偏好读写与通知会话重置；S02按该契约实现，下载由主进程Session下载事件接管，不新增通用另存为或业务代理方法。
3. 在阶段四实现可选页面适配；独立测试构建登记精确回环来源连接本机夹具与隔离后端，团队包不含测试来源或任意地址开关。若现有实时通道无法按此接入，回设计评审，不提前发布或擅自改后端。
4. 本阶段独立协作记忆已建立，工作区基线重新核对。

## 四、退出条件与停止点

**退出条件**：测试页 T01–T21 均有实际证据，问题页无阻塞项，四件套与八项交接完成。

**停止点**：

- 通知去重按告警 ID 生效，不能靠时间窗口近似；
- 另存为区分普通CSV的原鉴权/MIME及落盘大小、助手产物原size/SHA256；取消不记为失败；
- 断网或休眠恢复后**不**自动重提任务、**不**自动批准；
- 设置文件内不含 token、口令、报表内容或模型密钥；
- 关闭窗口隐藏后进程与托盘状态可解释，显式退出能真正结束。

> 当前状态见 [[00-当前系统状态]]。实际技术结果、R2后本机20项完整通过及T20自然告警缺样本边界只按本阶段测试页判定；本页退出条件不代表已满足。
