# 01 · 现状基线与需求范围

> 冻结第五版的目标用户、功能范围和不纳入首版的能力。生产事实不在此复述。

## 一、已核对的代码事实

现有前端为 Vue 3、TypeScript、Vite、Element Plus 与 ECharts。业务请求使用相对路径；WebSocket 根据页面来源连接 `/ws/realtime`；助手使用带 Authorization 的 fetch 事件流；登录令牌存 sessionStorage。前端支持鉴权下载，助手产物另外核对归属、字节数与 SHA256。

这些是本轮只读代码核对结果，不是第五版运行测试。具体维护入口见 [[06-代码工作区导航与链接映射/stages-04-frontend-README]]。视觉沿用实际浅色页面，旧深色样稿不能据此覆盖现有实现。

## 三、约束与默认值

- Windows 10/11 x64；本轮Win11本机增量与Win10第二机短验分别登记实际覆盖；首版为固定团队内部试用，安装程序按当前 Windows 用户安装，不要求团队安装本地数据库或 Docker。
- 业务入口固定为 `https://www.cyancarp.cn`。备用 IP 不自动切换，不开放任意服务器地址配置。
- 网站页面由现有发布流程更新；桌面原生功能随安装包更新，首个内部候选应用版本从 `0.1.0` 开始，不自动把仓库发布标签改成 v5.0.0。
- 正常窗口，不额外重做业务 UI。S01 关闭窗口退出；S02 交付托盘后，关闭窗口隐藏并首次说明，托盘菜单明确退出。
- 系统通知默认开启，Windows 的通知设置优先；开机启动默认关闭。完全退出后重新登录，常驻期间仍受令牌有效期限制。

## 四、不纳入首版与使用边界

不做本地离线整套系统、业务缓存同步、多平台安装包、独立内置业务页面、自动更新或公开签名分发。不新增服务器业务接口、数据库迁移、模型通道或审批权。

软件退出、休眠或断网期间不承诺实时提醒，也不承诺恢复时补齐全部历史推送；恢复后刷新当前业务数据。服务器上的定期任务不因客户端退出而停止。合成演示结果不能外推真实场站。
