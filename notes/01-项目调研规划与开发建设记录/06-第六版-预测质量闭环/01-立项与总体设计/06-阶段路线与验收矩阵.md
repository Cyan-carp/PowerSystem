# 06 · 阶段路线与验收矩阵

> 本版四个阶段在同一个工作批次内完成，没有分次发布。验收口径按「可复算」写，避免用「看起来对」结案。

## 一、阶段与交付物

| 阶段 | 交付物 | 代码位置 |
| --- | --- | --- |
| S01 | SQL 018、四张表、`qualityWorker`、真值回填、日指标、ECE、漂移检测、6 个接口 | `deploy/postgres/018_prediction_quality.sql`、`internal/model/prediction_quality.go`、`internal/api/prediction_quality.go`、`internal/store/store.go`、`internal/api/server.go` |
| S02 | 「预测质量」页签、KPI、混淆矩阵、校准曲线、趋势、版本表、漂移表 | `src/components/PredictionQuality.vue`、`CalibrationChart.vue`、`QualityTrend.vue`、`src/views/PredictionsView.vue`、`src/lib/api.ts` |
| S03 | 训练作业与准入判断、候选登记接口 | `prediction/retrain.py`、`POST /predictions/quality/models/import` |
| S04 | promote 状态机、版本表交互、漂移展示 | `internal/api/prediction_quality.go`、`PredictionQuality.vue` |

## 二、验收矩阵

| # | 验收项 | 判定方式 | 通过标准 |
| --- | --- | --- | --- |
| 1 | 迁移可执行 | 启动 api 或 `-migrate-only` 后查 `pg_tables` | 四张表存在，索引齐全 |
| 2 | 真值回填 | 观察 5 分钟后查 `prediction_outcomes` 行数 | 持续增长；`label_source='window_rule'` |
| 3 | 真值正确性 | 抽一条 `actual_fault=true` 的记录，核对其 `fault_onset_ms` 是否等于当日该场站槽位起点、设备是否为当日轮换设备 | 完全吻合 |
| 4 | 窗口未走完不标 | 查 `min(window_end_ms+3600000) <= now()` | 不存在提前标注 |
| 5 | 日指标 | 查 `prediction_quality_daily` 最近 3 天 | `samples = tp+fp+fn+tn` |
| 6 | 指标一致性 | 用 SQL 手算某日 precision 与接口返回比对 | 差异为 0 |
| 7 | 空值语义 | 选一个无样本的日期区间调 summary | 指标为 `null` 而非 0 |
| 8 | 校准曲线 | 手工把 `prediction_outcomes` 按概率分 10 桶重算 ECE | 与接口一致 |
| 9 | 漂移事件 | 观察若干小时后查 `prediction_drift_events` | 同日同 `level+signal` 只有一条 |
| 10 | 页签渲染 | 打开预测页切「预测质量」 | 六个区块都有数据或明确空态 |
| 11 | 权限 | 运维员账号进入 | 看不到「提升为现役」 |
| 12 | 提升 | 造一个候选后点击提升 | 旧 active 变 retired，目标变 active，`promoted_by` 为当前账号 |
| 13 | 提升拒绝 | 对非 candidate 版本调 promote | 返回 409 |
| 14 | 登记接口 | POST import 一份 retrain 报告 | 台账出现记录，`eligible=false` 时为 rejected |
| 15 | 训练脚本 | 跑一次 `retrain.py --synthetic` | 产出候选目录与报告；退出码 0 或 2 |

## 三、回归项（不能因为本版变坏）

| 项 | 判定 |
| --- | --- |
| 原预测列表 | 页签默认回到「预测排行」，筛选、分页、抽屉详情与改前一致 |
| 原预测接口 | `GET /predictions`、`GET /devices/:id/prediction` 行为不变 |
| 预测写入 | `predictionWorker` 未改动，新记录继续产生 |
| 启动时间 | api 冷启动未因新 worker 明显变长（worker 首次延迟 90 秒） |

## 四、明确不验收

- 真实模型文件替换与容器重启（运维流程，不在本版）。
- 自动训练与自动回滚（本版不做）。
- 真实设备故障下的预测准确率（仿真环境无法验证）。

## 五、发布依赖

1. **api 必须重新构建**（新迁移、新接口、新 worker）。
2. **frontend 必须重新构建**（新页签）。
3. `03-ai-prediction` 的 `retrain.py` 是新增脚本，**不影响运行时镜像**；若要实际重训，需要能在容器内或带依赖的环境执行。
4. SQL 018 随 api 启动自动执行，无需手工迁移；若要单独执行，用 `-migrate-only`。
