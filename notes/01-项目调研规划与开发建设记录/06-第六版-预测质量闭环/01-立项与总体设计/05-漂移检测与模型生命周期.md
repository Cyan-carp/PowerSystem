# 05 · 漂移检测与模型生命周期

> 说明「什么情况算漂移」「触发后会发生什么」「模型版本如何流转」，以及本版为什么刻意不做全自动。

## 一、三层漂移信号

阈值是 `internal/api/prediction_quality.go` 顶部的常量，改这里即可调整。

| 层 | 信号 | 基线 | 触发条件 | 频率 | 需要真值 |
| --- | --- | --- | --- | --- | --- |
| L1 | `probability` 均值偏移 | 前 7 天日均 | 偏离超 ±15% | 每小时（看 24h 观察窗） | 否 |
| L1 | `high_ratio` 高风险占比 | 前 7 天日均 | 越出 [0.05, 0.25] | 每小时 | 否 |
| L2 | `ece` 校准误差 | 前 7 天 | 高于基线 0.05 以上，连续 3 天 | 每小时算，看近 3 天 | 是 |
| L3 | `precision` 命中率 | 前 7 天 | 低于基线 10 个百分点，连续 3 天且样本 ≥200 | 每小时算，看近 3 天 | 是 |

去重规则：**同一天同一 `level+signal` 只写一条**，避免每小时刷一条。

`action` 只有两种：
- `watch`：L1 命中。只记事实，提示关注，不要求动作。
- `triggered`：L2/L3 命中。表示「质量已实质退化，建议人工介入」。

## 二、为什么 L1 存在

真值要等预测窗口走完才有，L3 天然滞后。L1 不需要真值，能在模型还没被证伪之前发现「输入分布变了」——例如模拟器停摆、设备掉线、遥测口径调整。它的作用是把发现时间从「天」压到「小时」。

## 三、模型版本状态机

```
（首次接入现役，import status=active）
        active ──promote 新候选──> retired
           ▲                          │
           │                          │
        promote                       │
           │                          ▼
      candidate ──不合格──> rejected（保留 rejection_reason）
```

- `candidate`：训练产出且通过准入，等待人工提升。
- `active`：登记为现役。全表最多一个（promote 时把旧的改 retired）。
- `retired`：历史现役。
- `rejected`：未通过准入，保留原因便于排查。

准入规则由训练脚本 `retrain.py` 判断，写入报告后由 import 接口落库：

| 条件 | 结果 |
| --- | --- |
| 训练样本 < 5000 | `insufficient_samples` |
| 正样本 < 50 | `insufficient_positives` |
| test F1 < 0.5 | `low_f1` |
| 全部通过 | `eligible=true` → `candidate` |

**正样本门槛是硬性的**：当前模拟器每天只产出 5 个正样本窗口，少于 50 条时重训必然学成「永远健康」，指标看起来很漂亮但完全无用。

## 四、提升的真实边界（必须知道）

页面上的「提升为现役」**只改数据库**：

- 它不会替换 `STAGE3_MODEL_DIR` 下的 `model.json`；
- 它不会重启 `ai-predict`；
- 它不会触发发布。

所以一次完整的模型切换是两步：**先在页面提升（台账）→ 再由运维换模型文件并重启容器（运行态）**。两步都做完，台账才与运行态一致。

接口与界面文案都已写明这一点。之所以不合并，是因为换模型属于发布变更，必须走既有发布流程与回滚机制，不能被一个按钮绕过。

## 五、本版刻意不做的事

| 不做 | 原因 |
| --- | --- |
| 漂移触发自动训练 | 训练需要调度、资源隔离、数据导出管道，属独立工程 |
| 训练完成自动上线 | 与发布流程冲突，且仿真真值不足以支撑无人值守 |
| 自动回滚 | 回滚依据的指标可能同样失真，需要人判断 |
| 阈值自动调参 | 会掩盖模型本身的问题 |

## 六、若要演进到全自动，前置条件

1. 真值来源从「注入窗口」升级为「真实故障工单或人工标注」，且 `label_confidence` 有足够多的 `confirmed`。
2. 有独立的训练容器与队列，训练不挤占推理。
3. 模型文件切换纳入发布工具（可回滚、可灰度）。
4. 至少积累 3 个月稳定指标作为基线，才能判断「变好」还是「抖动」。
