# S02 · 质量看板

> 在既有预测页加一个页签，不新开菜单、不引图表库。

## 一、交付

| 文件 | 内容 |
| --- | --- |
| `src/components/PredictionQuality.vue` | 主体：范围切换、KPI、混淆矩阵、版本表、漂移表、请求编排 |
| `src/components/CalibrationChart.vue` | 手绘 SVG 校准曲线 + 45° 参考线 |
| `src/components/QualityTrend.vue` | 手绘 SVG 命中率/漏报率双线趋势 |
| `src/views/PredictionsView.vue` | 顶部页签、`?tab=quality` 与 URL 同步、切页签收起抽屉 |
| `src/lib/api.ts` | 六个方法与类型定义 |

## 二、页签行为

- 默认仍是「预测排行」，行为与改前一致。
- 切到「预测质量」写入 `?tab=quality`，刷新后保持。
- 首次进入才挂载（`v-show` + 标记），来回切不重复请求。
- 原筛选的 watch 原先直接 `router.replace({query})` 会把 `tab` 冲掉，已收敛为统一的 `writeQuery()`，从组件状态拼 query。

## 三、六个区块

| 区块 | 数据来源 | 空态 |
| --- | --- | --- |
| KPI 四块 | summary | 指标为 null 显示 `—` |
| 混淆矩阵 2×2 | summary | 四格 `—` |
| 校准曲线 | calibration | 「暂无样本」 |
| 按天趋势 | series | 「暂无样本」 |
| 版本表 | models | 「尚无登记版本」 |
| 漂移事件 | drift | 「暂无事件」 |

## 四、权限

只有 `candidate` 行、且当前用户是管理员时显示「提升为现役」。点击弹确认框，写明「只切换登记的现役版本，真实模型文件由运维替换」。确认后调 promote，成功 toast 并重拉列表。

## 五、样式约束

- 只用 `tokens.css` 变量，不写死颜色。
- 图表沿用 `PowerChart` 的 `ResizeObserver + viewBox` 写法，测量无内边距容器。
- 趋势线遇 `null` 断段，不连线到 0。
