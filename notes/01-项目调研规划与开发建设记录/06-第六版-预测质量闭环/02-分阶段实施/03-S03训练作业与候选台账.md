# S03 · 训练作业与候选台账

> 训练在容器外跑，产出「候选目录 + 报告」；台账由接口登记。两者都不碰运行中的推理服务。

## 一、训练脚本 `prediction/retrain.py`

| 参数 | 说明 |
| --- | --- |
| `--out-dir` | 必填。候选输出根目录，最终写 `<out-dir>/<model_version>/` |
| `--data-dir` | 已有训练数据目录；与 `--synthetic` 二选一 |
| `--synthetic` | 用 `generate.py` 现场生成合成数据 |
| `--days` | 合成天数，默认 180（**少于 10 天无法训练**，`generate.py` 的硬要求） |
| `--seed` | 合成种子，默认 2026 |
| `--baseline-version` | 仅写进报告，不参与训练 |
| `--report` | 报告路径，默认 `<out-dir>/retrain-report.json` |

产出：`<out-dir>/<model_version>/{model.json, metadata.json}` + `retrain-report.json`。

退出码：`0` 可登记；`2` 训练成功但未过准入；`1` 异常。

## 二、准入判断（写在脚本里，不留给人）

| 条件 | 结果 |
| --- | --- |
| 训练样本 < 5000 | `rejected / insufficient_samples` |
| 正样本 < 50 | `rejected / insufficient_positives` |
| test F1 < 0.5 | `rejected / low_f1` |

样本量取 train+validation+test 之和，报告里用 `sample_source` / `positive_source` 注明取值方式，便于审计。

脚本内置保护：若 `--out-dir` 等于或位于 `STAGE3_MODEL_DIR` 内，直接报错退出——防止误写生产模型目录。

## 三、登记接口

`POST /predictions/quality/models/import`（requireAdmin），body 即 `retrain-report.json` 的字段：

```json
{
  "model_version": "stage3-xgb-xxxxxxxxxxxx",
  "data_source": "synthetic",
  "threshold": 0.35,
  "metrics": { "accuracy": 0.9, "precision": 0.7, "recall": 0.6, "f1": 0.64, "samples": 12000, "positives": 320 },
  "train_samples": 12000,
  "positive_samples": 320,
  "artifact_path": "/data/candidates/stage3-xgb-xxxxxxxxxxxx",
  "trained_at": "2026-11-01T08:00:00Z",
  "eligible": true,
  "rejection_reason": null
}
```

- `eligible=false` → 落库为 `rejected` 并保留原因。
- 同版本重复提交可更新；**已是 `active` 的版本拒绝覆盖**（409）。
- `status=active` 仅在台账无 active 时允许（首次接入现役）。

## 四、完整流程（三步）

```bash
# 1. 训练，产出候选
python -m prediction.retrain --out-dir /data/candidates --synthetic --days 180

# 2. 登记（管理员令牌）
curl -s -X POST "$BASE/api/v1/predictions/quality/models/import" \
  -H "Authorization: Bearer $TOKEN" -H "Content-Type: application/json" \
  -d @/data/candidates/retrain-report.json

# 3. 页面「预测质量 → 版本表」点「提升为现役」，再由运维替换模型文件并重启 ai-predict
```

## 五、边界

- 本版**不自动拉起训练**。漂移事件只是建议，训练由人执行。
- 训练数据源当前用合成数据；接 TDengine 导出的生产遥测是后续独立工程。
- `baseline_metrics` 恒为 `null`（现役模型指标需在同测试集上复算，本版未做）。
