# 06 · 开发环境与生产分开

> 本机开发环境与生产是两套东西：开发库只有 3 台有效设备，连接方式走 home-dev 隧道，命令以源码 README 为唯一入口。**本页不代表生产状态**。

## 一、现状

home-dev开发依赖已迁到DESKTOP-LHHD9GR；本机代码/Git保留、Docker Desktop可退出。5中间件/7卷及远端原生stage2-api可用，日常显式使用home-dev context与SSH隧道。开发库当前有效设备3台，不套用生产143台。源数据完整对账及整机重启恢复尚未完成，校对与连接入口见[[73-home-dev开发中间件迁移校对与连接手册修订]]；生产指针见 [[01-生产快照与发布指针]]。

## 二、入口

后续本地启动后端或管理开发Docker，先读[[05-代码工作区导航与链接映射/01-项目与阶段说明/stages-02-backend-deploy-home-dev-README|项目内远程连接手册]]；连接与命令以该文件为唯一入口。

## 三、边界

- 开发库结论不能外推到生产：设备数、数据量、镜像版本都不同。
- home-dev 的命令不适用于生产 VM117；生产按上传与分级发布规范执行。
- 本页只写"环境在哪里、怎么连"，不写发布步骤与门禁结论。
