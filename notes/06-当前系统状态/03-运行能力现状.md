# 03 · 运行能力现状

> 现在**能用什么、不能用到哪**：智能助手、S06/S08 审批、模型通道、额度面板、前端界面与发布门禁。每条只写现行口径，细节指向对应专题。

## 一、能力清单

- **智能助手**：对话、联网检索、平台只读查询、历史会话与任务记录均已上线；健康分阈值问句读取全平台健康分接口，验证后按有效分数严格低于阈值筛选，未知分单列；明确的当前设备、场站、告警事实问句优先只读取证，支持在线设备数、场站当前功率、最久未处理告警、已确认/未处理告警计数和今日暂计电量。场站“下降最多”缺历史同口径基准时只给当前功率并说明缺口；见 [[107-助手健康分问答取证与双服务发布]]、[[109-智能助手正常业务问答取证与两版发布]]。任务记录支持批量删除，删除为软删除（`ma_tasks.deleted_at`/`deleted_by`），只在列表隐藏，详情、报告与 9 张审计表全部保留。
- **S06/S08**：助手可提议告警确认、设备备注及本人定期日报/巡检；独立审查后须原轮次本人批准。定期任务入口`/agent/schedules`，仅本人站内交付，默认30天、最多90天只读授权，暂停/取消撤销、恢复重批；S07服务重启未开放。
- **模型通道**：主助手08已切官方 `api.deepseek.com` / `deepseek-flash` / thinking disabled，使用stage8_assistant专用凭据；09/10传统v6域保留既有兼容网关与SSE/JSON解析；新动作/调度另走下述独立官方域。07凭据与原模型保持，自动固定、仅指定手动model演示调用；敏感出站范围不扩。
- **模型质量“分析漂移”**：100 批接入质量分析密钥，101 批修复空白正文处理；交付后所有者回复“可以了”，记为本人可用反馈。未留存生成正文或请求记录，Codex 未独立完成登录态短验，详见 [[101-模型质量空白输出修复手工发布]]。
- **第四版角色**：主助手官方DeepSeek/Flash/thinking disabled保持；10仅新增动作/调度元数据独立官方通道，原09/10兼容网关与v6域不换。生产能力档为`v4-business-schedule/v1`，动作/调度开启、运维写/联合档关闭；未授权原始业务文本出站。
- **告警解读**：自动告警使用固定模板和数据库事实，新任务model_calls=0；指定手动model演示走原官方 `api.deepseek.com`（非流式），真实748号已回答、调用1次。来源明确标注，业务与脚本用法见[[01-项目调研规划与开发建设记录/补充业务/05-告警固定解读与手动演示/01-告警固定解读与手动演示]]；历史调用与结果不倒改。728 条旧业务告警及关联记录已备份后清空，ID 不重置；设备、规则、遥测、预测与平台监控保留。
- **前端界面（生产 vs 工作区）**：当前镜像来自 `user-management-20261109-r1`，在已上线「账号与安全」页增加管理员创建和管理账号区；桌面账号菜单、手机「更多」、此前矩阵与版本代号等界面保留。功能说明见 [[01-项目调研规划与开发建设记录/补充业务/08-登录后账号注册与权限管理/01-登录后账号注册与权限管理]]；发布事实见 [[114-登录后账号注册与权限管理直接发布]]。
- **账号与安全**：管理员、运维员均可查看本人资料并核旧密码修改本人密码；管理员登录后可创建账号并选择管理员或常规运维人员，普通运维人员不能注册。普通管理员可停用运维人员，只有原始 `user` 管理员可停用其他管理员；停用后旧会话及委托授权后续请求被拒，历史记录保留。生产未实际创建、删除或改密账号，见 [[01-项目调研规划与开发建设记录/补充业务/08-登录后账号注册与权限管理/01-登录后账号注册与权限管理]]。
- **模拟器遥测窗口与告警提醒**：五个合法真实时钟窗口已开启，固定轮换/每日上限5；当前TD确认源独立评估，历史业务接续与能源提交仍分离。全局页面提醒和原桌面v1通知桥恢复，短断线仅补查新鲜待处理告警，退出清理防串会话；实际范围与自然告警证据见[[67-每日告警与主动提醒链路补回]]。
- **模型通道与额度（2026-10-31 上线，11-03 改为按功能）**：顶栏额度胶囊与「模型与额度」面板仅管理员可见。面板不再按通道合并，而是按功能逐条列 5 项：告警解读（07）、主助手问答（08）、运维诊断（09）、安全审查（10）、模型质量评估（02）。前两项各有 `/internal/agent/model-balance`，查 DeepSeek 官方余额；质量分析密钥已只读接入 API，额度同账；09/10 走兼容网关 `hgapi.dieqiyun.top`，该网关无 `/user/balance`，如实标「未接入」并写明原因，不复制他项金额。金额按供应商字符串透传，非官方供应商显示「不提供余额查询」而不是 0。余额查询只转发结果；质量分析 API 单独只读挂载解读 Key。余额只对 DeepSeek 官方向有效，07/08 两条 Key 同属一个账号，金额相同不是两份额度。见[[01-项目调研规划与开发建设记录/补充业务/06-模型通道与额度面板/01-模型通道与额度面板]]。
- **跨屏显示密度（2026-11-08 上线）**：按屏幕物理像素宽分 `compact`/`standard` 两档，低分屏只对 `.page-inner` 收紧一档（0.9），页边距改 `clamp(22px, 3.4vw, 60px)`；顶栏、图标轨、抽屉、Toast 不受影响，窄屏断点复位。不设主观档位，不改数据、接口与口径；设计与边界见 [[01-项目调研规划与开发建设记录/补充业务/07-跨屏显示密度自适应/01-跨屏显示密度自适应|跨屏显示密度自适应]]，批次见 [[102-模型质量页信息架构与跨屏密度前端发布]]。真实双机目视未做。
- **发布门禁**：当前开发阶段按所有者效率授权可手工接受，仍核实际来源、镜像、配置、身份与数据边界。本批 `user-management-20261109-r1` 由受控源码快照构建，所有者明确不新建备份、不跑完整 HTTPS/WSS 门禁和功能测试，回执三项均为 false；不能称技术验收通过。现行恢复边界见 [[114-登录后账号注册与权限管理直接发布]]。
