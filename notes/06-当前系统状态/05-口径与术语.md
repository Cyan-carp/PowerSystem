# 05 · 口径与术语

> 同一个词在不同页面被理解成不同东西，就会出现"各自都对、互相矛盾"。这里只定义**跨页面必须一致**的少数说法。

## 一、现行口径

| 说法 | 含义 |
| --- | --- |
| 业务 140 台 | 第三版新增的四个业务场站合计 |
| 全平台 143 台 | 业务 140 + 基线 3 台 |
| 容量验证 200 台 | 隔离压测配额（ST-LOAD 200 台 / 5 秒 / 360 轮，72000 条），**不入生产** |
| 策略/许可 v6 | 阶段 10 现行版本，2026-10-19 起；v5 及更早为历史 |
| R0 | 生产只读登记，不含写动作 |
| pending=false | 无待发布候选，生产与登记的候选一致 |

## 二、容易混的两组

| 组 | 区分 |
| --- | --- |
| 命中率（批次口径 / 窗口口径） | 页面 KPI 按**故障批次**算（被提前叫出的批次 ÷ 总批次）；窗口口径只作备注，两者不能混着引用 |
| 预测窗口数 / 真实告警数 | 页面统计的"预测条数"是逐窗口推理量（约 4.1 万/天），真实告警每天 2–8 条；不能拿前者当告警量 |

## 三、维护

- 口径变了先改本页，再改引用它的页面。
- 只放"跨页面必须一致"的词；某一份文档内部的临时简称不进来。
