# 01 · 阶段三方案设计

> 对应 V2-T08～T10。说明受控知识库、静态页面帮助、值班问答与知识缺口维护的设计；具体启动命令维护于源码 README。

> **实施结果（2026-10-05）**：本方案已按合成演示与公开资料辅助建议范围完成技术验收并进入 V2-M4 交接。专业来源审核、真实设备手册校对、机型适用性和知识补齐未被本次签收替代，正式结论见 [[05-V2-M3测试与交付#十一、当天最终候选与真实页面验收（2026-10-05）]]。

## 一、目标与可行性

阶段一已经提供六个只读工具、用户会话和审计；阶段二已经验证模型不可用与业务主链路隔离。本阶段复用这些能力，不引入第二套身份认证或业务数据库写入。

知识源以结构清晰的 Markdown 手册为主，采用中文双字词、标题权重和人工同义词检索。当前资料规模适合本地索引；不额外部署向量库或嵌入模型。以后语义召回不足时可更换检索模块，回答和引用接口保持稳定。

## 二、需求与设计决策

| 任务 | 交付能力 | 对应需求 |
| --- | --- | --- |
| V2-T08 | 显式来源清单、章节索引、版本与来源阅读 | FR-22 |
| V2-T09 | 按页面打开静态使用指南 | FR-21 |
| V2-T10 | 问答页、证据回链、联网降级与缺口留档 | FR-22 |

- 文档问题先检索知识库；实时问题调用当前用户的业务工具，文档不能代替实时数据。
- 本地未命中时只对受控公开技术主题联网，不发送原问题中的账号、设备编码或私有地址。
- 页面帮助使用静态版本化文案，模型停止时仍能阅读。
- 未命中问题属于私有运行数据，正式知识库变更由人工审核。

## 三、数据流与失效边界

用户登录 → Go 鉴权 → Agent 会话 → 本地文档检索／业务工具 → 可选联网补充 → 引用与数字校验 → 回答、审计及缺口记录。

索引不可用和没有相关章节是不同状态；前者不启动联网兜底，不误报为知识缺口。搜索密钥未配置、认证失败、超时或无来源时显示原因，模型不能自由补充无依据事实。

部分工具无数据时只回答有效证据覆盖的内容，响应保留失败证据并增加限制提示。权限失败仍中止整轮。概率和阈值继续按业务证据原值校验。

## 四、默认限制与验收

- 模型单次 20 秒、Agent 总计 40 秒、Go 代理 45 秒；原六工具仍最多 5 轮、10 次调用。
- 联网最多一次、五条结果、五秒，不重试；知识证据预留五万字节，单次证据总量不超过 64 KiB。
- 缺口记录按天写入，默认保留九十天；审核状态另存，不覆盖失败证据。
- 检索固定至少三十例，正确章节前五召回不低于 90%；真实模型和真实搜索分别验收。

> 本阶段不自动确认告警、不建工单、不远控，不宣称真实场站诊断准确率。最终第二版整体安全复核和 Release 仍归 V2-M4。

## 五、博查补齐方案（2026-10-03）

DeepSeek 保持原回答职责，博查 Web Search 只返回取证资料。新增提供商选择属于服务私有配置，本阶段不增加网页 API 管理、不接入 AI Search 或新的模型工具。

处理仍为本地检索、判断公开搜索资格、博查取证、原模型回答、原校验与引用展示。搜索限一次、五条结果、五秒全过程、64 KiB 响应；取消搜索也必须记录已经确认的缺口。

实施前保存 `orchestrator.py/schemas.py/tools.py/interpret.py/main.py` 的 SHA256，并单独保存 URL 与公开查询构造的 AST 基线。主请求文件仅修正断连监听；鉴权、错误清理与审计函数的 AST 比对保持一致，其余四个文件逐字节一致。六个只读工具与所有校验防线原样保留，交付再次比对。概率、阈值、数字、引用、建议数量与长度均无搜索豁免。

## 六、开发阶段建议与签收口径调整（2026-10-04）

> 业务开发阶段受现实条件限制，尚未接入真实设备，也无法对接实际机型的设备手册。本阶段使用公开资料提供需人工核查的建议；后续须取得设备手册，并由专业工程师校对来源、操作建议及机型适用性。

项目所有者于 2026-10-03 明确：AI 可以提出资料支持的建议，涉及设备操作也可展示，由人员复核、决定与实施；不再因操作关键词整轮拒绝。此口径替代前次联网操作建议护栏与来源人工签收门槛，不改变实时业务取证、引用、数字、权限或工具只读限制。

- 来源审核本轮默认通过，单独记录所有者授权、回答与来源哈希、专业审核暂缓及待复核状态；不填写虚假的工程师审查。
- 问答与告警解读每条建议均可展开自己的来源；设备操作提醒默认醒目显示。告警解读不增加联网搜索，事件数据不冒充操作手册。
- 未命中后的搜索成功、失败、取消或回答拒绝均保留知识缺口；补库及专业审核保持待办，不因阶段签收自动完成。
- 仍须实际完成最终版本五题真实联网、严格问答、备份与隔离恢复、实际回退和三十分钟观察。专业来源与真实机型适用性另列后续任务，第二版 Release 归 V2-M4。
