# 02 · 测试矩阵与质量复核

> 对应 V2-T11。区分协议、真实模型、来源抽查和实际页面证据，不用单次HTTP成功替代整体验收。

## 一、测试矩阵

| 测试面 | 门槛 |
| --- | --- |
| 基础回归 | Agent、Go、前端、类型及构建全部通过 |
| 知识 | 固定题集前五召回至少90% |
| 解读 | 本机三类各10例，服务器三类各1例 |
| 问答 | 严格七题、真实联网五题、留档及取消 |
| 主链路 | 正常、故障、额度占满各10例告警≤10秒 |
| 权限 | JWT、角色、跨用户会话、限额及租约 |

## 二、质量抽查

三类解读各抽查3例，逐条核对结论、事件数据和建议关系。引用编号和数字校验不能证明根因正确；事件快照不能冒充操作手册。联网回答的专业审核继续 pending，原回答与来源哈希留存。

## 三、证据规则

本机产物进入 artifacts/stage7-智能体/v2m4/<运行编号>/，服务器进入 runtime/v2m4-<运行编号>/。统一账本保存证据SHA256；失败、中断、跳过或缺少门槛时不签收。

## 四、实际结果

实施中；最终批次、计数和复核结论以 [[05-V2-M4测试与交付]] 为准。
