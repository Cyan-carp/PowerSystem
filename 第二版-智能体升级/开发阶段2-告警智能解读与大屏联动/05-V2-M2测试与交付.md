# 05 · V2-M2测试与交付

> 核对日期：2026-10-01。V2-T05～T07、FR-20 已完成本机与 R730xd 验收，**V2-M2 合成演示范围技术验收通过，可以进入 V2-M3**。第二版 Release 留到 V2-M4。

## 一、正式结论

本阶段交付了三类事件的异步解读、触发时证据快照、用户列表/详情/已读接口、大屏队列、人工确认、管理员模型检测恢复，以及平台监控暂存、加密备份和回退。

验收门槛全部满足：

- 三类真实模型解读各不少于三例，最终本机 30/30 回答；
- 原告警、飞书与人工确认在 Agent、模型和解读存储故障时继续工作；
- 未配置、认证失败、明确无额度、普通限流和未知错误均按安全状态处理；
- 公网权限、大屏证据、备份恢复、实际回退和 30 分钟观察通过。

> 本结论只覆盖合成演示和当前服务器版本，不代表真实场站诊断准确率，也不等于第二版最终发布。

## 二、验收证据

### 2.1 代码与本机链路

**基础回归**

| 测试面 | 结果 | 证据批次 |
| --- | --- | --- |
| Go 全量回归 | 通过 | 含关闭解读时不连接 Agent |
| Agent 离线 | 38/38 | 引用、数字、时间、鉴权、审计与根因守卫 |
| 前端 | 类型、构建、8/8 | 大屏队列、确认与证据交互 |
| 协议模拟器 | 93/93，30 事件 | `fixture-20261001-final` |

**模型质量与兼容**

| 测试面 | 结果 | 证据批次 |
| --- | --- | --- |
| 真实模型 | 30/30 回答、87/87 检查 | `real-20261001-final-guard30` |
| 端到端延迟 | P95 27.84 秒 | 单事件从发生到持久终态 |
| 阶段一问答回归 | 25/25 | `m1-final-regression-r2` |

协议模拟器只证明错误分类与工程流程，不计真实模型质量。真实模型使用当前有效的 `deepseek-v4.1-flash`；没有故意消耗额度制造欠费。

### 2.2 故障与服务器链路

**故障隔离**

| 测试面 | 结果 |
| --- | --- |
| Agent 停止、解读表故障 | 原业务各 38/38；告警、确认、恢复和遥测不受阻断 |
| Go 重启、租约、监控暂存 | 去重、过期租约接管、提交后确认和 Stream 清零通过 |
| 未配置与恢复范围 | 缺失 5 项、恢复 3 项通过；旧事件和已恢复事件不补跑 |

**服务器交付**

| 测试面 | 结果 |
| --- | --- |
| R730xd 公网联调 | 28 项；三类各 3 例真实解读；MQTT 告警均在 10 秒内生成 |
| 飞书 | 业务通知发送；真实监控触发/恢复各 HTTP 200 |
| 备份、恢复与回退 | 两端密文一致；隔离续消费和旧镜像回退通过 |
| 最终观察 | 1800.52 秒、60 次采样、0 次失败 |

公网浏览器核对了自动面板、排序、概率/阈值、曲线、证据展开、已读、确认和断线恢复。飞书 HTTP 200 证明适配器接受，不等同于本轮独立确认群成员已阅读。

实施过程中遇到的问题、解决办法、验证状态和未解决边界已独立整理在 [[06-问题记录与解决方案]]。所有失败批次均与最终通过批次分开保存。

## 三、模型不可用验收

| 场景 | 已验证行为 |
| --- | --- |
| 未配置、空密钥、功能关闭 | Agent 保持存活；保留事实；不调用模型或不重试 |
| 认证失败、明确过期 | 映射 `auth_failed`，触发共享暂停 |
| 明确额度耗尽 | 映射 `quota_exhausted`，触发共享暂停 |
| 普通 429、网络、5xx | 不猜测余额；最多三次有限重试 |
| 输出、引用或数字非法 | 映射 `answer_validation_failed`，结论和建议为空 |
| 管理员恢复 | 每分钟一次；成功后只补最近 24 小时仍活动事件 |

供应商原错误正文、密钥和账户信息不进入浏览器。远程供应商要求有效密钥；本地 Ollama 可以使用空密钥文件。具体状态机和原因码见 [[02-异步解读与事件取证]]。

## 四、尚未解决的事项与边界

当前没有阻止进入 V2-M3 的功能性缺陷。V2-M2 不覆盖真实场站准确率和第二版最终发布；模型语义、飞书人工阅读及持久化物理边界统一登记在 [[06-问题记录与解决方案]]，不在测试页重复堆叠。

## 五、证据与清理

运行证据位于忽略目录 `artifacts/stage7-智能体/v2m2/`：

- 最终协议：`fixture-20261001-final/`
- 最终真实模型：`real-20261001-final-guard30/`
- 阶段一回归：`m1-final-regression-r2/`
- 服务器证据：`server-20261001/`

真实模型回答按三类各抽查三例，独立复核保存在 `review.json`；它检查引用、数字和人工确认标记，不宣称第三方认证。服务器收尾后，测试设备已软删除、测试告警和监控已恢复、规则已关闭、临时账号已禁用密码登录，历史快照与审计保留。

## 六、阶段三交接

V2-M3 可以直接复用本阶段的模型状态、引用校验、审计和大屏入口，但应保持以下分工：知识库回答使用受控文档来源，用户操作引导与当前页面版本对齐，任何业务写操作仍由现有接口和用户权限完成。
