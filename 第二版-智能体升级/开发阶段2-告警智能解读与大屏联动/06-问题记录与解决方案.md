# 06 · 问题记录与解决方案

> 汇总 V2-M2 实施、测试和上线期间实际遇到的问题。每条记录区分现象、原因、解决办法与最终状态；测试数字和阶段判定仍以 [[05-V2-M2测试与交付]] 为准。

## 一、记录口径

- **已解决**：已经修复并通过对应回归或现场复核。
- **已规避**：当前流程可安全运行，但需保留使用条件或操作约束。
- **未解决**：仍需后续数据、外部确认或下一阶段工作，必须注明是否阻塞当前阶段。
- 失败批次保留在忽略的 `artifacts/stage7-智能体/v2m2/`，不得覆盖或合并成通过批次。

下列表格的“问题”同时记录现象及直接影响，“状态”同时记录修复后的验证结果；无法合并表达的边界单独放在第六节。

> 当前没有阻止进入 V2-M3 的未解决功能缺陷。第六节列出的事项属于验证边界或后续阶段任务，不能写成当前已经完成。

## 二、开发环境与测试资产

| 问题 | 原因 | 解决办法 | 状态 |
| --- | --- | --- | --- |
| Go 测试无法写默认缓存 | 沙箱目录权限不足 | 改用工程内缓存目录 | 已解决，全量测试通过 |
| 前端首次构建失败 | 系统 Node 22.11 低于 Vite 要求 | 使用已有 Node 24.19，不修改依赖版本 | 已解决，类型与构建通过 |
| 首轮事件触发唯一约束 | 测试复用已有活动告警设备 | 每批创建独立 `INV-V2M2-*` 合成设备 | 已解决，失败批次保留 |
| 历史恢复测试出现竞态 | 提交后修改事件时间，快照已经保存 | 创建事件时直接写入 48 小时前时间 | 已解决，恢复范围复测通过 |

## 三、模型输出与校验

| 问题 | 原因 | 解决办法 | 状态 |
| --- | --- | --- | --- |
| 建议返回对象或引用非法 | 自由输出结构不稳定 | 固定唯一 `submit_interpretation` schema；非法回答整条拒绝 | 已解决，最终 30/30 |
| 合法时间被误拒绝 | 校验未覆盖嵌套时间和等价时区 | 接受证据中的 UTC/时区等价秒级表达 | 已解决，时间回归通过 |
| 温度 60 被当作预测阈值 | 多指标数字的就近关系不明确 | 按最近明确指标绑定，增加交换阈值拒绝测试 | 已解决，服务器复测通过 |
| 监控回答推断确定根因 | 证据只有告警标签，没有实际指标 | 增加确定根因语句守卫，缺指标时只陈述监控现象 | 已解决，离线守卫通过 |
| 阶段一续聊首次回归失败 | 既有时间校验触发拒绝 | 保留失败回答与审计，修复后重新执行 | 已解决，`m1-final-regression-r2` 为 25/25 |

机械校验可以拒绝伪造引用、概率改写和明显无依据根因，但不能证明所有自然语言语义正确。精确数字和时间仍以证据快照为准。

## 四、前端、部署与恢复

**大屏交互**

| 问题 | 原因 | 解决办法 | 状态 |
| --- | --- | --- | --- |
| 抽屉正文偏淡 | 面板继承顶栏颜色 | 挂载到 `body` 并明确正文色 | 已解决，公网复核通过 |

**服务器与恢复**

| 问题 | 原因 | 解决办法 | 状态 |
| --- | --- | --- | --- |
| 模型预检命令失败 | 使用了不存在的 `preflight` 子命令 | 改用实际 `probe` | 已解决，文本与工具检测通过 |
| 隔离 API 无法启动 | 恢复环境缺少 MQTT 依赖 | 增加无公网端口的隔离 MQTT | 已解决，续消费通过 |
| MQTT 健康检查误报 | 节点 RPC 状态不代表 1883 不可用 | 改查 TCP 1883 和 API 实际连接 | 已解决，隔离恢复通过 |

## 五、模型不可用场景

这些场景是实施前明确要求的故障能力，测试中均已闭环：

| 场景 | 解决办法 | 状态 |
| --- | --- | --- |
| 未配置、空密钥、功能关闭 | 保留事实，不调用模型或不重试 | 已解决 |
| 认证失败、明确过期 | 映射 `auth_failed`，共享暂停 | 已解决 |
| 明确额度耗尽 | 映射 `quota_exhausted`，共享暂停 | 已解决 |
| 普通 429、网络、5xx | 不猜余额，最多三次有限重试 | 已解决 |
| 输出、引用或数字非法 | 映射 `answer_validation_failed`，结论与建议为空 | 已解决 |
| 配置恢复 | 管理员限频检测，只补最近 24 小时仍活动事件 | 已解决 |

供应商原始错误、密钥和账户信息不进入浏览器。修改模型私有配置后需要重启 Agent，再执行管理员检测。

## 六、尚未解决的事项

| 事项 | 当前边界 | 后续归属 | 是否阻塞 V2-M2 |
| --- | --- | --- | --- |
| 真实场站诊断准确率 | 当前全部业务数据为合成数据 | 取得真实事件账本后重新验收 | 否 |
| 少量时间措辞不精确 | 相近时间可能被描述为“一致” | 继续改进语义评测；当前以快照为准 | 否 |
| 飞书群成员阅读证明 | 本轮只取得适配器 HTTP 200 | 通知配置变化或最终验收时复核 | 否 |
| 绝对零丢失 | AOF 与多组件备份存在物理窗口 | 运维持续复核，不作绝对承诺 | 否 |
| 第二版最终发布 | V2-M3 已完成限定范围技术验收；V2-M4 尚未完成 | V2-M4 安全复核与 Release | 否 |

上述事项必须保留在交接和后续验收中。它们分别属于数据真实性、模型语义、外部人工确认、基础设施边界和项目阶段范围。
