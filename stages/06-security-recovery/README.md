# 阶段六 · 公网安全与恢复能力运行说明

> 阶段六把第一版收官时完成的公网攻击面收敛、凭据审查、加密异地备份和隔离恢复正式列为项目主要亮点。为保持服务器部署路径稳定，实际脚本仍由 `stages/04-frontend/deploy/` 的统一 Compose 与 systemd 单元调用；本目录是阶段六的代码导航和边界说明，不复制脚本。

## 二、安全与恢复原则

- 公网只提供受信任证书的 HTTPS/WSS 入口；FRP 后端端口只供云端本机回环代理访问。
- SSH 使用公钥登录并关闭密码认证；数据库、MQTT、Redis、TDengine、AI、API、监控和飞书适配器不直接暴露公网。
- 备份目标必须在服务器私有配置中显式指定；备份包含数据库、队列、模型和恢复所需私有配置，整体加密后再传输。
- 恢复先在独立 Compose 项目和独立数据卷中验证，不直接覆盖生产卷。
- 仓库不记录密码、令牌、机器人地址、私钥、解密口令或生产数据；公开前同时扫描当前树和可达历史。
